# v0.8.16.0 — Theme Modes and Density

This is the last item of the automated run: the theme leftovers.
- Midnight (true black, for OLED screens);
- High contrast;
- compact and comfortable density;
- following the operating system's light/dark setting.

## Before

Each tab had an accent theme (Default, Emerald, Crimson, Violet) and a Light mode checkbox, stored on its
`ConnectionProfile` as `AccentTheme` and `ThemeVariant` ("Dark" or "Light"). `ThemeApplier.Apply` wrote the two
hand-tuned palettes in `ThemeCatalog` onto the application resources, and every surface reads them through
`DynamicResource`.

## Modes

`ThemeCatalog.Modes` lists five modes, still stored in `ConnectionProfile.ThemeVariant`. A tab saved as "Dark" or
"Light" reads exactly as before, and anything unknown is Dark, as a missing value always was.

| Mode | Built on | What changes |
|---|---|---|
| Dark | Dark | nothing (the default) |
| Light | Light | nothing |
| Midnight | Dark | backgrounds `#000000`; cards and chrome (command bar, sidebar, status bar, tabs, buttons) taken toward black with their alpha kept; page art dimmed almost to black; accent cards deeper |
| High contrast | Dark | white text, borders and card borders on black; muted text `#E8E8E8`; brighter status colours and accent hues; surfaces black, buttons dark grey with hover and press a step lighter; sidebar flat dark grey; page art hidden behind an almost opaque scrim |
| Follow the system | Dark or Light | the operating system's setting (Windows' app mode, the Linux desktop's colour scheme), and it changes with it |

- `ThemeCatalog.BaseVariant(mode, systemPrefersLight)` picks the hand-tuned palette.
- `ModeStructural` and `ModeSemantic` hold each mode's overrides.
- `ThemeApplier.ModeStop` adjusts the chrome gradient stops.
- The accent-coloured stops (primary, success, warning, danger, the selected tab and category) are not changed.
- `ThemeApplier.SystemPrefersLight` asks Avalonia's platform settings. The ViewModel subscribes to
  `PlatformSettings.ColorValuesChanged`, and only a tab set to follow the system re-applies (`OnSystemThemeChanged`).
- `IsLightMode` now means "the Light palette is showing", which the page art reads. Midnight and High contrast use
  the dark art.
- **Card borders** were a fixed `#426784` in `DesignSystem.axaml`. They are now `CardBorderBrush`: unchanged in Dark
  and Light, darker in Midnight, white in High contrast.

## Density

Density (Comfortable or Compact) applies to **every tab**. It is stored on this computer in
`display-preferences.json`, beside the other Desktop-local preferences (`LocalDisplayPreferencesStore`).

- The base styles in `DesignSystem.axaml` now read resources that `ThemeApplier.ApplyDensity` sets:

  | Resource | Used by | Comfortable | Compact |
  |---|---|---|---|
  | `ControlMinHeight` | Button, TextBox, ComboBox | 31 | 26 |
  | `CardPadding` | cards and status cards | 11 | 7 |
  | `InputPadding` | TextBox, ComboBox | 9,4 | 7,2 |
  | `ListItemPadding` | list rows | 4,3 | 4,1 |

- A class-specific style (the Ribbon's large buttons, section toggles, the smaller 28-high buttons) keeps its own
  size in either density.

## Settings

The Appearance card's **Light mode** checkbox is replaced by two pickers:
- **Mode** (per tab, like the accent theme);
- **Density** (every tab).

A line explains each mode.

## Verification

ArtworkHarness: 473 checks.
- A tab saved as Dark, as Light, or with an unknown value reads correctly.
- Each mode is stored on the tab. Text and muted text on a card meet 7:1 and 4.5:1 (15:1 and 12:1 in High contrast).
  Measured on a card:

  | Mode | Text | Muted text |
  |---|---|---|
  | Dark | 15.4:1 | 6.7:1 |
  | Light | 16.2:1 | 5.6:1 |
  | Midnight | 18.8:1 | 8.0:1 |
  | High contrast | 21.0:1 | 17.1:1 |

- Midnight's backgrounds are true black. High contrast's borders are white and its status colours reach 7:1 on
  black.
- **Follow the system**, both ways (the harness stands in for the operating system): a light system shows the Light
  palette and art, and switching to dark switches the tab. A tab set to Light ignores the switch.
- **Density:** Compact gives card padding 7, and the 27 base-size buttons and the boxes are 26 high. The Ribbon keeps
  its size. The setting is remembered in an isolated store, and switching back restores everything.
- Renders: `settings-midnight`, `settings-highcontrast`, `dashboard-midnight`, `dashboard-highcontrast`,
  `settings-compact`.

## Not done

- The ~240 smaller decorative colours outside the catalogue are still not themed: the glows, `BoxShadow` shorthands
  (which cannot bind to a resource) and a few fixed borders. Both new modes are built on Dark, which those values
  were tuned for.
- High contrast is MystTiq's own palette. It does not read Windows' "Contrast themes" colours.
- Per-accent art is still deferred.

# v0.8.0.0 — Artwork Refresh

## Why

The user updated the graphics in an older build: `MystTiqPalworldServer_v0.7.110.1_Complete_Windows.zip`, an
artwork patch made from the v0.7.110.0 source. They asked for it to be brought into the current version and
numbered 0.8.x. It also covers item 6 of the v0.7.115.0 deficiency report (navigation icons without distinct
silhouettes, and header art losing detail in the shallow crop), which had been deferred.

## What came in

From the patch's own `CHANGED_FILES_v0.7.110.1.txt` and `DELETED_FILES_v0.7.110.1.txt`:

- **26 navigation icons** replaced with distinct crystal-and-metal illustrations, one shape per page, with
  transparent backgrounds.
- **14 panoramic images**: a day and a night scene for each of the seven categories (Home, Server, World,
  Backups, Mods, Tools, System). Each category's day scene is a separately generated daytime picture, not a
  brightened night one.
- `Services/ArtworkCatalog.cs` (new):
  - maps every `NavigationPage` to a category, and throws for an unmapped page, so a future page cannot
    silently show nothing;
  - decodes each image once, backgrounds at 1600px and icons at 112px (twice their 56px display size);
  - provides an `IconArt` markup extension for the nav icons.
- `MainWindow.axaml`:
  - the page header shows the category's day/night art with a readability fade and a lighter accent wash;
  - the header gets its own layout column beside the Ribbon, so it can no longer cover the categories or
    commands in a narrow window;
  - the workspace backdrop and setup wizard use the themed art;
  - the nav icons load through `IconArt`.
- `MainWindowViewModel.cs`:
  - `PageArtwork` and `SetupArtwork` replace the four Home/World-only art booleans;
  - `IsLightMode` follows the applied theme when no profile is selected (the setup wizard).
- `DesignSystem.axaml` / `ThemeApplier.cs`: the `PageArtReadabilityGradient` brush, rebuilt per light/dark
  theme.
- **7 retired images removed**: the dashboard atmosphere image, the four old Home/World header JPGs, and two
  card-art PNGs. None is referenced any more.
- `scripts/Testing/MystTiq.ArtworkHarness` (new): an offline headless rendering harness with stand-in
  services and isolated stores, and no network access.
- `docs/artwork/`: preview page, generation prompts (`PROMPTS.json`), asset list, and the patch's own
  validation notes. The screenshots were replaced with renders of this merged build.

## How it was merged

The patch and this line both branched from v0.7.110.0, and this line had moved on through v0.7.115.0. So the
four edited files were **3-way merged**: base = our v0.7.110.0 checkpoint, theirs = the patch, ours = v0.7.115.0.
The patch's files used CRLF line endings, and ours LF. Normalising both to LF removed a whole-file false
conflict. After that the merge had **zero conflicts**. The images, the catalog and the harness were copied
as-is, and the seven retired images were removed.

Checked before and after merging:
- The code diff was read in full, about 100 lines.
- All 27 current `NavigationPage` values are mapped.
- Nothing references the retired images or the removed properties (two stale comments were updated).
- The v0.7.115.0 work in the same files survived. In particular, the Map page's separate label layers and
  dot-only marker buttons are intact, and were confirmed live after the merge.

## Two adjustments requested after the first look

- **The header artwork fills the whole card.** It had been drawn inside the card's `Padding="20,10"`, leaving a
  plain band between the picture and the card's rounded edge. The card now has no padding: the art, the
  readability fade and the accent wash fill it and are clipped to its 6px curve. Only the text layer keeps the
  20px inset. It is one shared header card, so this applies on every page.
  - While there, the title block was anchored to the card's bottom and the Auto refresh/Connected pill to its
    top right. A two-line subtitle (e.g. Server Setup's) was being cut off at the bottom edge. The subtitle is
    capped at two lines with an ellipsis.
- **Navigation icons are 10% smaller**: 50×50 instead of 56×56, with the icon column narrowed from 60 to 54
  to match, for all 26. They still decode at 112px, so they stay sharp.

Both were re-checked live (Home and Server Setup headers) and with the artwork harness (149/149, including
the 950×650 header/Ribbon layout and light mode). The `docs/artwork/screenshots` were re-rendered afterwards.

## Verification

- Desktop and full builds: 0 warnings / 0 errors.
- The patch's own artwork harness, **run against the merged code**, passed **149/149**:
  - every page has distinct day/night art that is reused;
  - the visible art is bound on seven representative pages in both modes;
  - profile switching restores the right mode;
  - at 950×650 the header covers neither the categories nor the Ribbon, and overflow still works;
  - the setup wizard keeps the theme;
  - all 26 icons are embedded and decoded at 112px.
- The gate now runs this harness as its v0.8.0.0 runtime check.
- Live Desktop on the Clone profile (Crimson accent): the Dashboard, World/Inspector and Map pages show the
  new icons and header art, and the Map labels are still correct.

## Not verified

- Anything beyond visuals. The patch changed no backend, and the backend is unchanged in this version.
- The patch's own notes say its art was made with an image-generation tool; the prompts are kept in
  `docs/artwork/PROMPTS.json` for provenance.

# v0.7.90.0 — Install With Extras (UE4SS)

## Direct live feedback

Following v0.7.89.0's own live feedback thread on the Install step, the user asked why UE4SS
Runtime and Palworld Save Tools aren't installed as part of "Install Palworld Dedicated Server."
Investigated the actual checklist data (`GET /server/environment`) and confirmed:

- **Palworld Save Tools** and **PIM/Oodle Decoder** are `actionSupported: false` with an explicit
  `"BACKEND REQUIRED"` reason — no install capability exists anywhere in the app today for either.
  Nothing to wire up without first building a real, separate backend feature.
- **UE4SS Runtime** does have a real install path, but it's a deliberate two-step
  Preview-then-Apply flow on its own page (pick a release, preview what it will do, confirm) — the
  same safety pattern already used for backups and world transactions, not a single click.

Response: "we should add that as part of the install, option to install just the server without
mods and then the option of installing it with the extras."

## Change

The wizard's Install step now offers two buttons instead of one:

- **"Install Palworld Dedicated Server"** — unchanged, server + SteamCMD only
  (`InstallPalworldServerFromWizardCommand`).
- **"Install with Extras (+ UE4SS)"** (new) — installs the server, then automatically installs the
  newest stable UE4SS release, then refreshes the environment checklist
  (`InstallPalworldServerWithExtrasCommand` → `InstallPalworldServerWithExtrasAsync`).

`InstallLatestUe4ssStableAsync` reuses the UE4SS page's own established
`RefreshUe4ssReleaseCatalogAsync`/`PreviewUe4ssInstallAsync`/`ApplyUe4ssInstallAsync` chain verbatim
— nothing new on the backend or in the release-resolution logic. It auto-selects
`SelectedUe4ssFork = "Palworld Fork"` (the existing default) and picks the newest non-prerelease
release by `PublishedAt` (falling back to the newest prerelease only if no stable release exists at
all), instead of asking the user to pick one from the catalog. This is an explicit, opt-in tradeoff:
choosing the "with extras" button means skipping the manual preview review that the UE4SS page's own
flow offers — the plain "Install Palworld Dedicated Server" button is unaffected and still leaves
UE4SS entirely untouched.

Palworld Save Tools and PIM/Oodle Decoder remain out of scope — still no backend capability to chain
into either button.

# v0.9.7.0 — Avalonia 12

The desktop moves from Avalonia 11.3 to 12.1.3. Dependabot's split pull requests (#15–#17, 2026-09-27) failed because
each bumped only half of the Avalonia packages; this version moves all four (Avalonia, Avalonia.Desktop,
Avalonia.Fonts.Inter, Avalonia.Themes.Fluent) and `Avalonia.Headless` in both harnesses together, pinned to 12.1.3.
Dependabot already groups the Avalonia packages (v0.8.26.0).

## What the new version needed

- **Clipboard.** `IClipboard.SetTextAsync` and `GetTextAsync` are now extension methods in `Avalonia.Input.Platform`,
  and reading is `TryGetTextAsync`. The window's code-behind (six copy buttons) and the remote sign-in harness (the
  X11 clipboard check) import that namespace.
- **Placeholders.** `TextBox.Watermark` is obsolete; the 62 text boxes use `PlaceholderText`. The text checker
  (`Update-MystTiqUiText.ps1`) already treated both as display text, the accessibility rule accepts either, and the
  ArtworkHarness reads `PlaceholderText`. The gate maps `PlaceholderText` back to `Watermark` before the contracts
  carried from earlier versions read the window, so they keep their meaning.
- **Window decorations.** `Window.SystemDecorations` is obsolete; the tray reminder toast and the harness's gallery
  window use `WindowDecorations`.
- **`NavigationPage`.** Avalonia 12 has its own `Avalonia.Controls.NavigationPage` control, which made the app's
  `MystTiq.Desktop.Models.NavigationPage` ambiguous in the two harnesses (the app itself never imports both); they
  alias the app's.

## Evidence

- The desktop builds on 12.1.3 with no new warnings (the two left are the old CA1416 notes in Core).
- The ArtworkHarness passes on Avalonia 12 (720 checks): every language has every key, no page shows an untranslated
  label, every control is named and reachable with Tab, templates round-trip, and layouts fit.
- Its page renders were compared with v0.9.6.0's (11.3). Full-size pages look the same (pixel differences are sub-pixel
  shifts in the background art). The 950×650 renders differ: under 11.3 the page ran past the window's right edge
  (no window buttons visible); under 12 it fits, and the ribbon folds into its "»" menu.
- Still to record: the real Linux desktop session on the test VM (window, maximize and restore, clipboard, tray), which
  needs the test user logged in to the VM's desktop.

# v0.7.79.0 — Server Doctor Compact, Color-Coded Checks

Direct live feedback against a Server Doctor screenshot: "these items listed should be compacted
and make use of the spacing a bit more. Perhaps Pass can be highlighted in green or red."

## Before

Each finding rendered as a full-width card: state text (plain bold, no color), component name, and
category on one line; Evidence on its own full-width line; Recommendation on another full-width
line below that, even when it was word-for-word identical to Evidence (a common case for a passing
check, e.g. both reading "Steam installation detected."). Recheck/Fix buttons sat top-aligned in a
separate column. Nothing distinguished PASS from FAIL/WARNING except the plain text itself.

## Changes

- **`DiagnosticFindingDto`** (`Models/DiagnosticFindingDtos.cs`) gained four computed properties:
  `IsPass`/`IsWarning`/`IsFail`/`IsOtherState` (mutually exclusive, derived from the existing `State`
  int) for binding the state badge's color, and `ShowRecommendation` — true only when
  `Recommendation` is non-empty and differs from `Evidence`, hiding the redundant second line seen
  on most passing checks.
- **Item template** (`MainWindow.axaml`, the `DiagnosticFindings` `ItemsControl`) restructured from
  a stacked-full-width layout into a 4-column `Grid` (`Auto,Auto,*,Auto`): a colored state badge,
  then Component/Category, then Evidence/Recommendation (vertically centered as a group instead of
  top-aligned), then the action buttons — all in one row instead of stacking. Reduced
  `Padding`/`Margin` further from v0.7.32.0's own compact pass. The state badge reuses the
  already-existing `Border.badge` pill style with an inline `Background` (green/amber/red/neutral),
  the same pattern already used for status pills elsewhere in this app (e.g. the Workshop item
  status badge on MOD Library).
- **Follow-up, same round**: "can we make the green a little darker or add a drop shadow to PASS to
  make it more readable?" — added a new `TextBlock.badgeText` style
  (`Styles/DesignSystem.axaml`) applying a subtle `DropShadowEffect` to the badge's own label text,
  rather than darkening the shared `GreenBrush` resource itself (used in many other places this
  feedback wasn't about).

## Verification

`dotnet build` on `MystTiq.Desktop` and the full solution — clean, 0 warnings/errors. Live-verified
against the real desktop app across two rounds: the compacted/color-coded layout, then the badge
text legibility fix. User's final sign-off: "Looks good, ship it."

# v1.1.0.0 — The new accepted baseline (internal)

Roadmap T-2 and owner decision D-12 (2026-10-12): after the backlog, a pass over the documentation, a release, and that
release as the accepted baseline in place of v1.0.0.0.

## The documentation pass

Every user and developer document was read against the code:

- **README:** the "Also new since 1.0" paragraphs (one per release, 20 of them) broke the documentation rule in
  `docs/README.md` (history belongs in the changelog). They became one "What's new in v1.1.0.0" by theme; the feature
  table gained what shipped (guarded save edits, the MOD browser, load order and profiles, anti-cheat and Discord
  commands, the browser view); the release history is grouped by series.
- **Site:** the milestones still said "CURRENT · v1.0.0.0" and "NEXT · v1.1: MOD browser" (shipped in v1.0.5.0).
- **Linux:** `docs/linux/README.md` still described the v0.3 plan ("starting/stopping PalServer … are later v0.3
  phases"). It now describes the ways to run the service (systemd, per-user unit, `service-run`, Docker), remote access
  and what is still open (E-4); the v0.3 text is in `docs/history/LINUX_DEVELOPMENT_v0.3.md`.
  `TESTED_ENVIRONMENT.md` has today's reference and the 24-hour result; `COMMAND_REFERENCE.md` lists `service-unit`
  (every listed command exists in `Program.cs`).
- **Roadmap:** "current and accepted baseline v1.0.0.0, the v1.1 MOD browser" in `docs/roadmap/README.md`; Q-10's 24-hour
  runs recorded; D-12; T-2.
- **Publishing guide:** `Build.ps1 Release` runs the gate with `-RunBuild`, now about an hour, not 50 minutes.
- Checked and correct: every file and build target the README, CONTRIBUTING and the publishing guide name exists.

## The 24-hour runs (Q-10)

Collected 2026-10-13 from the v1.0.7.5 runs:
- **Windows** (isolated `api-run` with the stand-in PalServer): 24 h, 49 samples; memory +1.5 MB (trend 2.3 MB a day),
  handles −4, threads −1; 16,600 status requests, none failed; stop in 1.9 s, exit 0, nothing left holding files.
- **Linux** (per-user systemd unit on the VM): 23.5 h, 48 samples; memory +3 MB (6.2 MB a day), handles −2, threads
  −1; 16,736 status requests, none failed; a clean stop.

## The baseline

v1.1.0.0 is the code of v1.0.9.3 with this documentation. From v1.1.0.1 on, the documentation checks name v1.1.0.0 as
the accepted baseline; the frozen-gate regression keeps running the previous version's checkpoint.

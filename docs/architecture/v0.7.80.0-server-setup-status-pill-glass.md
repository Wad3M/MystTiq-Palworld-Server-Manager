# v0.7.80.0 — Server Setup Status Pill Centering & Glass Gradient

Direct live feedback against a Server Setup screenshot: "the Ready should be in the middle of the
green. can we also add a gradient glassy effect."

## Root cause

The per-row STATUS pill (`MainWindow.axaml`, the `EnvironmentItems` `ItemsControl` inside the
Server Setup page's environment table) rendered as three overlapping `Border` elements (green
Ready / amber Disabled / red Missing) inside a `Grid Grid.Column="2"`, each with a `TextBlock`
already carrying `HorizontalAlignment="Center"`. Neither the `Border` nor its containing `Grid` cell
had an explicit alignment set, so their actual rendered width was left to default layout behavior
rather than being guaranteed to fill and center within the STATUS column — visually the text sat
off-center inside a badge that wasn't reliably sized to its cell.

## Fix

- Made both the fill and the centering explicit rather than relying on defaults: each status
  `Border` now has `HorizontalAlignment="Stretch"`, and its `TextBlock` has `HorizontalAlignment`,
  `VerticalAlignment`, and `TextAlignment` all set to `Center`.
- Replaced the flat `DynamicResource GreenBrush`/`AmberBrush`/`RedBrush` fills with this app's
  existing glass-gradient family — `SuccessGlassGradient` and `DangerGlassGradient` already existed
  (used elsewhere for ribbon-style success/danger buttons); a new `WarningGlassGradient` was added
  to `Styles/DesignSystem.axaml` following the exact same alpha-stop structure, amber-tinted, since
  no amber glass variant existed yet. Each pill also gained a thin matching accent border
  (`GreenAccentBorderBrush`/`AmberAccentBorderBrush`/`RedAccentBorderBrush`, already
  theme-generated resources) for definition against the glass background.

## Verification

`dotnet build` on `MystTiq.Desktop` and the full solution — clean, 0 warnings/errors, first try (no
AVLN1001 `--`-in-comment issue this round). Live-verified against the real desktop app: status
pills now center their text and show the glassy gradient look. User's sign-off: "Looks good, ship
it."

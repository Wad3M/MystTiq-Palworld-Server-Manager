# v0.8.1.0 — Ribbon Icons

## Why

The user supplied new Ribbon icons (`MystTiq_Palworld_Ribbon_Icons.zip`) and asked for them as v0.8.1.0. The
package has ten original single-colour vector icons for the main Ribbon actions, on a 24×24 grid with 1.8-unit
rounded strokes. Each is supplied as an SVG, as JSON path data with dark/light colours, and as Avalonia
geometries, together with a preview page, preview images and a README. Motifs:
- capture spheres for the lifecycle commands;
- a storage chest for Backup, a Palbox-style terminal for Console, Pal ears with a cross for Doctor;
- a shield for Verify Files, a workbench for Install Missing;
- a conventional red octagon for Force Stop.

## How it is wired

- `Services/RibbonIcons.cs` holds the ten path strings exactly as supplied, parsed once to `StreamGeometry` and
  cached. A gate contract compares every path against the package's own `icons.json`, so they cannot drift.
- `RibbonActionViewModel` gains `VectorIconKey`, `VectorIcon` and `HasVectorIcon`. A button gets a vector icon
  when:
  - its label is one of the ten the icons were drawn for (Refresh, Start, Restart, Stop, Backup, Console, Doctor,
    Verify Files, Install Missing, Force Stop); or
  - it shares one of those actions' existing glyphs: every "Refresh …" button uses ↻ and "Restart Server" uses
    ⟳. Without this the Ribbon would show the new Refresh icon next to an old ↻ on the same page.

  Every other button (Export, Validate, Kill Processes, …) keeps its text glyph.
- In the Ribbon button template, the icon tile shows either a `Path.ribbonIcon` (the vector) or the old glyph
  TextBlock. It uses the same `amber/green/blue/red/cyan` classes, so colours still come from the theme
  (`AmberBrush` etc.) and follow dark/light and the per-tab accent. The ten target buttons already used the
  colours the package assigns them.
- `Path.ribbonIcon` follows the package README: 24 DIP, `Stretch=Uniform`, `StrokeThickness 1.8`, round caps
  and joins, and `Fill` left unset. The disabled state is still the whole button's opacity, so colour never
  signals availability on its own.
- The package's SVGs, `icons.json`, `PalRibbonIcons.axaml`, preview and README are kept under
  `docs/ribbon-icons/`.

## Verification

- Desktop builds clean.
- Artwork harness, now 191 checks. The 42 new ones cover:
  - every icon parses once, is reused, and stays inside its 24×24 grid;
  - the label/glyph mapping for all ten, the two followers, and three buttons that must keep their glyph;
  - the Dashboard Ribbon, rendered dark and light, draws 8 stroked vector icons (with a stroke, no fill,
    1.8 thick), and none of the replaced glyphs remains visible.
- Live Desktop on the Clone profile: the Home and Server Ribbons show all ten icons, including Verify Files and
  Install Missing in Server's Environment group, in the tab's theme colours.

# v0.7.32.0 — Visual Density Pass

## Goal

Eighth version in the GUI/workflow/UX overhaul roadmap. Items 1, 16, 18, 36, 41, and 54 from the roadmap's findings log — larger nav-pane icons plus a compact-card pass across Server Setup, Backups, MOD Library, and Server Doctor.

Note: item 13 (Dashboard layout/density, compared against the v0.2.16.4 reference) was found during this version's implementation to have been grounded in the findings log but never actually assigned a version in the approved roadmap — an oversight in the roadmap itself, not something dropped from this version's scope. It's been appended as v0.7.46.0 rather than folded in here, to keep this version's scope matching what was actually approved.

## What shipped

### Larger nav-pane icons (item 1)

All 25 nav destinations in `MainWindow.axaml` shared the identical literal pattern `<Grid ColumnDefinitions="24,*" ColumnSpacing="8"><Image Source="/Assets/Icons/...` and `Width="20" Height="20" Stretch="Uniform"/><TextBlock Grid.Column="1" Text="...`, so both were fixed with two `replace_all` edits rather than touching each entry individually: the icon column widened from 24px to 32px (with `ColumnSpacing` 8→10), and the image itself from 20×20 to 28×28. A third occurrence of the 20×20 pattern (the "+" add-tab button's `IconAddTab` `Path`) was confirmed to use a different surrounding literal and was correctly left untouched — verified by checking the post-edit occurrence count (25, not 26).

### Compact cards (items 16, 18, 36, 54)

Server Setup's 4 summary cards, Backups' 4 summary cards, and Server Doctor's per-check finding cards all got the same kind of treatment, adapted to what actually drives their height:

- **Server Setup / Backups summary cards**: these have no base `.statuscard`-only style (`Border.statuscard.accentX` combinators only set `BorderBrush`/`BoxShadow` — confirmed by grep across `DesignSystem.axaml`), so there was no shared Padding/FontSize to shrink at the style level. The real driver of their height was the full-sentence description text wrapping to 2-3 lines inside a narrow 1-of-4 column. Fixed by adding explicit tight `Padding="8,5"`, reducing the big-number `FontSize` (18/22 → 15/16), the label `FontSize` (→10), and — the change that actually reduces wrap-driven height — shortening the description sentences ("Steam, PalServer, storage, runtime and service evidence" → "Steam, storage, runtime", etc.).
- **Server Setup's READY card**: its count `TextBlock` gained `HorizontalAlignment="Center"` (and the whole card's `StackPanel`), matching the reference's centered badge.
- **Server Doctor's finding cards** (`Classes="card accentTools"`, one per diagnostic check): these *do* inherit the base `.card` style's `Padding="11"`, so an explicit `Padding="8,6"` override plus reduced `Margin` (10px → 6px between cards), reduced inner `Spacing` (6px → 3px), and reduced `FontSize` on `Component`/`Evidence`/`Recommendation` all combine to fit more checks per screen.

### MOD Library's duplicate cards removed (item 41)

The 6 summary cards (HEALTH/INSTALLED/CONFIRMED/UNVERIFIED/DISABLED/ISSUES) were a single shared `Grid`, gated by `IsModInventoryPage` (`SelectedPage is NavigationPage.ModDashboard or NavigationPage.ModLibrary`) — meaning both pages showed the identical cards from one XAML block, not two separate copies. Changing the gate to `IsModDashboardPage` only removes them from MOD Library while MOD Dashboard keeps them, with zero duplication of markup.

### Fixed along the way: "Verify Files" was never actually removed from its old location

While touching Server Setup's summary-card `Grid` for the density pass, found that v0.7.26.0's changelog claimed "Verify Files" moved into the ribbon and the original button was removed — but the original `Button Content="✓  Verify Files" Classes="success" Command="{Binding VerifyEnvironmentCommand}"` was still embedded in the ENVIRONMENT HEALTH card. v0.7.26.0 had added the ribbon copy but never actually deleted the original. Removed now, while the card was already being edited for density.

## Explicit non-goals

- No change to the `.card`/`.statuscard` shared styles themselves — all changes are explicit per-instance overrides, so nothing on Dashboard or any other page using these classes is affected.
- No change to Dashboard density (item 13) — see the note above; that's now its own version, v0.7.46.0.

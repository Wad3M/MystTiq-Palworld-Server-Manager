# v1.0.8.5 — The Backups and Save Tools Pages (internal)

Roadmap C-5, with the mover from C-2.

## BackupsViewModel (`vm.Backups`)

**What moved:**
- the archive list and its summary cards;
- create, delete and restore;
- verify one backup, or all of them with the scan's progress and cancel;
- retention (preview and apply);
- opening the backup folder;
- the save-folder access card (the former `MainWindowViewModel.SaveAccess.cs`);
- the Save Tools page: diagnostics, self-test, the save files and export.

**What stays with the window:**
- **Backup All**, a fleet action that runs over every server.
- **`RestoreTabSessionAsync`**, which is tab coordination.
- **The Workshop scan**, which belongs to the MOD pages (C-6).

## Found while moving

**A wrong reflection target.** The ArtworkHarness looked up `ApplyBackupScan` by name. The mover changed the type in
the lookup to `BackupsViewModel`, but the calls still passed the window, so they would have failed when run. The three
calls now pass `vm.Backups`. Lesson: after each move, check that every `typeof(NewPage)` lookup in the harnesses passes
the matching object.

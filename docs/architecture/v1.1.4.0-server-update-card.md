# v1.1.4.0 — Server update card (internal)

Roadmap U-1 (owner, 2026-10-19, with a screenshot marking the right end of the LIFECYCLE bar), F-21 and F-22 (found
2026-10-20).

## U-1: the card and its update

- `HeadlessServerUpdateFlowService` (HeadlessHost), one per server profile. `GetCardAsync` returns the Palworld row of
  the Update Center (`HeadlessComponentUpdateService.GetPalworldServerVersionAsync`: the installed build from the app
  manifest, Steam's public build from SteamCMD app info, kept 15 minutes) and the running or last job. `Begin` starts
  one job in `BackgroundWork` with the service's stopping token only (half-updated server files are worse than a long
  update); a second `Begin` while one runs returns the running one.
- The job: read the status; if running, take the coordinator's `lifecycle` lock and stop with
  `ServerStopReason.Begin("Server update")`; a safety backup (`BackupClass.Safety`); `HeadlessServerDistributionService
  .UpdateAsync(validate: false)` (it takes its own lock, refuses a running server, and retries with a full check when
  Steam refuses the manifest); start again under the lock with the pre-start MOD diagnostics. A failed step ends the job,
  starts the server again if it ran, records a warning and raises a pinned notification.
- Routes: `GET /server/update` (the card), `GET /server/update/job` (204 when none ran), `POST /server/update` (Admin;
  202 with the job, or 409 with the running one).
- Desktop: `MainWindowViewModel.ServerUpdate.cs`. The card checks on connect (forced) and from the status poll every 15
  minutes, and reads the job each poll while it runs. `ServerUpdateState` is the English tag text (StatusTags);
  `ServerUpdateLineText` is the build or the job's step. The window's confirmation (`ConfirmOperationDialog`) lists the
  builds, what happens to a running server and its players, and the safety backup.
- Layout: the LIFECYCLE bar spans the first three of the cards' four columns; the card is the fourth (title, tag and
  build, button). At 950 px a long tag ends in "…" with its full text as the tooltip (Italian); the ArtworkHarness
  checks the title on one line, the build whole and everything inside the card in 12 languages at 950, 1100 and 1440 px.

## F-21: the wrong-path warning

`FindProcessesWithMismatchedPath` reported every PalServer not under this profile's root, so on a computer with several
servers each stopped one reported a running one. `ForeignServerProcess.StartedByMystTiq` walks up to four parents
(past the PalServer.exe launcher) and a process started by `mysttiq-server` is excluded. `WindowsServerSessionInspector`
now fills `ParentProcessId` (`NtQueryInformationProcess` with limited query rights); it was always 0 before.

## F-22: an interrupted stop is logged

`PolicyApplyingLifecycle.StopAsync` called `StopRecorded` only after the stop returned, so a stop that ended in an
exception (an API request cancelled after a second, seen live on 2026-10-20) left no line. `StopInterrupted` records
"Server stop interrupted: <reason>" and the exception still reaches the caller.

# v0.9.0.0 — The window in 12 languages

## Why

Since v0.8.5.0 the Desktop could switch language live (`Services/Localizer.cs`: flat `Assets/i18n/<code>.json` files,
English as the reference and the fallback, `{services:Tr key}` bindings in XAML), but only the category tabs,
navigation, page headers, Ribbon and Dashboard labels used it, in German and Spanish. Everything else in the window was
English written straight into the XAML. The user asked for the list of English words and phrases that change with the
language, and for the most widely used languages.

## The list and the tool

`scripts/Update-MystTiqUiText.ps1` is the one place that knows where the window's text is:

- `-Inventory` writes `docs/i18n/UI_TEXT_INVENTORY.md` (counts) and `.csv` (every text, its key, file and line). It
  covers the XAML (MainWindow, App's tray menu, the dialogs in `Views`), the texts already keyed in `en.json`, and the
  code's user-facing string literals (status and error messages, with interpolated values shown as `{0}`), which are
  listed but not yet translatable.
- `-ConvertXaml` gives each distinct hard-coded XAML display text (the attributes `Text`, `Content`, `Header`,
  `Watermark`, `PlaceholderText`, `ToolTip.Tip`, `ToolTipText`, `Title` and the accessible names, outside comments, with a
  letter in them) a key `ui.<words of the text>` (long texts get a short hash suffix), writes it to `en.json`, and puts
  `{services:Tr ui.…}` in its place. The same English text shares one key. XML entities are decoded first. It added
  `xmlns:services` to the files that lacked it.
- `-Check` lists any hard-coded XAML text left and exits 1; the release gate runs it, so a new literal cannot slip in.

Result: 932 places, 785 new keys; `en.json` has 998 texts.

## The languages

Chosen by use on PCs and among Palworld players (Steam's language share, and the languages the game itself ships):
English, 简体中文 (`zh-Hans`), Español (`es`), Português (Brasil) (`pt-BR`), Русский (`ru`), Deutsch (`de`),
Français (`fr`), 日本語 (`ja`), 한국어 (`ko`), Italiano (`it`), Polski (`pl`), Türkçe (`tr`). Each file has every key
English has (the gate checks). German and Spanish keep their reviewed v0.8.x wording; everything else is a first draft
awaiting native review, and the Settings note says so. Product and technical names stay as they are (MystTiq, Palworld,
PalServer, PalDefender, RCON, REST API, UE4SS, SteamCMD, file names, commands), and so do `{0}` placeholders, arrows and
example values.

## Fonts

Inter and Segoe UI have no Chinese, Japanese or Korean glyphs. The styles now read three resources
(`UiFontFamily`, `UiDisplayFontFamily`, `UiDisplayTextFontFamily`, English defaults in `App.axaml`) and `Localizer`
sets them on every language change: Inter (or Bahnschrift for display text) first, then that language's own system
font (Microsoft YaHei UI / Yu Gothic UI, Meiryo / Malgun Gothic on Windows; Noto Sans CJK SC/JP/KR or WenQuanYi on
Linux). Naming the language's font, rather than relying on "any font with this character", keeps Japanese from being
drawn with Chinese glyph shapes (they share code points).

## The title bar (the user, 2026-09-27)

The Notifications button was a grey dot; it is a bell, drawn as a vector like the other title-bar icons (fonts with
icon glyphs are missing on Linux). A language picker sits right of Settings; it binds the same `SelectedUiLanguage` as
the Settings page, so both always agree and the choice is remembered.

## Checks

The ArtworkHarness renders offline in every language: the category tabs fit at 950x650, no Ribbon button is cut off on
any page at 950x650 or 1440x880, no Dashboard label is split mid-word or cut off at 950x650, no page shows an English
`ui.*` text whose translation differs, the title-bar picker lists 12 languages and switches the window, and Japanese
gets a Japanese font. It found one real problem: French "SAUVEGARDE" as the Dashboard's backup card title did not fit
at 950x650; French uses "BACKUP" there.

## Not in this version

Text written in code (status values, dialogs' messages, validation and error messages; about 980 texts) is v0.9.1.0,
translated as it is shown on screen so the app's own logic keeps comparing English values. The service's messages
follow. Native review of the drafts is v0.9.2.0.

and `_batch_3.zip`. Batch 3 arrived first. Batches 1 and 2 arrived while this version's gate was running, so the gate
was stopped and all three shipped together in this one version.

## Design

- **Art embedded unchanged.** The files live under `src/MystTiq.Desktop/Assets/RibbonIcons/`. A gate contract checks
  every file against its recorded hash.
- **Images are a second kind of Ribbon icon.** `RibbonIcons.ImageKeyFor(label)` matches the exact English label.
  Since v0.8.6.0 that label is the button's identity whatever the display language, so the icons work in German and
  Spanish too. `Image(key)` decodes each file once, at 96 px, and caches it. 96 px is enough for a sharp 34 px tile on
  high-DPI screens.
- **Precedence.** A button shows its image if it has one, otherwise a vector icon, otherwise its text glyph
  (`ShowGlyph`). One consequence: Discover Saves borrowed the Refresh vector through the shared "↻" glyph, and now
  shows its own image. Every other "Refresh …" button keeps the Refresh vector.
- **Display.** The image fills the 34×34 icon tile, whose rounded, clipped corners frame it. Disabled buttons still
  dim as a whole.

## Look

- **Dark theme.** The tiles sit naturally.
- **Light theme.** Each shows as a dark square on a light button, because the background is part of the supplied art.
- **Two styles.** The Ribbon now mixes the first ten single-colour line icons, which take the theme colour, with these
  thirty full-colour illustrations.

Both effects come from the art as supplied. Transparent-background versions would drop in without any code change.

  - each of the 30 labels maps to its image, and the remaining glyph and vector buttons keep theirs;

- **Gate contracts.** Hashes match the record, the mapping covers all 30, the precedence holds, and the tile binding

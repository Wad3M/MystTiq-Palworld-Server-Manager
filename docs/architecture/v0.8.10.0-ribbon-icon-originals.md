# v0.8.10.0 — Ribbon Icon Originals

The user sent three new icon packages during the automated run:
- `palworld_ribbon_icons_batch_1_originals.zip`
- `palworld_ribbon_icons_batch_2_originals.zip`
- `palworld_ribbon_icons_batch_3_originals.zip`

The instruction was "all of the ribbon icons should be updated with the new icons. Please let me know which icons are
missing." This version applies them. Pal positions on the map, the next item of the run, moves to v0.8.11.0.

## What the packages hold

- The same thirty file names as batches 1–3 (v0.8.8.0), one per Ribbon button that already had an image.
- Each file is a 1254x1254 24-bit PNG of about 1–1.6 MB, 45 MB in total.
- Each is the full framed tile, with its glowing border and dark background. The v0.8.8.0 files were tighter crops.
- Nine batch 3 tiles are new designs, not just recrops:
  - detect instances, discover saves, export CSV, mark all read, refresh bases;
  - repair firewall, run diagnostics, self-test, self-tests.

  A 64 px comparison of every pair differs by 43–78 levels per channel on average. A review sheet was made to confirm
  it by eye.
- No image was supplied for any button that did not already have one.

## What changed

- **Files.** Each original was resized to 512x512 with Pillow (Lanczos) and saved as lossless, optimised 24-bit PNG.
  The results replace the 30 files in `src/MystTiq.Desktop/Assets/RibbonIcons/`.
  - The artwork is not otherwise changed.
  - 512 px is the size the app already shipped and more than the 96 px it decodes. It keeps the bundle at 8 MB instead
    of 45 MB. A first attempt with System.Drawing produced 12.6 MB and was replaced.
- **Record.** `docs/ribbon-icons/images/README.md` gives each file's "Shipped SHA-256", which the gate checks, and
  "Original SHA-256", which identifies the supplied file.
- **Two shared images** in `RibbonIcons`:
  - Quick Actions' **Backup** runs the same command as Backups' **Create** (`CreateBackupCommand`), so it uses
    `create_backup`.
  - Quick Actions' **Doctor** opens the Server Doctor page, so it uses `run_doctor`.

  These two appear on every page. `ImageKeys` now lists each file once, and the new `ImageLabels` lists the 32 labels.

# v0.8.7.0 — The Dashboard in Every Language

The third slice of display language support (after v0.8.5.0 and v0.8.6.0). Every fixed label, button and tooltip on
the Dashboard is now translated into German and Spanish, and so are its number templates. The pass also fixed a
minimum-size layout bug in English.

## Design

- **Fixed text.** The 37 labels, buttons and tooltips use `{services:Tr dashboard.*}`.
- **Number templates.** These were `StringFormat='Stored: {0}'`, and XAML cannot bind a StringFormat template. They
  now use the new `{services:TrFormat key, Path=Property}`: a `MultiBinding` of the translated template plus the
  value, so both can change live. A template that does not parse (a translation that lost or mangled `{0}`) shows the
  value alone instead of throwing.
  - `TrFormatExtension.Fill` is the pure part.
  - The gate and the harness both check that every translation keeps each template's `{0}`.
- **English** reads exactly as before: templates render as `Stored: 36 MB` and `5 known player(s)`, as they did.
- **Not translated in this slice:** the Dashboard's *values* ("Stopped / Not ready", "No active session",
  "Waiting for a server sample" and so on). These are built in many places in the view model and on the server.
  Translating them is a separate, larger slice. The Settings language note now says the Dashboard's labels are
  translated.
- **Translation files:** 208 keys each.

## Minimum window size (950×650)

Rendering German at the minimum size showed labels split mid-word ("MOD-PLATTFOR M", "SPEICH ER",
"Gespeicher t:") or clipped ("SPIELER IN DIESER SITZ…"). English had the same problem already: "MEMORY" split as
"MEMO RY".

- **Layout.** The CPU/MEMORY card's columns were fixed proportions (`0.8*,1.15*,1.05*`). The label columns now size
  to their text (`Auto,Auto,*`), and the bars take the rest. This fixes "MEMO RY" in English too.
- **Wording.** German and Spanish use shorter words where space is narrow:
  - German and Spanish: `MODS`, `Größe: {0}` / `Tamaño: {0}`.
  - German: `SPIELER (SITZUNG)`, `SPEICHERSTAND`.
  - Spanish: `JUGADORES (SESIÓN)`, `ÚLTIMO GUARDADO`, `SESIÓN`.
- **Check.** A new harness check renders the Dashboard at 950×650 in all three languages. It fails if any
  translated label is split mid-word or cut off. It was confirmed to fail on the old English layout (`[MEMORY]`) and
  passes now.

## Verification

- **ArtworkHarness (262 checks).** New checks:
  - the template filler, including broken and missing templates;
  - `{0}` is kept in every German and Spanish template;
  - English Dashboard text is identical to before, templates included;
  - German switches live, with labels, filled templates and all five OPEN buttons as ÖFFNEN;
  - English is restored after switching back;
  - no label is split or cut off at 950×650 in English, German or Spanish.
- **Gate contracts.** Confirm that:
  - the Dashboard has no fixed English text or StringFormat left;
  - every `Tr` and `TrFormat` key exists in English;
  - placeholders are kept;
  - English spot checks match;
  - the CPU/MEMORY layout is fixed.

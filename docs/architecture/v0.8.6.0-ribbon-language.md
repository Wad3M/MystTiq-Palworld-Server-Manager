# v0.8.6.0 — The Ribbon in Every Language

This is the second slice of the display language work begun in v0.8.5.0. It translates all 50 Ribbon button labels
and all 26 Ribbon group titles into German and Spanish, and fixes a Ribbon layout bug the new checks found in
English.

## Design

- **Identity and display are separate.** `RibbonActionViewModel.Label` and `RibbonGroupViewModel.Title` stay English.
  `RibbonIcons.KeyFor(Label, Glyph)` matches the user's vector icons by that English label, so it must not change.
  The shown text is the new `DisplayLabel` / `DisplayTitle`, which default to the English text.
- **Translated when built.** `RebuildRibbonGroups` runs `LocalizeRibbon`, which looks up `ribbon.<Label>` and
  `ribbon.group.<Title>` (letters and digits only, e.g. `ribbon.VerifyScan`). The Ribbon is rebuilt on every
  language change.
- **Every place that shows the text uses it.** That covers the Ribbon buttons, the group titles underneath them, and
  the overflow ("»") menu.
- **Not translated yet:** the accessible names (`AutomationName`) stay English.
- **English is unchanged.** `en.json` holds each label and title exactly as written in the code, and a gate contract
  compares every one found in `BuildRibbonGroupsForActivePage` against it. The Settings language note now mentions
  the Ribbon, and the translations have 165 keys each.

## The layout fix

`EstimateRibbonGroupWidth` decides which groups fit and which go to the overflow menu. It counted every button as the
68 px minimum, but a button grows with its label. A new harness check asks whether any shown Ribbon button ends past
the start of the page header. With the old estimate, that check failed in **English**, on the **UE4SS** and
**Doctor** pages at 1440 px wide. Their long labels ("Preview Install", "Confirm Install", "Detect Instances") pushed
the last buttons under the header, where they were cut off.

The estimate now takes the wider of the 68 px minimum and the label's length (about 7.2 px per character plus
padding), plus the group title. The same check passes on every page in all three languages at both sizes.

## Verification

ArtworkHarness, 248 checks. The new ones:
- For each of English, German and Spanish, and at 950×650 and 1440×880, every page is visited. On each page:
  - every Ribbon group title and button shows real text, not a raw key;
  - in English, that text is identical to the English identity;
  - every shown Ribbon button ends before the page header.
- The German Dashboard Ribbon shows German buttons and group titles, and all 8 vector icons still appear.

The layout check was confirmed to fail on the old estimate and pass on the new one.

Gate contracts:
- the English identity and the separate display text;
- the Ribbon is rebuilt on a language change;
- all display points use the translated text;
- the text-based estimate;
- English key parity for all 50 labels and 26 titles.

## Not done yet

- Page content, dialogs and messages are still English.
- Accessible names are still English.
- No native-speaker review of the translations.
- No CJK languages yet.

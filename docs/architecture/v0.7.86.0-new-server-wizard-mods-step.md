# v0.7.86.0 — New Server Wizard: MODs Step

## Context

The last remaining item scoped out of v0.7.81.0's original wizard rework Phase 2: "embed the
existing MOD Library Workshop-scan machinery as a wizard step, letting the user pick MODs to import
before finishing setup — same commands, new step placement, no new backend."

## Changes

- **New MODs step (7 of 8)**, install-wizard only, New World/Import paths only (Clone already
  carries over whatever MODs the source server had, copied as part of the clone itself). Reuses the
  exact same Workshop-scan commands already built for the MOD Library page —
  `ScanWorkshopModsCommand`/`WorkshopItems`/`SelectedWorkshopItem`/`ImportSelectedWorkshopModCommand`
  — verbatim, same `ListBox` template. Both commands already correctly resolved
  `BuildProfileFromEditor(SelectedProfile?.Id)` rather than requiring `SelectedProfile` directly, so
  (unlike a couple of other reused commands found earlier this session) no wizard-usability bug
  needed fixing here.
- Entirely optional: "Next" advances to Confirm whether or not anything was imported. Users can
  always add more MODs later from MOD Library, exactly as before this version.
- **Confirm & Finish renumbered from step 7 to step 8** (MODs now sits between Install and Confirm
  for the New World/Import paths); Clone's own jump-to-confirm and the existing
  "server turned out to already be running" short-circuit were both updated to the new step number.
  Connect's own step numbers are untouched, as with every prior renumbering this session.

## Verification

`dotnet build` on `MystTiq.Desktop` and the full solution — clean, 0 warnings/errors. The reused
Workshop-scan commands are already proven on the live MOD Library page; this version only changes
where they're also reachable from, not their own logic.

# Ribbon image icons (batches 1-3)

The user supplied these on 2026-09-24 as `palworld_ribbon_icons_batch_1.zip`, `_batch_2.zip` and `_batch_3.zip`. There
are thirty full-colour illustrated tiles, and each tile has its own dark framed background. They are shown in the
Ribbon icon tile (34x34, decoded at 96 px) for the button whose exact English label is listed. See
`docs/architecture/v0.8.8.0-ribbon-image-icons.md`.

**v0.8.10.0: the originals.** The user then sent `palworld_ribbon_icons_batch_1_originals.zip`, `_2_originals.zip` and
`_3_originals.zip`.
- They hold the same thirty file names as full 1254x1254 framed tiles. The first set were tighter crops.
- Nine batch 3 tiles are new designs: detect instances, discover saves, export CSV, mark all read, refresh bases,
  repair firewall, run diagnostics, self-test and self-tests.
- Each original was resized to 512x512 (Lanczos, lossless PNG, 24-bit RGB as supplied) and embedded under
  `src/MystTiq.Desktop/Assets/RibbonIcons/`. Their artwork is not otherwise changed.
- The release gate checks every shipped file against its "Shipped SHA-256". "Original SHA-256" identifies the
  supplied file. See `docs/architecture/v0.8.10.0-ribbon-icon-originals.md`.

**v0.8.13.0: batch 4.** `palworld_missing_10_icons.zip` holds the last ten, as 1254x1254 framed tiles in the same style. They were
resized the same way (512x512, Lanczos, lossless). With them every one of the 50 Ribbon labels has an image: 40 files, since
the Refresh variants, Restart Server, Backup and Doctor share one.

## Scope and remaining checks

This is artwork and layout validation using the actual desktop XAML with offline service substitutes, not live-server acceptance. No PalServer process was started or modified. Native Windows GPU/DPI interaction, Linux rendering, installer upgrade and live integrations remain untested. Known backend/map findings from the prior audit remain outside this patch.

The original logo/wordmark, functional game maps and compact command glyphs are retained. Light backgrounds are separate daytime artwork; navigation icons intentionally share transparent, high-contrast masters between modes. Categories share their scene across their child pages.

## Reproduce

From the source root with .NET 10 SDK and package access:

```powershell
dotnet build src/MystTiq.Desktop/MystTiq.Desktop.csproj -c Release
dotnet run --project scripts/Testing/MystTiq.ArtworkHarness -c Release -- ./artwork-render-checks
./scripts/Build-ConsoleProxy.ps1 -ProjectRoot .
./Build.ps1 -Action DesktopWindows -NoGuiLaunch
```

The harness uses offline API/discovery/bootstrap/Nexus substitutes and in-memory connection profiles. Test-specific credentials/session paths are isolated under its output directory. Source build commands require NuGet access or a populated cache.

# MystTiq Button & Action-Grid Standard — v0.2.16.2

> **Archived document.** This file describes a historical implementation phase and is retained for traceability. See the root README and current architecture docs for present behavior.

## Common characteristics
All normal MystTiq action buttons inherit the established common template and tooltip behavior. Semantic variants change intent/color, not interaction geometry.

Approximate density change: 10% smaller than the v0.2.16.1 button footprint.

## Semantic intent
- Success: positive/start/create/enable
- Warning: caution/restart/disable/restore
- Danger: destructive/stop/delete/force
- Info: neutral information/navigation
- Diagnostic: repair/doctor/diagnostic
- Refresh: refresh/verify/scan
- Secondary/Neutral: supporting actions

## Alignment
Button-only action bars use equal-cell `UniformGrid` layouts when the actions form one logical row. This prevents inconsistent widths and improves alignment across pages.

Special-purpose icon/row controls retain dedicated compact variants but still follow the same interaction and tooltip standards.

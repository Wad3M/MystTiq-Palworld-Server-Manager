# Application Update Awareness — v0.2.16.3

> **Archived document.** This file describes a historical implementation phase and is retained for traceability. See the root README and current architecture docs for present behavior.

## Release source
Repository: `Wad3M/MystTiq-Palworld-Server-Manager`

Endpoint:
`GET /repos/Wad3M/MystTiq-Palworld-Server-Manager/releases/latest`

The endpoint represents the latest published full release. Drafts and prereleases are not used as the normal update channel.

## Version semantics
Tags may be formatted as `0.2.15.17` or `v0.2.15.17`. MystTiq extracts the numeric version and compares `System.Version` values component-by-component.

Examples:
- 0.2.16.10 > 0.2.16.9
- 0.2.15.17 = v0.2.15.17
- development build 0.2.16.3 > public release 0.2.15.17

## Safety
The checker is informational. It does not silently download or execute application updates. Update Center can open the official repository Releases page for administrator review.

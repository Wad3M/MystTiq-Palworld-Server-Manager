# Live Save Read Safety — v0.2.16.2

> **Archived document.** This file describes a historical implementation phase and is retained for traceability. See the root README and current architecture docs for present behavior.

## Problem
PalServer can briefly hold, write, or atomically replace `Level.sav`. A direct `File.OpenRead` from World Inspector can therefore fail with a Windows sharing violation.

## Read-only flow

World Inspector
→ SafeWorldSaveSnapshotService
→ shared read (`ReadWrite | Delete`)
→ temporary snapshot
→ source length/write-time stability check
→ Plm1SaveDecoder on snapshot
→ temporary snapshot cleanup

The active save is never modified.

## Failure behavior
Transient sharing/write contention is retried. If a stable snapshot cannot be obtained, the Inspector reports a recoverable status message instead of displaying a blocking modal sharing-violation dialog.

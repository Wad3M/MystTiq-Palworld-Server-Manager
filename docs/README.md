# MystTiq Documentation

This directory contains current architecture/reference documentation and archived implementation history.

## Current documentation

- [`architecture/`](architecture/) — current architecture and platform-completion documents
- [`release/`](release/) — publication/release-process documents
- [`history/`](history/) — historical version-specific architecture and feature notes
- [`index.html`](index.html) — public GitHub Pages landing page
- [`images/`](images/) — README/public documentation screenshots
- [`assets/`](assets/) — GitHub Pages assets

## Repository-level documents

The following intentionally remain at the repository root:

- [`../README.md`](../README.md) — current product overview
- [`../CHANGELOG.md`](../CHANGELOG.md) — authoritative release history
- [`../RELEASE_CHECKLIST.md`](../RELEASE_CHECKLIST.md) — current release/promotion checklist
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md)
- [`../SECURITY.md`](../SECURITY.md)
- [`../CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md)

Version-specific release/build/apply notes remain under [`../release-notes/`](../release-notes/).

## Documentation rule

The root README describes the **current product**. Historical implementation detail should not be appended to the README; it belongs in CHANGELOG, release-notes, or `docs/history/`.

# MystTiq v0.7.81.0 — "Set Up New Server" Wizard Rework

## Highlights

- **"Set Up New Server" is now a real install wizard**, not a copy of "Connect to Local/Remote
  Server." It always assumes local, skips the old Local/Remote choice screen entirely, and walks
  you through: connect to the local management service → choose your world source (clone an
  existing server, set up a new world, or import a world) → install the Palworld dedicated server →
  configure in-game defaults (with a starter preset picker and live port-conflict warnings) →
  confirm and finish.
- **Clone an Existing Server** is now available directly inside the wizard — pick any already-saved
  server profile as the source, choose a port offset, and the brand-new profile you're creating gets
  seeded from it.
- **A read-only environment checklist** (the same one Server Setup shows) now appears during
  install, so you can see SteamCMD, dependencies, and UE4SS status while setting up.
- **A starter preset picker** (Official/Vanilla, Balanced QoL, Relaxed QoL, or any custom preset) can
  now be applied directly during setup instead of only from the Configuration page afterward.
- Import a World isn't wired in inline yet — the wizard tells you honestly and points you to the
  World Transactions page once basic setup is done.

## Upgrade notes

- No configuration changes. Touches `MystTiq.Desktop` only (no backend routes changed; existing
  routes reused throughout).
- New automated test: `scripts/Test-v0.7.81.0-RouteSmoke.ps1`.

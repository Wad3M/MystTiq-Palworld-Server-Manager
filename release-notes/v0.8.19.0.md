# v0.8.19.0 — Every Route Declares Its Role

- **Security fix for remote and multi-user setups.** With sign-in switched on, many server actions were not checked
  for a role. Anyone signed in, even a Viewer, could:
  - run any RCON command;
  - kick or ban players;
  - change the Palworld settings file;
  - change mods.
  An account limited to one server could also reach the others. Every action now needs the right role:
  - reading needs Viewer;
  - changing needs Admin, unless it is an everyday server task that Operators may do (for example, save now, verify
    backups, update the server);
  - accounts limited to one server stay on that server.
  Using MystTiq on this PC without signing in is unchanged.
- **Ribbon buttons follow your role.** A button your role can't use is disabled, and its tooltip says which role it
  needs. Kick, ban, teleport and sending RCON commands also need Admin now.

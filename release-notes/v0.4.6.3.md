# MystTiq v0.4.6.3 — Deployment Bootstrap & Dashboard Telemetry Parity

## Scope

- Adds `Update-FromDownloads.ps1` and `scripts/Install-LatestFullSourceFromDownloads.ps1` for safe replacement of the Windows source tree from the newest downloaded FullSource archive.
- Runs the existing build clean before replacement so artifact-hosted Avalonia/headless processes are stopped before the target tree is cleared.
- Rejects unsafe ZIP traversal/rooted entries and validates required source layout before destructive replacement.
- Replaces the CPU percentage bar with a compact live history graph driven by the existing aggregate polling samples.
- Restores a distinct World Pulse band using authoritative decoded `GameDateTimeTicks` when available; it also reports session uptime, online/known players, last world-save age and latest backup age.
- Shows the active world nickname and complete canonical World ID together and adds Copy World ID actions.
- Combines MystTiq redirected stdout/stderr with `Pal.log` in the in-app Live Console and renders console text in green.
- Restores Server Name and Description to the dashboard footer and removes the redundant second Dashboard heading.
- Repairs the persistent sidebar server-status layout so long management-service text wraps instead of colliding with labels.
- Preserves the single aggregate status polling contract; World Pulse, backup summary and Palworld server identity are sampled inside `/api/v1/status/poll`.

Official baseline remains **v0.4.5.1** until the v0.4.6.x release gate is explicitly promoted.

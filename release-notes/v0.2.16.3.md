# MystTiq Palworld Server Manager v0.2.16.3

## Application Update Awareness & Server Setup Polish

### MystTiq GitHub release checking

MystTiq now checks its own public release channel using:

`https://api.github.com/repos/Wad3M/MystTiq-Palworld-Server-Manager/releases/latest`

The installed application version comes from the centralized `ApplicationVersion` source. The latest GitHub `tag_name` is normalized to a numeric `System.Version` before comparison.

Expected comparison states:
- `UPDATE AVAILABLE`
- `UP TO DATE`
- `DEVELOPMENT BUILD`
- `CHECK FAILED`

A development candidate such as v0.2.16.3 correctly reports itself as newer than public v0.2.15.17 rather than incorrectly claiming an update is required.

### Server Setup status badges

The Server Environment status badge column is narrower and each badge uses centered compact geometry. READY, MISSING, DISABLED, and OPTIONAL retain their semantic colors but no longer stretch unnecessarily across the full cell.

No server or MOD behavior changes are intended.

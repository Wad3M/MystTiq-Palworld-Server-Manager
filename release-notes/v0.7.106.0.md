# v0.7.106.0 — Map: De-overlapping Marker Labels

Tenth of the "enhancements to features we already have". Named as a follow-up since v0.7.100.0's map-zoom work:
players or bases standing close together drew their name labels directly on top of each other.

- Markers whose labels would collide now stagger into a readable column instead of overlapping. Only the
  label moves — the dot itself always stays exactly on its real position.
- Reacts to zoom: spreading markers apart by zooming in naturally un-staggers their labels back to normal once
  there's enough real screen distance between them.
- Checked live on the real clone's Map page: a base and a nearby offline player's labels, previously
  overlapping and unreadable, now draw as two clean, separate lines.
- One known limit: if two markers' dots sit at the exact same screen position, they still render as a single
  visible dot — this only fixes the label text, not two icons sharing the same pixel.

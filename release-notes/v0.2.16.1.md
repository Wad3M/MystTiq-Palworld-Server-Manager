# MystTiq Palworld Server Manager v0.2.16.1

## Runtime Path & Deployment Abstraction

- Added `IServerPathProfile` as the shared deployment-path contract.
- Added `WindowsServerPathProfile` preserving the existing Windows server layout.
- Centralized runtime binary, UE4SS, MOD-root, save, config, log, server executable, and SteamCMD path semantics.
- Application composition now creates and shares one path profile across migrated services.
- Migrated UE4SS resolver, MOD verification, MOD compatibility, MOD service native-loader deployment, Environment service, Installer service UE4SS handling, and Server Doctor runtime detection away from direct Win64 path construction.
- No intentional changes to MOD health, runtime evidence, lifecycle policy, dashboard behavior, or Windows deployment locations.
- Linux path implementation is intentionally deferred; this release establishes the contract required for it.

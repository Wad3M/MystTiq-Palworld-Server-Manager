# MystTiq v0.7.25.0 — Ribbon Adaptivity

## Highlights

- **First release of a broader GUI/workflow/UX overhaul**, gathered page-by-page into a 21-version roadmap covering 57 flagged issues — layout, workflow, and several real bugs found and pinpointed during the walkthrough itself.
- **The ribbon now shrinks to fit** instead of silently clipping when there isn't enough width — the same adaptive behavior the tab strip already had (v0.7.16.0), now shared by the ribbon. Groups that don't fit move into a new "»" overflow flyout.
- No visible change to ribbon content this release — same buttons, same icons, same colors. This is purely the shared infrastructure every later ribbon-relocation version in the roadmap needs.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.

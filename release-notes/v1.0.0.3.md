# v1.0.0.3 — PalDefender on the MODs Page

## MODs

- **PalDefender is listed on the MODs page.** It isn't a PAK or UE4SS MOD: it's a DLL the game loads through `d3d9.dll`
  next to the server's executable. It now shows as a **NATIVE** MOD with its version, whether it loaded the last time the
  server started, and an on/off switch.
- **The UE4SS loader is listed too.** If it's switched off, every UE4SS MOD is marked as not loading, instead of looking
  enabled.
- Switching a NATIVE MOD off renames its loader. Switching it back on restores it, including a loader that was renamed
  by hand (for example `d3d9.dll.disabled-test`). **Disable All**, **Enable All** and the stuck-start tests include them.
- Dropping PalDefender's ZIP on the install box explains where its files go, instead of installing it as a UE4SS folder
  that would never load.

## Fixed

- **Drag and drop on the MODs page.** Dropping a ZIP on the install box only worked right on its button or caption. It
  now works anywhere in the box.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.0.2

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

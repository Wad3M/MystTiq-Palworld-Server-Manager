# MystTiq v0.7.32.0 — Visual Density Pass

## Highlights

- **Navigation pane icons are noticeably larger** — 20×20 → 28×28 across all 25 destinations.
- **Server Setup, Backups, and Server Doctor** get more compact cards — tighter padding, smaller text, shorter labels — so more fits on screen without scrolling.
- **MOD Library** no longer shows the 6 summary cards duplicated from MOD Dashboard.
- Server Setup's READY count is now centered.
- Also fixed: "Verify Files" was still embedded in the Server Setup card even after moving to the ribbon in an earlier release — removed for real this time.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- Sizing/spacing values are reasonable estimates, not pixel-verified against a live render — flag anything that looks off and it can be tuned in a follow-up.

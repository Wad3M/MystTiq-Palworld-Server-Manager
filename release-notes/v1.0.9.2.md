# v1.0.9.2 — MOD Load Order and Profiles

**Choose the order UE4SS loads your MODs in.** The MOD Library has a new **Load Order and MOD Profiles** card:
- It lists your UE4SS MODs in the order they load (top to bottom). Move one up or down with the arrows, then **Save
  Load Order**. It takes effect at the next server start, and MystTiq keeps the previous order file as a backup.
- PAK MODs are listed too, with an explanation: they have no order a file name can set. When two PAKs change the same
  thing in the game, the game decides, so renaming files does not help.

**Save your MOD setup to a file, and load it again.** **Export Profile…** writes a small file listing every MOD,
whether it is on, the UE4SS order, its version, where it came from, and a check of its files. It never contains the
MOD files themselves. **Import Profile…** first shows what it would change; **Apply Profile** then switches MODs on or
off and sets the order for the MODs this server has, and lists any it is missing with where to get them.

The server has to be stopped to change the order or import a profile.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.9.1

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert, and the service is unchanged. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

# MystTiq Palworld Server Manager v0.3.0.4

## Secure Management API & Automated Linux Acceptance Foundation

v0.3.0.4 hardens the management API boundary and makes Linux acceptance a one-command workflow.

### Security defaults

Default API remains:

```text
http://127.0.0.1:8213
```

Remote/non-loopback binding is rejected unless bearer authentication and TLS are both enabled.

New security configuration uses schema version 2 and keeps secret values out of normal JSON configuration. Default secret paths are under `/etc/mysttiq/secrets/`.

### Commands

```bash
./mysttiq-server config-migrate
./mysttiq-server api-token-create --token-file /etc/mysttiq/secrets/api-token
```

### Automated acceptance

Linux archive:

```bash
bash ./scripts/Test-v0.3.0.4-LinuxAcceptance.sh
```

Windows repository:

```powershell
.\scripts\Deploy-Test-MystTiqLinux.ps1
```

The Linux runner saves a concise summary and raw diagnostics in `~/mysttiq-test-results/v0.3.0.4/<timestamp>/`.

Use `--extended` / `-Extended` only for lifecycle mutation testing on the disposable VM.


For the disposable VM, the full install + lifecycle acceptance is one Linux command:

```bash
bash ./scripts/Test-v0.3.0.4-LinuxAcceptance.sh --install-current --extended
```

# v0.9.9.0 — One Helper, Crash Causes and Local Formats

- **Adding a server no longer restarts your running ones:** the new-server wizard restarts MystTiq's local helper to
  bring the new server online. That restart used to take every game server the helper had started down with it, and
  they were then restarted as "crashed". Running servers now keep running.
- **One local helper, not several:** when the usual port was held by another MystTiq (an older version after an
  upgrade, or an installed service), the desktop started a fresh helper on every launch and they piled up, all
  watching the same servers. It now remembers the helper it started and reuses it.
- **Crash analysis names a server that dies when a player joins:** if PalDefender's log for a session ends on a player
  connecting, with nothing after it, the Crash Analyzer says so and points at PalDefender, UE4SS and mods that don't
  match the game version.
- **UE4SS is compared for you:** when there's no record of which UE4SS release was installed, MystTiq compares the
  installed file with the newest releases' downloads and names the release it is identical to.
- **Alerts for every update:** the Alert Center's out-of-date alert now also tells you when UE4SS has a newer release
  and lists installed MODs that have an update, alongside the game server and PalDefender. Each sends one alert,
  reminders while it lasts, and a "Resolved" notice.
- **Fix a port mismatch from the Doctor:** when a server advertises one port and uses another, Fix now sets the
  advertised port to the one players actually reach.
- **Numbers, dates and times follow your language:** they used to follow Windows' language whatever you chose in
  MystTiq.
- **A check for the downloads themselves:** `scripts/Test-v0.9.9.0-Distribution.ps1` verifies the checksums, what's in
  each ZIP, the version on the binaries, and that the packaged service starts from a clean folder.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.8.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. If an older MystTiq helper is still running from the previous version, close it (Task Manager: `mysttiq-server`) so only one watches your servers; MystTiq tells you when it finds one.

## Known limitations

This is a development version, not v1.0. A helper left running by an older version is reported, not stopped: MystTiq only stops helpers it started itself. The UE4SS comparison covers the three newest releases; an older or custom build still reads "check manually". The 11 translations are drafts awaiting native review. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

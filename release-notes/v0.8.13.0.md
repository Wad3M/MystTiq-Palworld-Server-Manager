# v0.8.13.0 — Game Names, and an Image on Every Ribbon Button

- **Real names for items and Pals.** The Give Item picker now shows "Pal Sphere (PalSphere)" instead of just the
  internal id, and you can search by name, for example "lamball" or "pal sphere". The map says "Cattiva" instead of
  "PinkCat".
- **Items nobody has had yet are listed too.** After what your world already has, the picker lists the game's other
  items and Pals, marked "not yet seen on this server". You no longer have to type unknown ids by hand.
- The names come from your server's own game files, read with the Python tools already installed for save decoding.
  They're read again automatically after a game update. If Python or its Oodle module is missing, everything still works
  with ids, and the picker says what's needed.
- **Your last ten icons are in.** Refresh, Start, Restart, Stop, Console, Force Stop, Verify Files, Install Missing,
  Run Analysis and Preview Plan now have your images, so every Ribbon button on every page has one.
- Checked on Windows (with the real game files) and on the Linux VM. The VM's Oodle module is incomplete, so its own
  MystTiq will show ids until that's reinstalled.

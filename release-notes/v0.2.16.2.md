# MystTiq Palworld Server Manager v0.2.16.2

## Live Save Read Safety & UI Button Standardization

### Live Level.sav safety
The World Inspector now obtains a stable temporary snapshot before reading the active save header. The snapshot reader:
- opens the source with `FileShare.ReadWrite | FileShare.Delete`
- copies to a MystTiq temporary read snapshot
- verifies source length and last-write time remained stable
- verifies copied length
- retries briefly while PalServer is writing/replacing the save
- deletes the temporary snapshot after inspection

If a stable snapshot cannot be obtained during the retry window, World Inspector shows a recoverable status message instead of a blocking file-lock dialog.

### Button consistency
The shared MystTiq button family is approximately 10% more compact. Semantic color meanings and the existing common template/tooltips remain intact. Major button-only action rows now use equal-cell UniformGrid alignment rather than uneven WrapPanel sizing.

No server lifecycle, MOD evidence, Overall Health, or save-writing behavior changes are intended.

# v0.7.105.0 — Doctor: Confirm Before Fix

Ninth of the "enhancements to features we already have". The Doctor's Fix button (Create Nightly Backup Rule,
Create Backup Folder, Install / Repair Server Files) ran the instant you clicked it — a confirmation step was
named as a desired follow-up since v0.7.103.0.

- Every Doctor Fix button now needs an explicit tick first: a "Confirmed" checkbox next to the button, with a
  tooltip naming exactly what the fix will do. The button stays disabled until it's ticked.
- Same pattern Backup Restore already uses ("I understand restore replaces the active save") — applied here
  per finding, since more than one Doctor finding can offer a fix at once.
- Nothing about what a fix actually does changed; this only adds the one extra click first.
- Checked with a new logic-harness scenario and on the running app: the button stays disabled until the box is
  ticked, then enables.

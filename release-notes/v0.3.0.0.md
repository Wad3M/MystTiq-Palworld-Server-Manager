# MystTiq Palworld Server Manager v0.3.0.0

## Headless Core Foundation & Linux Platform Base

v0.3.0.0 opens the Linux/headless implementation line while preserving v0.2.16.4 as the validated Windows baseline.

### New cross-platform projects

- `src/MystTiq.Core` — plain `net10.0`; no WPF dependency
- `src/MystTiq.HeadlessHost` — plain `net10.0` command-line host referencing the shared core

The existing Windows WPF application is not rewritten in this phase.

### Initial Linux capabilities

- `/etc/os-release` distribution detection
- Linux path profile
- Linux PalServer process/executable profile
- Valve Linux SteamCMD package profile
- Linux Palworld App `2394010` install-plan generation
- required `+@sSteamCmdForcePlatformType linux` platform override
- read-only `/proc` process-tree and mapped-file inspection
- guarded TCP/UDP port observation
- non-destructive `probe`, `status`, and `install-plan` headless commands

### Safety boundary

v0.3.0.0 intentionally does **not** let the headless host execute SteamCMD or start/stop PalServer. It proves the cross-platform/headless boundary first. Lifecycle authority follows in later v0.3 phases after the Linux observation layer is validated.

### Tested Linux environment

Initial validation environment:

- Ubuntu Server 24.04.4 LTS (Noble Numbat)
- x86_64 / amd64
- kernel `6.8.0-137-generic`
- headless / OpenSSH
- Valve Linux SteamCMD
- Palworld Dedicated Server App `2394010`
- native server executable `Pal/Binaries/Linux/PalServer-Linux-Shipping`
- UDP `8211` listener validated

See `docs/linux/TESTED_ENVIRONMENT.md` for details.

### Windows backport rule

Every Linux phase classifies useful discoveries as SHARED, LINUX, or WINDOWS-BACKPORT. Windows-specific headless/service/minimized-resource improvements are tracked for v0.4 in `docs/roadmap/WINDOWS_BACKPORT_REGISTRY.md`.

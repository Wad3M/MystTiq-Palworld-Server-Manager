# v1.1.1.0 — MOD Sources, Player Checks Without the Desktop, Linux and Docker Downloads

**MOD Sources.** A new page under MODs holds everything MODs come from: this PC's Steam Workshop downloads, the MOD
browser (folders on this PC, Thunderstore, CurseForge, GitHub releases, Nexus Mods) and the Nexus Mods catalog. MOD
Library keeps what is installed: the ZIP install, the load order and profiles, and the installed MODs. A Nexus Mods
"Mod Manager Download" link now opens MOD Sources.

**Player checks run without the desktop.** The join check, the identity guard, character moves, the player list, the
whitelist, unique names, starter kits and temporary-ban expiry used to run only while a desktop was open. The service now
runs them itself every 15 seconds when no desktop is connected, so a server running as a Windows service, a systemd unit or
in Docker is covered all the time.

**Players on the new-character screen are told what to do.** When the game sends a returning player to make a new
character (it gave their account a new player ID), MystTiq disconnects them once with the steps: their character is
safe; join again and make a character with any name; MystTiq then moves their own character onto it.

**Every account is covered, not only Steam.** Xbox and other non-Steam accounts are found from MystTiq's player list, so
a new ID from the game is noticed and the character moved for them too.

**Link an account to its character.** Players > Player IDs has a form to link an account to the character that is
theirs, for an account whose ID the game changed before MystTiq saw it. If the game last gave them another ID with a
character, that character is replaced by theirs with the usual move (a safety backup first).

**Faster tab switching.** Switching between server tabs re-applied the colour theme every time, even when both tabs
use the same one, and the desktop froze for about two seconds per open window. A tab with the same theme now switches
at once (measured: from 3.7 s to under 0.1 s per switch); a tab with a different theme still changes the colours.

**Smaller changes**
- The Dashboard tells a player on the server's own PC to join with a local address (for example `192.168.1.x:8211`),
  not `127.0.0.1`: joins through 127.0.0.1 have dropped.
- Server > Launcher: the "Like double-click" preset is gone. It was added when a way of starting the server seemed to
  keep players' characters; the game itself was later shown to change player IDs. The other presets are unchanged.

## Upgrading from v1.1.0.3

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. If you saved the Like double-click preset, your saved launcher settings are kept as they are. Coming from an older version, also read the [v1.1.0.3](v1.1.0.3.md), [v1.1.0.2](v1.1.0.2.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

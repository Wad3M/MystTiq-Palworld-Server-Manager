# v0.7.115.0 — Deficiency Fixes

Fixes items 1–5 of the deficiency report supplied after the 0.7.x pass. All were checked against the real code
and app first, and all were confirmed. Item 6 (icon silhouettes and header art) is deferred.

- **Map labels no longer overlap, and player names now actually show.** Labels are laid out as real text
  boxes and placed next to their own marker (below, right, above or left) wherever there is room. Checking
  the live map also showed that player names had never been drawn at all; they are now. Marker dots also sit
  exactly on their point instead of a few pixels off.
- **A "server is DOWN" notice no longer stays pinned after MystTiq restarts.** Crash recovery remembers the
  notice, its restart attempts and whether it had given up. After a restart it keeps watching instead of
  restarting a server it had already given up on.
- **"Server is back up" now means ready.** The notice waits until the server's game port is up, not just
  until a process exists. A restart that never becomes ready counts as a failed restart.
- **Operation history survives a restart.** An operation cut off when MystTiq stopped is marked
  "Interrupted" instead of staying "Running" forever.
- **Release checks.**
  - The release checklist no longer names an old version.
  - The full test gate no longer fails every time on its own build folders; that was the long-standing
    "known residue".
  - A missing previous backup archive is now reported as skipped instead of stopping the whole gate.
- Checked with 4 new logic-harness scenarios, a rewritten map-label scenario, a live smoke that restarts the
  real backend in the middle of a crash cycle, and live map screenshots before and after.

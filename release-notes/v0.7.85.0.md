# MystTiq v0.7.85.0 — Import a World, Phase 2

## Highlights

- **"Import a World" is now a real, working step** in the "Set Up New Server" wizard instead of an
  honest placeholder pointing to World Transactions. Click "Prepare for Import" to start the
  freshly-installed server once (Palworld generates its own initial world within a few minutes),
  then choose and Analyze your world archive, review the plan, and Apply with a fresh safety backup —
  all inline, without leaving the wizard.
- **Fixed a real bug**: the Analyze/Apply archive commands silently did nothing when used outside the
  main Configuration page's own connection — now fixed the same way an identical v0.7.81.0 bug was.

## Upgrade notes

- No configuration schema changes. Touches `MystTiq.Desktop` only.

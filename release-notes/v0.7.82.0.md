# MystTiq v0.7.82.0 — Update Center Actionability & Server Setup Table Resize

## Highlights

- **Update Center's pip row is now actionable** — click "Update" to run a real, safe
  `pip install --upgrade pip` directly from the app, no need to open a terminal.
- **"Unknown" rows now have a real way to check** — Python Runtime, Visual C++ Runtime, Microsoft
  C++ Build Tools, and PIM/Oodle Decoder each get an "Open" button linking to the real official page
  where you can check the latest version yourself, since none of these publish a reliable
  unattended feed this app could safely automate.
- **Server Setup's environment table now resizes with the window** instead of being stuck at a
  fixed height — more room on a taller window, less wasted scroll on a shorter one.
- **Fixed a real crash** in the Alert Center's disk-space-exhaustion prediction that was flooding
  Activity & Audit with a repeating warning roughly once a minute.
- **Configuration page reordered** — Server Identity now sits at the top, with the Simple/Advanced
  toggle, QoL preset picker, and search bar moved down to just above World Settings. Server Identity
  also has more breathing room.
- **Unsaved changes now highlight in amber** across Server Identity, Network toggles, network
  settings, and World Settings sliders, so it's obvious at a glance what's been edited but not saved.
- **Fixed a real Dashboard bug**: the SERVER/OVERALL HEALTH cards could say "Stopped" while the
  ribbon only offered Stop — a detected-but-not-yet-ready PalServer process now correctly shows
  "Starting / Not Ready" instead of falsely claiming the server was stopped.
- **Fixed the Server Identity "🎲 Generate" button (and "Save As Preset")** getting permanently
  stuck disabled after the very first Configuration load, in every session.

## Upgrade notes

- No configuration changes. Touches `MystTiq.Desktop` and `MystTiq.HeadlessHost`.

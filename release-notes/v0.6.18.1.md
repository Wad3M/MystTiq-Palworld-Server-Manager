# MystTiq v0.6.18.1 — Fix Release (Code Review Findings)

## Highlights

A user-requested code review of everything built this session (v0.6.15.0 through v0.6.18.0) found and fixed three real logic bugs. No new features, no schema changes.

- **Pal Editor**: the Gender field's post-apply verification used `EndsWith("Male")`, which also matches `"Female"` (it ends in "...male" case-insensitively). This meant the independent re-decode verification — the whole point of which is to catch a mutation that silently failed to land — could never actually catch a failed Male-gender edit. Fixed with an exact-suffix comparison against the real enum value.
- **Anti-Cheat**: the Pal stat-anomaly rule's cooldown key was keyed by the owning player (or the shared literal `"(unowned)"` for ownerless Pals), not by the individual Pal. A second anomalous Pal owned by the same player — or a second unowned anomalous Pal — was silently dropped for up to 30 minutes: no notification, no activity-log entry, no chance of enforcement. Fixed by keying the cooldown on the Pal's own stable instance ID; Kick/Ban enforcement still correctly targets the real owner.
- **Discord Bot**: the bad-token detector (introduced in v0.6.17.0 specifically to stop hammering Discord's servers with an invalid token) scanned *every* Discord.Net log line, regardless of severity, for the bare substring `"401"`. Discord.Net's routine Debug/Verbose gateway traffic (session IDs, latency values, snowflake ID fragments) can incidentally contain that substring, which risked tearing down a perfectly healthy, long-running bot connection. Fixed by scoping the check to Warning-or-worse severity from the `"Gateway"` log source specifically — the exact shape of a real 401 rejection, confirmed via live testing against Discord's actual servers.

## Upgrade notes

- No configuration schema change. No new routes. No behavior change for any correctly-functioning path — these are pure bug fixes.
- Full solution rebuild is clean (0 warnings/0 errors); the v0.6.18.0 static logic gate (18/18 checks) still passes unchanged.

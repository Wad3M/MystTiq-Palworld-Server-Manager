# MystTiq Palworld Server Manager v0.3.0.6 FIX2

## Linux Remote-Tool Packaging Hotfix

FIX1 corrected the remote-enrollment workflow itself, but Linux acceptance exposed a packaging defect: the self-contained Linux archive did not contain the new remote enrollment and rollback scripts.

FIX2 updates `Build-LinuxHeadless.ps1` so every v0.3.0.6 Linux package must contain:

- `scripts/Test-v0.3.0.6-LinuxAcceptance.sh`
- `scripts/Configure-MystTiqRemoteApi.sh`
- `scripts/Disable-MystTiqRemoteApi.sh`

The Linux package build now fails instead of silently producing an incomplete archive when any required Linux-side script is missing.

No runtime, API, security, lifecycle, systemd, PalServer, or Windows WPF behavior changed.

# v0.2.14.7 — Diagnostics Center

## Summary

Adds a read-only system health center for MystTiq and its configured Palworld environment. Diagnostics run through registered providers and do not modify Palworld server or world data.

## Added

- Application, workspace, server, world, backup, MOD, transaction, and notification diagnostics.
- Weighted overall health score and categorized findings.
- JSON and text report export.
- Redacted support package generation.
- Diagnostics Center navigation under Tools.

## Safety

The support package excludes the protected password value and records only whether a password is configured. Recent logs are limited by count and size. Users should still review support packages before posting them publicly because logs can contain paths, player identifiers, and environment details.

# MystTiq v0.7.58.0 — Website-Sourced MOD Descriptions, Light Polish

## Highlights

- **Long MOD descriptions now scroll instead of getting cut off** past a fixed height.
- **The Source URL link is actually clickable now** — a new Open button launches it in your default
  browser.
- **The "no known match" message no longer shows before you've clicked Fetch** — it only appears
  after a real fetch attempt comes back empty.

## Upgrade notes

- No configuration changes, no new routes, no backend changes at all. Purely three small UI/UX
  fixes to the MOD DETAILS panel's DESCRIPTION section shipped in v0.7.55.0.
- No way to visually render this app in the environment that built it — please open MOD Library,
  select a MOD with a long description, and confirm scrolling/the Open button work as expected.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md) and [`docs/architecture/v0.7.58.0-mod-description-light-polish.md`](../docs/architecture/v0.7.58.0-mod-description-light-polish.md).

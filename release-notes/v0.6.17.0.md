# MystTiq v0.6.17.0 — Two-Way Discord Bot Control

## Highlights

- **New: real Discord integration, in both directions.** Outbound notifications to Discord actually work now (a fixed "not implemented" stub), and — the headline feature — a real Discord bot lets an authorized Discord user run server commands and get a reply, right from Discord.
- **Inbound slash commands**: `/mysttiq-status`, `/mysttiq-players` (anyone mapped to at least Viewer), `/mysttiq-start`, `/mysttiq-stop`, `/mysttiq-restart`, `/mysttiq-broadcast` (Operator), `/mysttiq-kick`, `/mysttiq-ban` (Admin) — gated by a Discord-role-to-MystTiq-role mapping you configure, checked against the caller's real Discord roles.
- **Outbound**: notifications routed to the "Discord" channel now post a real, formatted embed to a Discord webhook URL — no bot needed for this half.
- Connects outbound to Discord's gateway only — MystTiq never exposes a public HTTPS endpoint for this. Consistent with the local/LAN-first security model every other feature already follows.
- **A real bug found and fixed during this release's own live verification**: an invalid bot token would have made the bot retry against Discord's real servers forever without ever surfacing a clear failure. Fixed — three consecutive rejections and it stops, marks itself failed, and logs why.

## Upgrade notes

- No configuration schema change to `mysttiq.json`. New per-profile file: `discord-bot.json` (alongside the existing `channels.json`/`templates.json`), created empty/disabled on first run.
- New routes: `GET`/`PUT /notifications/discord-bot` (Admin-gated). The bot token is never returned by `GET` — only whether one is configured.
- To use the bot, create a Discord application + bot at the Discord Developer Portal, invite it to your server with the `applications.commands` scope, and paste the bot token and guild ID into the new Discord Bot card (Alert Center page).

## What's deferred

- Wild Pal/base positions, world/save mutation, and backup/MOD triggers are not exposed via Discord commands.
- Command→role mapping is fixed, not user-configurable, this pass.
- Anti-cheat & save-integrity scanning is the next release — see `docs/architecture/v0.6.15-plus-competitive-survey.md`.

# MystTiq v0.7.36.0 — Theme System Audit

## Highlights

- **The title bar and footer status bar now actually re-theme.** Both were hardcoded to a fixed dark navy color instead of a theme resource, which is why they stayed dark in Light mode while everything around them lightened. Now wired to `StatusSurfaceGradient`/`BorderSoftBrush` — resources that already existed and were already fully registered for every theme and variant, just never connected to these two surfaces.
- The already-disclosed BoxShadow/decorative-glow color limitation (a real Avalonia platform constraint) is unchanged and stays documented as such.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- No live GUI verification against Light mode or the Emerald/Crimson/Violet accent themes in this environment — the fix is grounded in the resource's existing theme registration, not a rendered comparison.

# v0.7.107.0 — Alert Center: Reminder Re-alerts

Eleventh of the "enhancements to features we already have". Named as a follow-up since v0.7.102.0 first
introduced episode-based alerting: a condition that stayed true for days sent exactly one alert and then
nothing else until it cleared.

- A condition that is still true after 24 hours now gets a follow-up "Still active: ..." notice, and again
  every 24 hours after that until it clears. The original alert is untouched — this is purely a reminder that
  something is still wrong.
- The reminder is never pinned, even for a Critical. Only the original alert is pinned (and unpins itself on
  recovery, from v0.7.104.0); reminders would otherwise grow the pinned count without bound for a long-running
  condition.
- Recovering stops the reminders immediately, same as before.
- Checked with two new logic-harness scenarios and a new live smoke (with the interval shortened for testing):
  the reminder arrives once the interval elapses, stays quiet in between, keeps arriving every interval while
  the condition holds, and stops the moment it clears.

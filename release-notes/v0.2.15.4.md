# MystTiq Palworld Server Manager v0.2.15.4

## Runtime-Loaded Status & Expanded UE4SS Diagnostics — Phase 4

Official baseline: **v0.2.15.3 FIX2**.

### Implemented
- MOD inventory distinguishes configured enablement from presence in the resolver-selected Active Mods Root.
- UE4SS/Lua rows expose `Active` / `Missing` runtime-location state.
- UE4SS/Lua rows expose `Loaded` / `Not loaded` state based on the latest UE4SS log's `Starting Lua mod` entries.
- A UE4SS/Lua mod outside the Active Mods Root reports `Misconfigured`.
- MOD Runtime diagnostics show UE4SS Root, Active Mods Root, Legacy Mods Root, runtime-reported Mods Root, path health, active/legacy directory counts, and loaded Lua-mod count.
- No automatic migration, deletion, or legacy cleanup was added.

### Next planned phase
**v0.2.15.5** — Centralized MOD Health & Identity (completed), followed by **v0.2.15.6** — Pre-start MOD Reconciliation & Runtime Health Hardening.

## FIX1 — MOD Archive Normalization Null Guard

Fixed a null-reference exception in MOD archive preview/install when an archive
does not have a removable common wrapper folder. This specifically restores
valid handling for root-level PalDefender packages and UE4SS packages wrapped
under `Mods/<ModName>/...`.

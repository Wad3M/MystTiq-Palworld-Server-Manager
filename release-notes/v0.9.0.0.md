# v0.9.0.0 — The Window in 12 Languages

- **Every label, button, tip and menu in 12 languages:** English, 简体中文, Español, Português (Brasil), Русский,
  Deutsch, Français, 日本語, 한국어, Italiano, Polski and Türkçe. The pages, dialogs, the new-server wizard, the tray
  menu and screen-reader names all follow the chosen language, live, without restarting. Translations other than
  English are first drafts awaiting native review (the Settings page says so).
- **Pick the language from the title bar:** a language drop-down now sits right of the Settings gear, as well as in
  Settings. Both are the same setting, and the choice is remembered.
- **The Notifications button is a bell** (it was a grey dot).
- **Chinese, Japanese and Korean** are drawn with each language's own system font; on Linux, install Noto Sans CJK (or
  WenQuanYi) for them.
- **The list of translatable text:** `docs/i18n/UI_TEXT_INVENTORY.md` and `.csv` list every English text the app shows
  and whether it follows the language. `scripts/Update-MystTiqUiText.ps1` keeps it current, and the release gate fails
  if a new English text is added to a page without a translation key.
- Still in English: status and error messages written by the app (v0.9.1.0) and messages sent by the service.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.8.26.0

Extract into a new folder and start it; settings, accounts and server data are kept. Your language choice carries over (German and Spanish users keep their language; everyone else stays in English until they pick one).

## Known limitations

This is a development version, not v1.0. Status and error messages are still English. The 11 translations need native review. On Linux, file pickers and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need the live scripts to be run with a player and real channels. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# v0.7.93.0 — Nexus Mods Catalog

Second of the "real gaps" from the competitive feature review.

- New collapsed **Nexus Mods Catalog** card on the MOD Library page: connect with your own Nexus API
  key, browse Trending / Latest Added / Latest Updated Palworld mods, look one up by id or page URL,
  list its files, and install a ZIP through the existing validated ZIP install.
- Honest about what Nexus allows: its public API has **no search** (10 per list, plus lookup by id) and
  only **Premium** accounts get direct download links. Free accounts use **Open on Nexus** or paste the
  `nxm://` link from the Mod Manager Download button (**Install From Link**). Nothing bypasses Premium.
- Your API key stays on your PC and is never sent to the MystTiq server. It is kept in memory; **Save
  Key** stores it DPAPI-encrypted (Windows), **Forget Key** removes it.
- Downloads are limited to https Nexus hosts, capped at 750 MB, sniffed for ZIP (7z/rar get a clear
  message), and always installed through the server's existing extraction limits and traversal checks.
- Shows Nexus attribution and remaining rate-limit headroom.

Not verified end to end (no Nexus key was available): the first real Connect / list / install is the
true test. Before a public release, Nexus's policy asks public apps to contact them with a test build.

Touches `MystTiq.Core` and `MystTiq.Desktop`. See
[`docs/architecture/v0.7.93.0-nexus-mods-catalog.md`](../docs/architecture/v0.7.93.0-nexus-mods-catalog.md).

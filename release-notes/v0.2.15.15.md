# MystTiq Palworld Server Manager v0.2.15.15

## Server Platform Services Abstraction

This release continues the behavior-preserving platform-preparation roadmap.

### New platform boundary

`IServerPlatformOperations` now owns platform-specific lifecycle operations:

- resolve the PalServer executable
- build the process launch policy
- apply post-launch window behavior
- detect server processes for force-stop verification
- terminate an owned process tree
- terminate validated fallback PalServer processes

### Windows implementation

`WindowsServerPlatformOperations` contains the current Windows behavior, including:

- Win64 PalServer executable resolution
- hidden/no-console launch settings
- Windows post-launch window hiding
- process-tree kill behavior
- process-name/root-path fallback cleanup

`ServerService` remains the public compatibility facade and uses the Windows implementation by default.

### Linux preparation

Together with `IServerSessionInspector` from v0.2.15.14, the major OS-specific process boundaries are now explicit. A later Linux implementation can replace the platform services without changing the MOD runtime evidence engine or high-level lifecycle policy.

No user-facing behavior changes are intended.

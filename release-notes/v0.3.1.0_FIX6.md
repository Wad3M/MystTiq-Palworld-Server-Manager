# MystTiq Palworld Server Manager v0.3.1.0 FIX6

## Actual RunBuild Block Locator Hotfix

The final FIX5 false failure was caused by the block locator itself.

`IndexOf('if($RunBuild){')` found the string literal inside the regression-check setup rather than the actual executable `if($RunBuild){...}` block later in the script.

FIX6:

- locates line-level `if($RunBuild){` constructs with a multiline regular expression
- selects the last matching construct, which is the actual build block
- bounds that block at the `$passed=` summary
- verifies the extracted block contains no `$LASTEXITCODE`
- verifies Validate, DesktopWindows and DesktopLinux all use non-throwing PowerShell completion semantics

The locator was also independently simulated against the final harness source during package generation.

No application/runtime behavior changed.

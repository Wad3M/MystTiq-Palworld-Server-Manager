# MystTiq v0.7.86.0 — New Server Wizard: MODs Step

## Highlights

- **New MODs step in "Set Up New Server"** — optionally scan and import Steam Workshop MODs right
  in the wizard before finishing setup, for New World and Import World installs. Clone already
  carries over the source server's own MODs. Entirely optional; you can always add more later from
  MOD Library.

## Upgrade notes

- No configuration changes. Touches `MystTiq.Desktop` only.

# MystTiq v0.7.62.0 — Dashboard/Ribbon Layout Overlap Fix

## Highlights

- **Fixed a real, reported UI bug**: after certain reconnect sequences, the ribbon and category tabs
  went visually blank on every page (Dashboard, Inspector, confirmed live on both). Live process
  inspection (`dotnet-sos` + Sysinternals `cdb`, attached non-invasively to the actual running app)
  proved the underlying data was completely correct the whole time — this was a pure layout/overlap
  bug, not a data or logic bug. The page-header panel had no `MaxWidth`, and under certain reconnect
  conditions could expand across the full row, painting its own opaque background directly over the
  ribbon and category tabs beneath it. A `MaxWidth="620"` ceiling fixes it.

## Upgrade notes

- No configuration changes, no data migration, no backend changes — this is a Desktop-only XAML fix.
- No new routes, no schema changes.
- Confirmed fixed live on both Dashboard and Inspector after reproducing the original bug twice
  across two separately-launched app instances.

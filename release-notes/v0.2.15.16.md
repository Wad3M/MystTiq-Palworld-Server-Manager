# MystTiq Palworld Server Manager v0.2.15.16

## Platform Profile Abstraction & Documentation Consistency

### Server platform profile
`ServerPlatformProfile` centralizes process names, executable-relative paths, SteamCMD executable naming, and guarded ports.

The Windows profile preserves the current names and paths. `ServerService` no longer embeds Windows PalServer process names directly.

### README/documentation audit
The README was treated as a public overview rather than a second changelog:
- duplicate feature matrix removed
- accumulated v0.2.15.x release diary removed
- stale baseline/current-RC claims removed
- MOD runtime/health wording reconciled with the operational-health model
- Windows support vs future Linux work stated explicitly
- historical details delegated to CHANGELOG and release-notes

No user-facing runtime behavior changes are intended.

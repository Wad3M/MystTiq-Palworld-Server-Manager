# MystTiq v0.7.50.0 — Console Source Completeness (UE4SS.log)

## Highlights

- **The Console page now shows real UE4SS activity it was missing entirely** — mod loading, hook
  registrations, and admin-command diagnostics from `ue4ss/UE4SS.log`, a real, substantial log file
  that was never included in the console's merged sources before this version.
- **A long-standing assumption was checked against real data and found wrong**: `Pal.log`, which the
  console mechanism has always tried to read as "where PalServer/UE4SS write native output," does
  not actually exist anywhere on a real, actively-modded local Palworld install — confirmed via a
  live, read-only check. This lines up with the earlier finding that `-ABSLOG` also produces nothing.
- **As a side effect of verifying this fix, found that player connect/disconnect events were already
  reachable** through the existing "AdminCommands server log" source, just easy to miss when the
  console otherwise looked thin. Adding UE4SS.log alongside it makes the whole console noticeably
  richer with zero further code changes.

## Upgrade notes

- No configuration or behavior change beyond the console content itself — purely additive.
- This is a small, low-risk, server-side-only fix (no Desktop changes) verified live and read-only
  against a real Palworld install before shipping.
- The deeper gap this doesn't fix — raw base-engine log output with no UE4SS involvement — genuinely
  has no accessible path today; that's what the next roadmap item (Native Console Capture, a native
  DLL proxy project) targets.

# v0.9.8.0 — Small Screens, Alerts and Linux Install

- **The "+" stays on small windows:** on a narrow window the new-tab button was pushed off the title bar. It now
  always follows the tabs; below 1200 px the title bar drops its "Palworld Server Manager" subtitle to make room, and a
  tab that doesn't fit goes to the "»" menu.
- **Alerts when a component falls behind:** the Alert Center now tells you (and your Discord or email channels) when
  the game server is behind Steam's public build, or when PalDefender says it isn't updated for the game version, and
  again when it's resolved. Before, only the Doctor showed it. You can switch it off in the Alert Center.
- **The firewall check knows your network:** a rule counts only on the networks it covers, so a rule for Private
  networks no longer reads as "allowed" while your computer is on a Public one; the check says so instead.
- **Server search on bigger networks:** the search covers each network card's own subnet (up to 1,022 addresses)
  instead of always the 254 addresses around it, and typed ranges accept up to a `/22`.
- **Install on Linux with a desktop shortcut:** `scripts/Install-MystTiqDesktopLinux.ps1` (or
  `.\Build.ps1 DeployDesktopLinux`) copies the Linux download to a Linux machine over SSH, installs it in your home
  folder and puts a MystTiq launcher on the desktop and in the applications menu. Later installs update the same
  shortcut.
- **Upgrades keep accounts:** a new test upgrades from v0.8.25.0 with sign-in on: every account, role, changed password
  and disabled account carries over, and back.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.7.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert: alert rules from earlier versions get the new "out of date" alert switched on.

## Known limitations

This is a development version, not v1.0. The Linux installer doesn't install MystTiq as a service (it runs as the signed-in user). The 11 translations are drafts awaiting native review. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# MystTiq Palworld Server Manager v0.3.0.4 FIX1

## HeadlessHost Compile & Automation Harness Hotfix

The first v0.3.0.4 Windows gate exposed one HeadlessHost compile error and two harness/validation issues.

### Compile fix

`LocalManagementApiHost.WaitForShutdownAsync()` previously attempted to call `WaitForShutdownAsync` directly on `WebApplication`, which resolved to the wrong extension-method family in this build context and produced CS1929.

FIX1 explicitly bridges the `WebApplication` through `Microsoft.Extensions.Hosting.IHost` before calling the generic-host `WaitForShutdownAsync(CancellationToken)` extension.

### Automation harness fixes

- Corrected the deployment-script contract check to match the actual `& .\Build.ps1 LinuxHeadless` invocation.
- Reworked the versioned Linux-acceptance-script lookup in the PowerShell logic harness so the release validator no longer interprets the filename suffix as a stale semantic version.
- Added a regression contract for the explicit `IHost` shutdown bridge.

No authentication, TLS, configuration schema, lifecycle, systemd, PalServer, Linux acceptance, or Windows WPF behavior changed.

# v0.2.14.9 — Final Polish & Release Candidate

## Added
- Release-candidate validation script for repository hygiene, version consistency, XAML resources, XAML handlers, dialog abstraction, and required release documentation.
- `Validate` action in the unified root build script.

## Changed
- `Build.ps1 All` now validates the source tree before compilation and packaging.
- Release preparation stops before compilation when required files, release notes, event handlers, or XAML resources are missing.

## Safety
- Validation is read-only and does not inspect or modify Palworld world data.
- Historical release notes are excluded from stale-version warnings.

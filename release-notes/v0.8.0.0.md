# v0.8.0.0 — Artwork Refresh

First 0.8.x release: your updated graphics from the v0.7.110.1 artwork build, brought into the current version.

- **New navigation icons.** All 26 are distinct crystal-and-metal illustrations with a different shape per page,
  so they are easy to tell apart at a glance.
- **Day and night artwork for every category.** Home, Server, World, Backups, Mods, Tools and System each have
  their own scene in the page header and behind the page, switching with light/dark mode.
- **The header artwork fills the whole card**, right into its rounded corners, on every page. A two-line page
  description now fits instead of being cut off at the bottom.
- **Navigation icons are 10% smaller** (50px instead of 56px) and still sharp.
- **Header no longer crowds the toolbar.** The artwork header has its own space next to the Ribbon, so in a
  small window it never covers the category tabs or commands.
- Everything from v0.7.111.0–v0.7.115.0 is kept: mute alerts, Give Item, teleport points, multi-user login,
  and the deficiency fixes. The artwork was merged into the current code, not the other way round.
- Checked with the artwork build's own 149 rendering checks (run against the merged code), the full test gate,
  and live screenshots of the app.

# MystTiq v0.6.11.0 — Stale-Instance Fix, UI Polish & WAN Reachability Diagnostics

## Highlights

- **Real bug fixed**: a leftover old MystTiq backend from an earlier session could silently be reused instead of the current version starting its own — the reuse check never compared actual version numbers, only a coarse compatibility flag. Fixed: a version mismatch now always starts a fresh backend and tells you plainly that an older instance is still running elsewhere, rather than attaching to it silently.
- **UI polish**: Start button softened to a green style matching Stop's intensity (both toned down), the selected-nav-item color darkened to match the header tab, and a "Palworld Server Manager" tagline added next to the MystTiq wordmark.
- **New WAN / External Reachability diagnostics**: automatically detects your public IP and checks whether your router already has a UPnP port-forward mapping for your game port, with a one-click "Add UPnP Port Mapping" repair. True internet-side reachability confirmation needs a third party this project doesn't control, so that last step is an honest manual hand-off (copy your IP:port, open a well-known port-checker site) rather than a faked pass/fail. Local Windows Firewall inspection/repair for the game port already existed on the Diagnostics Center page from earlier releases — nothing changed there.

## Upgrade notes

- No configuration schema change — an existing v3 `mysttiq.json` loads unchanged.
- New, additive routes: `GET /diagnostics/network/wan`, `POST /diagnostics/network/wan/upnp/repair` (per-profile). Every existing route is unchanged.
- If you were relying on MystTiq silently reusing an old backend process, it will now start its own instead — close the old process manually once you've confirmed the new one is working.

## What's deferred

- Automated confirmation that your game port is actually reachable from the internet — no infrastructure exists to do this honestly without a third party; use the new "Open Port Checker" button for that final manual confirmation.
- TCP reachability checks for RCON/REST API ports — scoped to the game UDP port this pass.
- IPv6/PCP UPnP alternatives, and multi-hop double-NAT discovery.

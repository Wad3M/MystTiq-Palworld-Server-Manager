# MystTiq v0.7.40.0 — MOD Library Layout & Details Panel

## Highlights

- **MOD Library is now a 3-column layout**: Installed MODs and Available Local Steam Workshop Mods side-by-side, matching the v0.2.16.4 reference instead of stacking full-width.
- **New MOD DETAILS panel** shows Overall Health, Installation, Runtime, Compatibility, and Evidence for whichever MOD is selected — nothing showed this before.
- **Install Validated ZIP moved to the top of the page.**

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- The website-sourced MOD description (fetching a description from the mod's source site) stays explicitly out of scope — a separate, deliberate design decision, not part of this release.
- No live GUI verification in this environment — column proportions are reasonable estimates, not pixel-verified.

# MystTiq v0.7.2.0 — Port-Conflict Warnings for New-Server Creation

## Highlights

- When setting up a new server, the Game Port and REST Port fields now check live as you type and show a warning if that port is already in use by another process on the target machine — naming the process where possible.
- Not a hard block: you can still proceed if you know the warning doesn't apply (e.g. a stale listener), but you won't be caught by surprise.

## Upgrade notes

- No configuration schema change. This is the one v0.7.x release that touches the server-side (`MystTiq.Core`/`MystTiq.HeadlessHost`), adding one new read-only diagnostic endpoint — no existing behavior changes.
- Verified live against a real running server and a real occupied port before shipping, not just checked statically.

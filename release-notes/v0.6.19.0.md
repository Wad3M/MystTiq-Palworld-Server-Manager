# MystTiq v0.6.19.0 — True Multi-Tab Server Connections

## Highlights

- **Tabs are now real, independent connections.** Each open tab keeps its own live connection to its own server — switching tabs no longer tears down and reconnects a single shared connection. Every open tab's own status dot updates live, even in the background.
- **"+" now offers a choice**: set up a brand-new server, or connect to an existing saved profile — filtered to exclude any profile already open in another tab, so you can't accidentally open the same server twice.
- Each tab bar item has its own close ("×") button; the last remaining tab can't be closed.

## Upgrade notes

- Background (non-active) tabs keep a lightweight connection/status poll alive but do not refresh full page data (Console, World Explorer, Player Registry, Configuration, etc.) — that still refreshes when you switch to that tab, at the same latency as clicking between nav pages today.
- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- **Disclosed gap**: interactive GUI click-through (opening multiple tabs, confirming independent connections) has not been verified in this environment — verification here is compile-clean plus static contract checks. Please confirm the actual multi-tab behavior once installed.

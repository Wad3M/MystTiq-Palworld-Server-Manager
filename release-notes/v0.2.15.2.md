# MystTiq Palworld Server Manager v0.2.15.2

## UE4SS Runtime & Mod Management Refactor — Phase 2

### Objective
Move live UE4SS MOD operations from the legacy hard-coded `Win64\Mods` assumption to the authoritative Active Mods Root supplied by `Ue4ssRuntimeResolver`.

### Implemented
- `ModService` and `ModScannerService` share a resolver instance when created by the main application.
- Inventory enumerates `ActiveModsRoot`.
- UE4SS ZIP install destinations use `ActiveModsRoot`.
- Enable/disable and apply-enabled reconciliation use `ActiveModsRoot`.
- `mods.txt`, `enabled.txt`, and Repair States operate in `ActiveModsRoot`.
- UE4SS delete and managed-path checks use `ActiveModsRoot`.
- Open Mods Root / Open Selected Mod Folder use `ActiveModsRoot`.
- Server Doctor and dependency checks use resolver-aware UE4SS detection.
- Managed manifest identity recognition accepts active, modern, or legacy paths so legacy manifests remain identifiable without making the legacy path active.

### Not Included
- No automatic migration/copy of legacy mods.
- No destructive legacy cleanup.
- No generalized ZIP wrapper normalization yet.
- No automated runtime mismatch remediation.

Those items remain planned for v0.2.15.3.

# MystTiq v0.7.4.0 — Per-Category Card Flare

## Highlights

- Every page's cards now carry a subtle color accent matching that section's nav category (Home=blue, Server=cyan, World=violet, Backups=amber, Mods=magenta, Tools=orange, System=green) — previously only the Dashboard had any color accents at all.
- The effect is deliberately gentle (a soft border tint + low-intensity glow, not a background recolor) so it adds visual identity without competing with the app's existing status indicators (server health, backup verification, etc.), which are untouched.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- This is the first half of the last item in the v0.7.x UX plan; the "no-scroll" initiative (reducing how much scrolling most pages need) remains a separate, ongoing effort.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

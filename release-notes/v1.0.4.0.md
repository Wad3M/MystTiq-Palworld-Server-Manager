# v1.0.4.0 — Guarded Save Edits: Items

## Remove or add an item in a player's saved inventory

**Players > Inventory in the world save** (admins) shows the selected player's main inventory as the world save holds
it, slot by slot.

- **Remove Selected Stack** takes one stack out.
- **Add To Inventory** puts the item picked in the item list above into the first free slot. The amount box sets how
  many.

Every edit is guarded:
- It only runs while the server is stopped, so nobody is online and the game can't overwrite the change.
- You see what will change and confirm it first.
- A fresh safety backup is taken and checked before anything is touched.
- The edited save is decoded again and must show exactly that one change before it replaces the world. If anything
  fails, the original is put back.
- Each edit is in the Activity log, with the backup's name.

Only plain stacks are edited (coins, ores, Pal Spheres, food and the like). Tools, weapons, armour and eggs carry their
own record in the save, so MystTiq leaves them alone for now. An item can be added only if the world already holds it
as a plain stack somewhere.

## Fixed

After a PalServer crashed or was ended outside MystTiq, backup restores, save edits and MOD changes kept answering "Stop
PalServer first" until the server was started again, even though nothing was running. Pressing Stop on the crashed
server didn't clear it. Restores now work as soon as the server is gone.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.3.0

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

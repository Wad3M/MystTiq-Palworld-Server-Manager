# v0.8.17.0 — The HOST Tab, Process Priority and Eco Mode

- **A new HOST tab.** It shows the machine your server runs on (for a remote server, that machine):
  - processor and memory use, and uptime;
  - each disk's free space, and which disk holds the server, its saves and its backups, with a warning when one is
    nearly full;
  - each network adapter's traffic.
- **Server priority.** Run the server at below normal, normal, above normal or high priority. It is kept through
  restarts and crashes. "Leave as it is" (the default) changes nothing.
- **Eco mode.** Uses less power and leaves the processor to other work:
  - **On:** always;
  - **When no one is online:** after a number of minutes empty, and back to full speed when someone joins.
  On Windows it uses the system's efficiency mode. On Linux it lowers the priority, and going back up needs MystTiq's
  service to run as root.
- Everyone signed in can see the HOST tab; changing priority or eco mode needs Admin.

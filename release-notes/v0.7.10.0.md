# MystTiq v0.7.10.0 — Whitelist System

## Highlights

- **Whitelist**: opt-in per-server allow list. Enable it and add Steam/UserIDs — anyone who connects who isn't on the list is automatically kicked, checked on the same 5-second cadence the rest of MystTiq's player monitoring already uses. Disabled by default, so nothing changes unless you turn it on.
- This is the last of the verified feature gaps from this session's survey of other Palworld server-management tools — with this, the v0.7.6.0→v0.7.10.0 sequence (bug fixes + feature parity) is complete.

## Upgrade notes

- No configuration schema change beyond the new whitelist file (`whitelist.json` under each server's runtime data directory) — nothing existing is affected, and the feature is off by default.
- Enabling the whitelist without adding any entries first will kick every online player — add your allowed players before enabling.

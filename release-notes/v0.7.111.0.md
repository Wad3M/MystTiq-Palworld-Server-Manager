# v0.7.111.0 — Alert Mute and Crash Alert Settings

First of the four items pulled into 0.7.x on 2026-09-22 (crash-alert mute/per-profile, Give Item, player
teleport points, multi-user login).

- **Crash Alerts** settings on the Alert Center page: switch crash-recovery alerts off, or keep them but
  drop the "server is back up" notices. Each server profile has its own.
- **Mute Alerts**: mute everything for this server for 1 hour, 8 hours, 24 hours or 7 days, for example
  during maintenance. A mute always ends by itself (capped at 30 days); Unmute ends it early. Anything still
  wrong when the mute ends alerts then, and anything that cleared during it sends its "Resolved" notice.
- Crash recovery itself is unaffected: a muted server is still restarted. Crash alerts skipped during a mute
  are written to the Activity log. A DOWN notice pinned before a mute still unpins once the server is back.
- Checked with 3 new logic-harness scenarios, a live smoke with a real crash while muted, and in the Desktop
  on the Clone profile (the Default Server was confirmed unaffected).

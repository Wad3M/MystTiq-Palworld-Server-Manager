# MystTiq Palworld Server Manager v0.3.1.3 FIX2

The v0.3.1.3 monitoring code compiled far enough to expose a packaging regression: `Build-LinuxHeadless.ps1` requires release-version-matched Linux acceptance and production-readiness scripts, but v0.3.1.3 still contained only the legacy v0.3.0.7 runners.

FIX2:

- adds `Test-v0.3.1.3-LinuxAcceptance.sh`
- adds `Test-v0.3.1.3-ProductionReadiness.sh`
- removes the obsolete v0.3.0.7 Linux gate scripts from the full-source baseline
- updates the ChangedFiles cleanup helper to remove those legacy files after overlay installation
- extends Linux acceptance to verify:
  - `/api/v1/players`
  - `/api/v1/logs/tail`
  - `/api/v1/metrics`
  - JSON payload contracts
  - absence of `AdminPassword` in the player response

No desktop GUI behavior or PalServer lifecycle behavior changed.

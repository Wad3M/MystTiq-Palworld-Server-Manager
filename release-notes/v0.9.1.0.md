# v0.9.1.0 — Status and Error Messages in 12 Languages

- **The app's messages follow your language:** server states ("Stopped / Not ready"), progress ("Restoring backup…"),
  results, warnings and errors, time ranges, drop-down choices, confirmation dialogs and file-picker titles are now
  shown in the chosen language, not just the labels around them. 1,113 messages in each of the 12 languages.
- **Values stay as they are:** names, numbers, times and paths filled into a message are kept ("Restarted. 'Frostbound'
  is now online." becomes 「Frostbound」が稼働中です in Japanese), and a value that is itself a message is translated
  too ("Status: Stopped / Not ready").
- **Nothing changes underneath:** the app still works with the English messages internally, so every check, filter
  and automation behaves exactly as before. English is shown exactly as before.
- **Kept English on purpose:** your server and world names, the in-game restart command, date formats and place names.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.0.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration.

## Known limitations

This is a development version, not v1.0. Messages sent by the MystTiq service itself (Doctor findings, server replies), a few messages the app builds from several pieces (the map's marker summaries, uptime) and the game's item and Pal names are still English (v0.9.2.0). The 11 translations need native review. On Linux, file pickers and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need the live scripts to be run with a player and real channels. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# v0.7.95.0 — Discord Bot: Live Status, Join/Leave Feed, Autocomplete, More Commands

First of the "enhancements to features we already have".

Reading the bot first showed per-Discord-role permission mapping **already exists**, so that was not built.
What was genuinely missing, and is now added:

- **Live status message:** give the bot a channel and it keeps one self-updating message there (server state,
  player count and names). Survives restarts; edited, not re-posted.
- **Presence:** the bot shows "Watching N players online" (toggle).
- **Events feed (optional channel):** players joining/leaving and server online/starting/stopped/crashed.
  Never mistakes a restart for everyone leaving.
- **Kick/Ban autocomplete:** start typing a name and pick the online player; no raw player id to copy.
- **New commands:** `/mysttiq-save`, `/mysttiq-backup` (Operator), `/mysttiq-unban` (Admin).
- **Safety fix:** bot replies and posts no longer allow mentions, so a player named `@everyone` cannot ping
  your Discord server. This also fixes the existing `/mysttiq-players` and `/mysttiq-status` replies.
- New fields on the Discord Bot card: live status channel ID, events channel ID, presence toggle. A mistyped
  channel ID is refused with a reason. An existing saved bot config keeps working unchanged.

Not verified against real Discord (no bot token here): the first run in a test server is the true test. The
bot needs View Channel, Send Messages and Embed Links in the configured channels.

Touches `MystTiq.Core`, `MystTiq.HeadlessHost` and `MystTiq.Desktop`. See
[`docs/architecture/v0.7.95.0-discord-bot-live-features.md`](../docs/architecture/v0.7.95.0-discord-bot-live-features.md).

# v0.5.1.1 — Home Navigation Refinement

This fix responds to the approved prototype reference after v0.5.1.0 promotion.

- Home now contains Dashboard and Notifications.
- System now contains Settings and Activity & Audit.
- Dashboard and Notifications use a compact Home row with a blue glass selected state rather than the former large filled Dashboard row.
- The top notification bell still opens the persistent Notifications page.
- Notification data and mutations remain View → ViewModel → API client → route → headless notification service.
- All v0.5.1.0 architecture, security, polling, containment, button and Windows/Linux guarantees remain unchanged.

Promotion requires the complete strict validation, logic, Windows/Linux build, runtime smoke, rendered UI verification and package checksum gate.

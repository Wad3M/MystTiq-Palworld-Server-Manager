# MystTiq Palworld Server Manager v0.3.0.1 FIX1

## Linux Lifecycle Compile Contract Hotfix

The first v0.3.0.1 compile exposed two contract/analyzer issues in the new Linux lifecycle layer.

### Fixed

1. `LinuxServerLifecycleService` consumes `FindProcessesByName(...)`, which already existed on `LinuxServerSessionInspector`, but the method was missing from the shared `IServerSessionInspector` contract.

   FIX1 adds:

   ```csharp
   IReadOnlyList<ServerSessionProcessInfo> FindProcessesByName(IEnumerable<string> names);
   ```

   to the core interface.

2. `File.SetUnixFileMode(...)` is intentionally used by the Linux-only detached-launch implementation. The cross-platform core analyzer could not infer that the lifecycle class is Linux-only from its constructor guard.

   FIX1 marks `LinuxServerLifecycleService` with:

   ```csharp
   [SupportedOSPlatform("linux")]
   ```

   so CA1416 correctly understands the platform boundary.

### Scope

No lifecycle policy changed. Start, stop, restart, SIGTERM/SIGKILL escalation, process/port readiness, crash evidence, paths, and exit codes are unchanged.

The v0.3.0.1 harness now checks both contracts to prevent regression.

# MystTiq Palworld Server Manager v0.2.14.11

## Update Center & UI Reliability

### Implemented

- Polished the Update Center check action to use the standard MystTiq refresh semantic style and tooltip language.
- Preserved existing action-specific semantic colors for update, install, verify, source, retry, and management actions.
- Added an explicit Admin Commands runtime status refresh action to the Console page.
- Admin Commands refresh now re-evaluates the newest retained server-session evidence instead of relying only on a newly arriving log line.
- Console Refresh now also synchronizes the Admin Commands status badge.
- Admin Commands status is only shown as loaded when the server is running and retained evidence confirms a successful runtime load.
- Audited global mouse-wheel routing for nested ScrollViewer, DataGrid, ListBox, and multiline TextBox controls.
- Scroll routing now respects disabled scroll directions, Windows wheel-line settings, smooth touchpad deltas, nested scroll boundaries, and Shift+wheel horizontal scrolling.

### Scope Control

- No application redesign.
- No architecture replacement.
- No unrelated feature additions.
- Existing MystTiq dark theme, tooltip conventions, semantic colors, and responsive layout patterns were preserved.

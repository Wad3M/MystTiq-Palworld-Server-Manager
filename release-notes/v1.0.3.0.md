# v1.0.3.0 — Packaging and Read-only Access

## A read-only view in any browser

- MystTiq's service now serves a page at `/web` on its own address (for example `https://your-host:8213/web`). Sign in
  with a MystTiq account to see each server's status, who is online and the latest backups. It refreshes every 30
  seconds.
- It cannot change anything. MystTiq refuses every change made from a browser session, whatever the account may do in
  the desktop. Your account's role still decides what you may see.
- It needs authentication switched on (remote access), and from another computer, TLS, like any remote use of
  MystTiq. **Security** in the desktop shows the address.

## A Docker image

- The headless service now comes as a Linux container image (`deploy/docker`). Everything it keeps (configuration,
  server files, backups, its API token and TLS certificate) is in the folder you mount at `/data`.
- On the first start it creates its configuration, an API token and a TLS certificate there, and serves the API on port
  8213 over TLS with that token.
- It installs and runs the Linux Palworld server inside the container through the usual Update Center action.

## Xbox players

Before building anything for Xbox players, MystTiq records what the server shows for one. The script and the procedure
are ready (`scripts/Discover-v1.0.3.0-XboxPlayer.ps1`) and wait for a session with an Xbox account on the test server.

## Fixed on the way

- A SteamCMD that has just installed itself sometimes fails its first server install with "Missing configuration".
  MystTiq now runs it once more, which works. This was found installing the server into a new container.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.2.0

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

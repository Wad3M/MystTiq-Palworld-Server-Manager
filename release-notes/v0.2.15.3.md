# MystTiq Palworld Server Manager v0.2.15.3

## UE4SS Legacy Migration & ZIP Normalization — Phase 3

Official baseline entering this phase: **v0.2.15.2 FIX1**.

### Implemented
- Safe copy-first migration from legacy `Win64\Mods` to the resolver-selected Active Mods Root.
- Legacy source copies are retained.
- Existing active files are never overwritten when content differs; conflicts are reported.
- Known UE4SS runtime-component folders are skipped.
- MOD Dashboard includes `MIGRATE LEGACY MODS` with MystTiq warning semantics and tooltip guidance.
- UE4SS ZIP layouts normalize `ue4ss\Mods\<Mod>`, `Mods\<Mod>`, and normal wrapped MOD layouts into `<ActiveModsRoot>\<Mod>`.
- Generic `Mods/` archive routing no longer deploys to hard-coded `Win64\Mods`.

### Safety
This phase does not delete legacy MOD copies. PalServer must be stopped before the migration action will run.

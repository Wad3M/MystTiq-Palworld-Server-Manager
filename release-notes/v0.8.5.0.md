# v0.8.5.0 — Display Language (first slice)

- **Choose your language.** Settings → Appearance now has a Language picker: English, Deutsch or Español. It
  switches at once, with no restart, and is remembered on this computer.
- **Translated so far:** the category tabs, the navigation and every page's title and subtitle. The rest of the app
  is still in English, and Settings says so. More will follow.
- **English is unchanged**, and it fills in for anything a translation is missing, so you'll never see a blank label.
- **Adding a language** is one translation file. The release checks fail if a language is missing any text.
- The German and Spanish were written for this release and haven't yet been checked by a native speaker.
- **Tested:** in the offline test harness, German and Spanish were switched live and the longer tab names still fit
  at the smallest window size. In the live app, the language was switched to German, reopened in German, and
  switched back to English.

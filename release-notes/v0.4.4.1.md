# MystTiq v0.4.4.1

Fix release for the v0.4.4 Server / Configuration / Console / Workspace integration.

## Fixes

- Adds bounded LAN discovery of MystTiq headless services using `/healthz`.
- Keeps remote management security intact; discovery does not bypass bearer-token or TLS/pinning requirements.
- Makes expanded Avalonia navigation rows uniformly sized and reduces child indentation so labels fit consistently.
- Restores/guarantees the current version logic test in release packages.
- Adds stronger version/package/discovery/navigation logic contracts.

This remains a release candidate until the complete promotion gate passes on the target Windows/Linux environments.

## Gate fixes

- Corrected false-positive WPF detection caused by the valid cross-platform `System.Windows.Input.ICommand` namespace.
- Restored version-matched Linux acceptance/production-readiness scripts.
- Added successful Windows desktop publish auto-launch with an unattended-build opt-out.

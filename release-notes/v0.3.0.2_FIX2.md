# MystTiq Palworld Server Manager v0.3.0.2 FIX2

## systemd Start-Limit Section Hotfix

Ubuntu 24.04.4 LTS runtime validation exposed that `StartLimitIntervalSec=300` was incorrectly emitted under `[Service]`, causing systemd to ignore it.

FIX2 moves both `StartLimitIntervalSec=300` and `StartLimitBurst=5` to `[Unit]`. `Restart=on-failure` and `RestartSec=10` remain under `[Service]`.

No lifecycle, recovery algorithm, PalServer launch, or Windows WPF behavior changed.

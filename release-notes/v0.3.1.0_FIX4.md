# MystTiq Palworld Server Manager v0.3.1.0 FIX4

## RunBuild Block Boundary Hotfix

All real v0.3.1.0 FIX3 gates passed:

- validation: 0 errors / 0 warnings
- Windows Avalonia desktop publish: PASS
- Linux Avalonia desktop publish: PASS
- release validation: PASS

One FIX3 regression assertion still failed because its source scanner used:

```powershell
$self.Substring($runBuildStart)
```

That captured the actual `if($RunBuild){...}` block plus the remainder of the harness. The later regression assertion itself contains the text `$LASTEXITCODE`, so the check falsely reported that the RunBuild block still used it.

FIX4 isolates the actual RunBuild block between `if($RunBuild){` and the report-generation section before evaluating the build-gate semantics.

No Avalonia application, headless service, WPF, API, lifecycle, TLS, systemd, PalServer or Production Doctor behavior changed.

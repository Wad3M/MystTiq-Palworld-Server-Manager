# v0.9.3.0 — The Service's Messages in Your Language

- **The service speaks your language too:** messages that come from the MystTiq service are now shown in the
  language you picked, like the app's own. That covers Doctor findings, operation results, crash explanations and
  what to try, network and router checks, recovery and restore steps, and configuration errors: 1,339 more messages
  in all 11 languages.
- **Values stay as they are:** server names, ports, paths, process ids and error details inside a message are kept,
  and translated too when they are themselves a known message.
- **Some things stay English on purpose:** commands sent to the game server (KickPlayer, TeleportToMe…), log patterns
  the crash analysis looks for, protocol text, and the names Windows shows for the MystTiq service and its firewall
  rules, so they still match what you see in the game, in logs and in Windows.
- **Help for reviewers:** `scripts/Export-MystTiqTranslationReview.ps1` writes a review sheet per language (every text,
  the English beside it, where it is used, a column for corrections), and `docs/i18n/TRANSLATION_REVIEW.md` is the
  checklist. The translations are still drafts awaiting native review.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.2.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert: the service still sends English, and the Desktop translates it as it is shown.

## Known limitations

This is a development version, not v1.0. The 11 translations are drafts that need native review; dates and numbers still use one fixed format. A message the service sends that is not in the catalog (a new one, or an error text from Windows, Linux or the game) is shown in English. On Linux, file pickers and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need the live scripts to be run with a player and real channels. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# v0.7.109.0 — Map: Spreading Out Exactly-Coincident Markers

Thirteenth of the "enhancements to features we already have". The one residual gap v0.7.106.0's own doc named:
two markers at the exact same screen position still rendered as a single icon, since that version only ever
staggered labels, never the dots.

- Markers at (or extremely near) the exact same pixel now fan out a few pixels around that point instead of
  stacking invisibly on top of each other. The first marker in a coincident group stays exactly on its real
  position; the others fan out around it.
- Anything with real separation is completely untouched — this is strictly for the "same pixel" case, using a
  much tighter radius than the existing label-collision fix.
- Checked with a new logic-harness scenario and live on the real Map page: a cluster of offline players that
  was a single invisible-behind-itself ring now shows as 4 distinct rings, while a nearby base with real
  separation stayed exactly where it was.

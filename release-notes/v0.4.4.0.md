# MystTiq v0.4.4.0 — Server / Configuration / Console / Workspace Integration

v0.4.4.0 is the first release candidate after the promoted v0.4.3.1 baseline.

## Highlights
- One aggregate headless status-poll endpoint supplies lifecycle, service, players, metrics, and log-tail state to the desktop polling loop.
- The Avalonia shell has a persistent bottom status bar with last-update evidence and an indeterminate animation while work is active.
- Workspace is no longer a placeholder: it exposes managed server, SteamCMD, backup, and runtime paths through the existing configuration API path.
- Server lifecycle remains headless/API-owned and cross-platform; the GUI does not directly launch or terminate PalServer.
- Release logic tests trace View → ViewModel → API/service → endpoint → Core/platform wiring and preserve Windows/Linux build gates.

## Promotion
Do not promote until Validate reports 0 errors / 0 warnings and all logic, regression, Windows/Linux build, packaging, checksum, and runtime acceptance gates pass.

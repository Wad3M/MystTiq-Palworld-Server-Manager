# MystTiq v0.6.8.0 — MOD/UE4SS Platform & Monitoring

## Highlights

- **MOD Backup & Rollback.** Every MOD install or delete now automatically captures a pre-mutation snapshot. A new "Rollback Selected" action restores a MOD to exactly what it looked like before your last change — or, for a MOD that was just installed for the first time, removes it entirely.
- **Alert Center now watches MOD/UE4SS health.** When an enabled MOD's health degrades (Failed/Missing/Misconfigured/Attention), a real notification fires naming the specific MOD(s) — no need to check the MOD Dashboard yourself to find out.

## Upgrade notes

- No configuration schema change — an existing v3 `mysttiq.json` loads unchanged.
- New, additive route: `POST /api/v1/mods/{type}/{package}/rollback`.
- `GET`/`PUT /api/v1/alerts/rules` gains an additive `ModHealthDegraded` field (enabled by default); existing rule fields are unchanged.

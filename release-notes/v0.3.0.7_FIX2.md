# MystTiq Palworld Server Manager v0.3.0.7 FIX2

## Extended Production-Readiness Integration Hotfix

The v0.3.0.7 FIX1 Windows gate compiled and validated successfully, but the logic harness exposed one remaining integration defect:

```text
Automation :: Extended Linux acceptance invokes production readiness
Missing: Production-readiness integration gate
```

The production-readiness runner existed and was packaged, but the Linux acceptance script never actually invoked it.

FIX2 adds the missing integration.

When `Test-v0.3.0.7-LinuxAcceptance.sh --extended` runs, it now:

1. resolves `Test-v0.3.0.7-ProductionReadiness.sh` beside the acceptance runner
2. passes the exact MystTiq executable path using `MYSTTIQ_APP`
3. passes the effective configuration path using `MYSTTIQ_CONFIG`
4. runs the production-readiness gate
5. captures its output into the timestamped acceptance report
6. records PASS when readiness succeeds
7. records FAIL when the runner is missing or returns failure

A production-readiness failure therefore contributes to the final Linux acceptance failure count and prevents promotion.

No runtime API, lifecycle, systemd, TLS, PalServer, or Windows WPF behavior changed.

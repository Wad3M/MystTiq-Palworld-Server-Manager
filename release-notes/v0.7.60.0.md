# MystTiq v0.7.60.0 — Port Conflict Prevention & UE4SS Version Tracking

## Highlights

- **Starting a server on a port that's already in use now fails clearly and immediately**, instead
  of silently launching a process that spins up but can never actually bind its game port — a state
  that looked exactly like an unexplained hang. Found directly while investigating this session's
  own PalServer launch freeze.
- **UE4SS version checking is now real.** Update Center could previously report UE4SS as current
  when it wasn't, because there was never a reliable version to compare against. Installing UE4SS
  through MystTiq's own install flow now records exactly which release was applied, enabling a
  genuine up-to-date/update-available comparison going forward.

## Upgrade notes

- No configuration changes, no data migration for existing installs.
- The port-conflict check only covers the game port (matching the existing readiness-check scope),
  not the REST API or RCON ports.
- Real version comparison for UE4SS only works for installs done through MystTiq's own Install flow
  going forward — an existing install (or one copied in manually) still shows "Check manually" until
  reinstalled through MystTiq once.
- No way to visually render this app in the environment that built it — please confirm the port
  conflict error surfaces clearly, and confirm Update Center reports UE4SS accurately after a real
  install.

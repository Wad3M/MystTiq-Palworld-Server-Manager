# MystTiq v0.7.55.0 — Website-Sourced MOD Descriptions

## Highlights

- **MOD Library's MOD DETAILS panel can now fetch a real description of what a MOD does**, not just
  its installed/health evidence. Click Fetch/Refresh on the selected MOD to load it.
- **Two real sources**: Steam Workshop items are matched and described automatically (a real Steam
  Web API call). MODs with no Workshop match (most UE4SS/Lua mods) can have a Source URL set
  manually — a GitHub repository URL gets a real fetched description too; any other link is saved
  and shown as-is.
- **Fetches only ever happen when you click Fetch/Refresh.** Nothing is fetched automatically —
  not on selecting a MOD, not on opening the page. Results are cached so repeat views are instant.

## Upgrade notes

- No configuration changes. Purely additive — two new routes, one new panel section.
- The only outbound network calls this adds are read-only, unauthenticated requests to Steam's and
  GitHub's own public APIs, made only when you click Fetch/Refresh.
- Nexus Mods is not a supported source yet — no public, keyless API exists for it. A MOD from Nexus
  can still use the manual Source URL field; it just shows as a plain link rather than a fetched
  description.

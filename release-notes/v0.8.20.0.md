# v0.8.20.0 — Host History

- **The HOST tab has a history.** It charts the machine's processor, memory and network upload over the last hour,
  24 hours or 7 days, with averages and peaks. For example: "Processor 27 % on average, peak 80 % · busiest upload
  9.6 Mbit/s".
- MystTiq takes a reading every minute and keeps a week of them, so the history is there after a restart.

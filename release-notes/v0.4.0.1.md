# MystTiq v0.4.0.1 — Network Diagnostics & Connectivity Recovery

Adds independent runtime/network health, effective game-port resolution, PID-aware UDP ownership, 0.0.0.0 interpretation, LAN endpoint resolution, Windows Firewall inspection/repair, wrong-process/wrong-port detection, startup grace, optional RCON/REST checks, controlled restart with post-restart verification, diagnostics API endpoints, and an Avalonia Diagnostics page.

The real-world regression remains explicit: PalServer can be running while UDP 8211 is absent; that state is Network ERROR and recommends a controlled restart. A post-restart 0.0.0.0:8211 PalServer-owned binding is healthy.

Firewall mutation is restricted to the stable MystTiq-owned rule name. Normal tests do not alter the real firewall.

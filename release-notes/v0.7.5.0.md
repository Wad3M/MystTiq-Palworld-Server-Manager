# MystTiq v0.7.5.0 — No-Scroll Initiative, Pass 1

## Highlights

- **Real bug fixed**: the Settings page's "Managed Server / Headless Configuration" and "Security" cards used to render underneath every step of the new-server wizard, even before a profile existed to configure. They now correctly stay hidden until you're editing an actual saved profile.
- **Denser everywhere**: card padding, button/text-field height, and the space between cards on every page are all slightly tighter — no content removed, just less wasted space.
- **Six sections now collapse by default**: Players' World Map and Pal Editor, Diagnostics Center's WAN Reachability and Local Machine Diagnostics, and Alert Center's Discord Bot and Anti-Cheat sections all start collapsed (one click on their header to expand) since each is a large, occasional-use tool rather than a page's primary content.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- This is the first of an expected series of no-scroll passes — the Simple Settings tile layout, the Doctor page, and Alert Center's page structure are all explicitly deferred to future passes.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

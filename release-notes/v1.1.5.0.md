# v1.1.5.0 — Resizable Window, Simple Mode, Installer and Portable

## Choose how you install it (Windows)

- **Setup (`.msi`)**: installs MystTiq for everyone on the PC in `Program Files\MystTiq`, with a Start-menu shortcut,
  an optional desktop shortcut and an entry in Apps & features. A newer setup replaces the older install and keeps your
  settings. Uninstalling removes the program only: servers, backups and settings are kept. If you installed MystTiq's
  Windows service from the installed folder, the setup stops it while it replaces the files and starts it again; a
  service installed from anywhere else is left alone. The Update Center updates an installed copy with the next setup.
  The setup is not code-signed yet, so Windows SmartScreen asks before running it ("More info", then "Run anyway").
- **Portable (`Windows-x64-Portable.zip`)**: extract it anywhere you can write, even a USB drive. Everything MystTiq
  saves stays in the `data` folder beside it, and it writes nothing to Windows: it does not start with Windows, take
  Nexus links or install a Windows service. If another MystTiq already uses port 8213, the portable copy picks its own.
  To update it, extract the new portable ZIP and move your `data` folder into it (the Update Center downloads it and
  says so).
- **ZIP (`Windows-x64.zip`)**: as before.

## A window you can size

Drag any edge or corner of the window to size it, down to 950 × 650. MystTiq remembers its size, position and whether it
was maximized, and puts it back next time. If that screen is gone, it opens on one that is there.

## Simple and Advanced

A switch in the title bar (also in **Settings > Appearance**) chooses **Simple** or **Advanced**. Click it to change.

- **Simple** is for setting a server up, choosing its settings and starting it. It keeps the Dashboard, Server Setup,
  the Configuration page's simple settings, Backups and Settings, and hides everything else: the World, MODs, Tools and
  HOST tabs, the other menu pages, the Console, Doctor and Force Stop buttons, and the Dashboard's monitoring panels.
  The Dashboard shows a three-step guide with **Open Server Setup**, **Open Configuration** and **Start the server**.
- **Advanced** shows everything, as before. It is the default.

Simple hides things but disables nothing: a button that leads to a hidden page still opens it. Your choice is remembered
on this PC.

## The Dashboard's top row

- The **update card** now covers MystTiq too: **MystTiq 1.1.5.0** with its own **Update MystTiq** (the setup for an
  installed copy, the portable ZIP for a portable one, the ZIP otherwise), and the **Palworld server** build with
  **Update Server**, each with a tag.
- The **local and public addresses** moved up into their own card between LIFECYCLE and the update card.
- The title bar's **Simple / Advanced** switch works with one click (owner 2026-10-23: "the advanced button doesnt do
  anything"): Settings' Simple/Advanced list reloaded on every change and set the mode straight back.
- The top row stays on screen while MystTiq's service is not connected (owner 2026-10-23: "missing the top cards when
  the server is not started"). Behind it: after the install the helper's first start took longer than the desktop's
  8-second wait, and the desktop never tried again until Refresh was clicked. A helper it has just started now gets 45
  seconds while it runs, and a disconnected local tab asks the service every 10 seconds and connects once it answers.
- On the Configuration page, **Simple Settings** (blue) and **Advanced Settings** (amber) have different colours, and the
  title bar's switch matches them: blue while it says Simple, amber while it says Advanced.
- **Configuration fills itself in** from the server's `PalWorldSettings.ini`, with the server running or not (owner
  2026-10-24). Opened while MystTiq was still starting (it reopens on the page it was left on), it used to stay on
  "Not loaded"; it now waits for the start-up work and then reads the settings.
- After connecting, the status box no longer keeps the old "Nothing answers…" line, and while MystTiq is not connected
  the update card says "Server build —" instead of leaving the line empty.
- New screenshots in the README, including the Dashboard in Simple mode.

## Upgrading from v1.1.4.0

Back up your server data and configuration. Then either run the setup (your settings in ProgramData and AppData carry over), or extract the ZIP into a new folder as before (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder. Nothing to convert. Moving to the portable copy starts with fresh settings in its own `data` folder; reconnect your servers there. Coming from an older version, also read the [v1.1.4.0](v1.1.4.0.md), [v1.1.1.0](v1.1.1.0.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

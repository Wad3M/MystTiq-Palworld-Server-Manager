# v1.1.5.0 — Resizable Window, Simple Mode, Installer and Portable

## Choose how you install it (Windows)

- **Setup (`.msi`)**: installs MystTiq for everyone on the PC in `Program Files\MystTiq`, with a Start-menu shortcut,
  an optional desktop shortcut and an entry in Apps & features. A newer setup replaces the older install and keeps your
  settings. Uninstalling removes the program only: servers, backups and settings are kept. If you installed MystTiq's
  Windows service from the installed folder, the setup stops it while it replaces the files and starts it again; a
  service installed from anywhere else is left alone. The Update Center updates an installed copy with the next setup.
  The setup is not code-signed yet, so Windows SmartScreen asks before running it ("More info", then "Run anyway").
- **Portable (`Windows-x64-Portable.zip`)**: extract it anywhere you can write, even a USB drive. Everything MystTiq
  saves stays in the `data` folder beside it, and it writes nothing to Windows: it does not start with Windows, take
  Nexus links or install a Windows service. If another MystTiq already uses port 8213, the portable copy picks its own.
  To update it, extract the new portable ZIP and move your `data` folder into it (the Update Center downloads it and
  says so).
- **ZIP (`Windows-x64.zip`)**: as before.

## A window you can size

Drag any edge or corner of the window to size it, down to 950 × 650. MystTiq remembers its size, position and whether it
was maximized, and puts it back next time. If that screen is gone, it opens on one that is there.

## Simple and Advanced

A new switch in the title bar (also in **Settings > Appearance**) chooses **Simple** or **Advanced**:

- **Simple** shows the everyday pages: the Dashboard, Server Setup and the Configuration page's simple settings,
  Players, Guilds, Bases and the Map, Backups, MOD Library and MOD Sources, the Update Center and the Doctor,
  Settings, Notifications, the Alert Center and Automation (without the rule editor).
- **Advanced** shows everything, as before. It is the default.

Simple hides pages from the menus but disables nothing: a button that leads to a hidden page still opens it. Your choice
is remembered on this PC.

## Upgrading from v1.1.4.0

Back up your server data and configuration. Then either run the setup (your settings in ProgramData and AppData carry over), or extract the ZIP into a new folder as before (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder. Nothing to convert. Moving to the portable copy starts with fresh settings in its own `data` folder; reconnect your servers there. Coming from an older version, also read the [v1.1.4.0](v1.1.4.0.md), [v1.1.1.0](v1.1.1.0.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

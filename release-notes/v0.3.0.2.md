# MystTiq Palworld Server Manager v0.3.0.2

## Linux Service & Automatic Recovery Foundation

v0.3.0.2 turns the experimental Linux headless host into a boot-capable background service.

### New commands

```bash
./mysttiq-server service-status
sudo ./mysttiq-server service-install
sudo ./mysttiq-server service-install --start-now
sudo ./mysttiq-server service-uninstall
```

The installed service runs:

```text
/opt/mysttiq/bin/mysttiq-server service-run
```

under `mysttiq-palworld.service`.

### Supervision model

systemd supervises MystTiq. MystTiq supervises PalServer.

The long-running supervisor starts or adopts PalServer, monitors the native process and guarded-port evidence, performs bounded automatic crash recovery, and exits non-zero if its recovery budget is exhausted so systemd can apply its own `Restart=on-failure` safety net.

### Shutdown

SIGTERM/SIGINT cancels the long-running supervisor and invokes the established graceful PalServer stop path before the MystTiq service exits.

### Logging

```bash
journalctl -u mysttiq-palworld
```

shows MystTiq service/supervisor output.

PalServer detached-console output remains:

```text
/opt/mysttiq/runtime/palserver-console.log
```

Lifecycle state remains:

```text
/opt/mysttiq/runtime/lifecycle-state.json
```

### Reference environment

Primary validation target:

- Ubuntu Server 24.04.4 LTS
- x86_64 / amd64
- observed kernel 6.8.0-137-generic
- systemd
- service account `mystroth`
- Valve Linux SteamCMD
- Palworld App 2394010 / Linux depot 2394012

Windows WPF behavior remains unchanged. Relevant service/supervisor discoveries are tracked for v0.4.

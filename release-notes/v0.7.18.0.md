# MystTiq v0.7.18.0 — Player Directory Name Deduplication

## Highlights

- **A new "Hide duplicate names" checkbox on the Players page.** When the same player shows up more than once under the same name — a rejoin under a different platform ID, a stale record from an old save — only the best match (online, then has a save, then most recently updated) stays visible.
- **Nothing is deleted or merged.** This only hides rows from the list; uncheck the box and every record is back instantly.
- The visible-count line now says how many duplicates are currently hidden, so a shorter list doesn't read as "fewer known players."

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- The toggle doesn't persist across restarts, matching every other filter already on this page.

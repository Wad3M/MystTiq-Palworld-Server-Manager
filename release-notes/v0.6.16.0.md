# MystTiq v0.6.16.0 — Live World Map (Player Positions)

## Highlights

- **New: Live World Map.** The Players page now shows a live-updating world map plotting every online player's real position, refreshed on the existing 5-second status poll. The single most common feature the v0.6.15.0 competitive survey found MystTiq lacking (six separate competitor tools have it).
- No new data source: Palworld's own REST API (`GET /v1/api/players`) already returns real `location_x`/`location_y` per online player on the exact poll MystTiq was already running — the fields were simply never captured until now.
- Ships with a plain coordinate-grid background. You can drop in your own sourced/licensed map image via "Browse for Map Background" on the World Map card at any time — Palworld's actual in-game map art is Pocketpair's copyrighted asset, so MystTiq doesn't embed or trace it.

## Upgrade notes

- No configuration schema change — an existing v3 `mysttiq.json` loads unchanged.
- No new server routes — this rides the existing player-status poll path (`GET /players` / aggregate status). The map background preference is stored locally on the Desktop machine only, never sent to or stored by the server.

## What's deferred

- Wild Pal positions — not exposed by Palworld's REST API at all.
- Base positions — needs new `Level.sav` decode work this codebase doesn't yet do; deferred pending its own investigation.
- Two-way Discord bot control and anti-cheat/save-integrity scanning are scoped as the next releases — see `docs/architecture/v0.6.15-plus-competitive-survey.md` for the full comparison this roadmap came from.

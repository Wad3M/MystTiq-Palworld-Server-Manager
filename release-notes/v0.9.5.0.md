# v0.9.5.0 — Upgrade and Recovery

- **Servers no longer start each other:** on a machine with several server profiles, a server starting or stopping
  could make MystTiq think the other servers had crashed, and start them, even ones you had stopped on purpose. Each
  server now only ever looks at its own process, so a stop holds.
- **The update check tells the truth:** the Update Center compares your Palworld server with the build Steam is
  actually publishing, so a server one update behind shows "update available". Before, it always said "Up to date", and
  players on the new game version could not join. PalDefender now has its own row with its latest release, and the
  Doctor warns (on the Dashboard's health line) when your server is behind Steam, or when PalDefender says it isn't
  updated for the game version yet.
- **Updates get past a refused download:** when Steam refuses the files of the build you have installed ("Access
  Denied"), MystTiq checks every file against the new build instead and only downloads what changed. A failed update
  now says why, instead of "exit code 8".
- **Servers become ready on the right port:** MystTiq now waits for the port your server really uses (its `-port=`
  launch argument), not the one it only advertises, so a server with those two set differently no longer restarts in
  a loop.
- **Upgrades tested end to end:** the settings and data of the accepted v0.8.25.0 carry over, backups verify and
  restore byte for byte, going back to v0.8.25.0 works, and a fresh setup starts.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.4.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. The first Update Center check runs SteamCMD once (a few seconds); later checks use its answer for 15 minutes.

## Known limitations

This is a development version, not v1.0. There is no notification yet when a component falls behind (the Doctor warning and the Update Center show it), and UE4SS's installed release is still compared by hand. Updating PalDefender is a manual step: MystTiq tells you when and where. The 11 translations are drafts awaiting native review. On Linux, file pickers and installed-service priority recovery still need acceptance. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

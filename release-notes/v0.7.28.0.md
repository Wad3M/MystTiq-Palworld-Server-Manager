# MystTiq v0.7.28.0 — New Ribbon Actions

## Highlights

- **Force Stop Server** is now reachable from every page via a new "Danger" ribbon group — previously only fired automatically when closing the app while a server was running.
- **Install Missing** added to Server Setup's ribbon group — previously only reachable indirectly through the component checklist's per-row action.
- **Server Doctor** now shows the real managed processes (name + PID) for the active server, with a "Kill Processes" ribbon action to force-terminate them.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- Force Stop / Kill Processes bypass PalServer's normal graceful shutdown — use Stop for a clean shutdown when possible; Force Stop is for when a server is unresponsive.

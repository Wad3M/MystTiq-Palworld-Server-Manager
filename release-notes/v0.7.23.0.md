# MystTiq v0.7.23.0 — Specific Background-Tab Connection Errors

## Highlights

- **Background tabs now report what actually went wrong**, not just a generic "Connection failed." An incompatible API version and a missing bearer token each get their own specific message — the exact same distinction the active tab's own connection check already made, now applied to background tabs too.
- **The tab's red error dot still shows correctly** for these new, more specific failure states — no visual regression from this change.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.

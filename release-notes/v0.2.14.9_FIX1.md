# v0.2.14.9 FIX1 — Installer and Live UE4SS Compatibility

## Fixed
- The unified release build now treats the Windows installer as a required release asset unless `-SkipInstaller` is explicitly supplied.
- Inno Setup detection checks common system and per-user locations plus `INNO_SETUP_HOME`.
- Added `Build.ps1 InstallerTools` to install Inno Setup 6 through winget when needed.
- Installer output is written to `artifacts` and added to `SHA256SUMS.txt`.
- The installer uses the non-portable publish payload and excludes portable workspace markers/data.
- UE4SS compatibility is recalculated from the complete MOD inventory whenever MODs are refreshed, installed, enabled, disabled, deleted, repaired, or applied.
- Removed the stale hard-coded Admin Commands compatibility message.

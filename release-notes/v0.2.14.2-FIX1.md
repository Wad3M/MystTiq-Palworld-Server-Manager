# v0.2.14.2 FIX1 — Compile and Build Pipeline Hotfix

## Fixed

- Corrected unreachable exception handlers in `SafeFileSystemService` caused by catching `IOException` before derived exception types.
- Simplified guarded filesystem handling so missing files and directories remain safely covered by `IOException`.
- Updated the build scripts to fail immediately when `dotnet restore`, `dotnet build`, or `dotnet publish` returns a non-zero exit code.
- Prevented `Build.ps1 All` from continuing into packaging after a failed compile.
- Prevented the packaging script from reporting a portable package when publishing fails.

## Validation

Run from the repository root:

```powershell
Get-ChildItem . -Recurse -Filter *.ps1 | Unblock-File
.\Build.ps1 Clean
.\Build.ps1 All
```

The process must stop immediately on any compile or publish failure.

# MystTiq v0.7.44.0 — Palworld Instance Detection & Termination Tool

## Highlights

- **Server Doctor now shows every Palworld process on the machine**, not just this tab's own managed one — a new "ALL PALWORLD INSTANCES ON THIS MACHINE" panel, reusing the same list-plus-details layout MOD Dashboard/MOD Library already use.
- **Two stop paths, chosen automatically per instance**: an instance confirmed as this tab's own managed process gets the existing safe, crash-recovery-aware Force Stop. An instance MystTiq can't confirm as its own gets a separate, clearly-labeled "Force Kill (Unmanaged)" action with an explicit on-screen warning.
- **The warning is real, not boilerplate**: this exact scenario — a raw kill outside MystTiq looking like a crash to that server's own crash-recovery and triggering an auto-restart — happened twice during this session's own release verification. The tool discloses that risk instead of hiding it.
- New ribbon button "Detect Instances" on the Server Doctor page; Run Doctor refreshes the list too.

## Upgrade notes

- Additive only — no change to this profile's own status polling, Force Stop, or the existing MANAGED PROCESSES panel.
- New routes require the same `Operator` role as every other server-control route; no new authentication surface.
- Direct mid-session request, motivated by a real environmental collision hit during this project's own build verification, not from the original 57-item findings log.

# v0.7.96.0 — Live Map: Players and Bases Work Out of the Box

Second version of the "enhancements to features we already have" group, prompted by "i did supply the
world maps ... there should be functionality to show where the user is on the map and bases".

- The World Map (Players page) is now open by default and starts on the bundled Palpagos map on a first run
  (a saved choice, including Clear Background, is respected).
- Real-world player positions and guild base markers are on by default for the Palpagos map. The checkbox
  remains as an off switch and is no longer labelled experimental.
- Fixed the position conversion: the bundled image is the expanded map including Feybreak, but the old code
  assumed the pre-expansion frame and would have drawn dots in the wrong place. It is now calibrated against
  the game's documented start location and a real world's base, character positions and travel trail.
  Accuracy is a few pixels of the map image: the right spot, not survey grade.
- Bases load together with the Players page (no separate refresh needed) and draw even while the server is
  stopped, since they come from the world save.
- A status line under the map says what is drawn, so an empty map is explained: nobody online or server
  stopped, players online without a reported position, or how many bases are shown.
- Not changed: the World Tree preset and your own images keep the relative view; Pal positions are still not
  shown; teleport from the map still targets a selected player only.

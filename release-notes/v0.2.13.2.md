# MystTiq Palworld Server Manager v0.2.13.2

## Workspace & Portable Foundation

This release introduces a dedicated working environment for the portable edition while preserving the existing installed-mode data locations.

### Added

- Portable-mode detection through `portable.mode` beside the executable.
- A portable `Data` directory for MystTiq settings, logs, cache, notifications, diagnostics, and window state.
- A portable `Workspace` directory with dedicated folders for servers, SteamCMD, backups, downloads, and exports.
- First-run discovery of `PalServer.exe` under `Workspace\Servers`.
- First-run discovery of `steamcmd.exe` under `Workspace\SteamCMD`.
- Portable settings remember discovered or manually selected server paths.
- Clear startup errors when the portable directory is not writable.

### Packaging

- Portable ZIPs now include `portable.mode`, `Data`, and the complete `Workspace` layout.
- The installer uses the normal published application files and deliberately excludes portable mode.
- Installed deployments retain the existing ProgramData and LocalAppData behavior.

### Safety

Portable mode never requires the Palworld server to be inside the workspace. External server and backup locations remain supported through Manager Settings.

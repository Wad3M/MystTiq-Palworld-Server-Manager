# MystTiq Palworld Server Manager v0.3.0.3 FIX1

## Configuration Compile & systemd Argument-Quoting Hotfix

The initial v0.3.0.3 compile exposed two implementation errors in the new
configuration/systemd integration.

### Fixed

1. `HeadlessConfigurationService.ValidateAbsoluteLinuxPath()` used:

```csharp
value.StartsWith('/', StringComparison.Ordinal)
```

The `StringComparison` overload requires a string. FIX1 now uses:

```csharp
value.StartsWith("/", StringComparison.Ordinal)
```

2. `LinuxSystemdServiceManager.BuildUnit()` referenced
`QuoteSystemdArgument(configurationPath)`, but the helper method was missing.

FIX1 adds the helper and preserves safe quoting of the configured systemd
`--config` path, including rejection of newline injection.

### Scope

No API routes, configuration schema, lifecycle policy, systemd recovery policy,
PalServer behavior, or Windows WPF behavior changed.

The v0.3.0.3 logic harness now explicitly checks both compile contracts.

# v0.2.14.5 — Repair Center Foundation

## Summary

This release establishes the guided, dark-themed Repair Center inside World Inspector. It remains intentionally preview-only while transaction apply and rollback services are developed.

## Added

- Repair Center status and next-step guidance.
- Active-world scan action.
- Candidate, selected, high-risk, and mode summary cards.
- Clear-selection and preview-selected controls.
- Read-only repair plan feedback.

## Changed

- Removed the redundant World Validator left-navigation item.
- Consolidated world validation and repair access under World Inspector.
- Applied shared MystTiq button, tooltip, card, and spacing standards.

## Safety

No save data is modified by this release. Repair Center only scans, selects, and previews candidate operations.

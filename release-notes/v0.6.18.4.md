# MystTiq v0.6.18.4 — Server Control Button State

## Highlights

- **Start/Restart/Stop now grey out correctly.** Start disables while the server is already running (including mid-startup, before it's fully ready); Stop and Restart disable while the server is already stopped. Previously all three stayed clickable regardless of the server's actual state.
- Uses the same "is the server running" definition already proven server-side (`HeadlessPalEditService`'s precondition for blocking a Pal edit while running) — not a new, separately-invented check.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.

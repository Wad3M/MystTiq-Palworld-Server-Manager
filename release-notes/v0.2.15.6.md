# v0.2.15.6 — Pre-start MOD Reconciliation & Runtime Health Hardening

Official baseline entering this phase: **v0.2.15.5**.

## Added
- `ModLifecycleCoordinator` owns the normal modded pre-start boundary.
- UE4SS state reconciliation now runs before every normal Start, Restart, and maintenance-backup restart.
- A startup health gate blocks unsafe/indeterminate modded starts after reconciliation.
- `ModRepairRecommendationEngine` converts MOD evidence into deterministic operator actions.
- MOD Dashboard **EXPORT REPORT** action writes both TXT and JSON verification reports.

## Startup gate rules
A normal modded start is blocked when an enabled MOD is not deployed, an enabled UE4SS MOD is outside the resolver-selected Active Mods Root, a state mismatch survives reconciliation, a duplicate logical MOD install is detected, or state reconciliation reports filesystem/state warnings that prevent MystTiq from guaranteeing the effective runtime state.

**Start Without MODs intentionally bypasses the MOD lifecycle gate** and remains the isolation/recovery path.

## UI standards
The new report-export action reuses the existing MystTiq `InfoButton`, `ModActionWrapPanel`, tooltip conventions, spacing, and dark-theme surfaces. No new visual style family was introduced.

## Promotion rule
Do not promote v0.2.15.6 until the user completes the required build sequence and runtime test plan and reports the build validated.

# MystTiq Palworld Server Manager v0.3.1.7 FIX1

## Validation Warning Cleanup

v0.3.1.7 compiled and functionally passed, but release validation reported one stale-version warning from the logic harness itself.

Cause:

The harness contained the previous patch version as a literal string solely to assert that the Doctor source no longer contained that old value. The release validator correctly interpreted the literal in the test as a stale active-source reference.

FIX1 replaces that negative literal-version assertion with a positive behavior assertion:

- Doctor version is assembly-derived.
- The derived `reportVersion` is passed into `DoctorReport`.
- No prior patch-version literal is required by the active logic harness.

No World Explorer, Doctor, API, GUI, lifecycle, TLS, backup, monitoring, SteamCMD, or PalServer runtime behavior changed.

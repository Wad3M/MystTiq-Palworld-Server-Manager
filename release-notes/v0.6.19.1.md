# MystTiq v0.6.19.1 — Ribbon Cleanup and Fleet Page Fixes

## Highlights

- **Ribbon toolbar decluttered.** The category-specific ribbon groups that exactly duplicated the left nav sidebar (World/Server/Mods/Tools/System) are gone — those pages are still one click away in the sidebar. The Server Control and Quick Actions ribbon groups are unchanged.
- **Fleet page**: each server in the Server Profiles list now shows a colored status dot (green running / red crash detected / grey stopped). A failed fleet-wide action (Backup All/Doctor All/Update All) now shows its actual error message instead of just a bare "False."

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- The Fleet page feedback that prompted this was broad; this release addresses the concrete gaps found in the existing data model. If there's more specific Fleet functionality you'd like to see, that's a good next thing to flag.

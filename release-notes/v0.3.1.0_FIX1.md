# MystTiq Palworld Server Manager v0.3.1.0 FIX1

## Avalonia Font Dependency & Desktop Compile-Gate Hotfix

The first v0.3.1.0 desktop build failed because `Program.cs` calls `.WithInterFont()` while the project did not reference the `Avalonia.Fonts.Inter` package that supplies that extension.

FIX1:

- adds `Avalonia.Fonts.Inter` on the same Avalonia 11.3 servicing line
- retains `.WithInterFont()` in the Avalonia bootstrap
- updates `docs/index.html` to v0.3.1.0 so validation is warning-free
- strengthens `Test-v0.3.1.0-Logic.ps1 -RunBuild` to build/publish both Windows and Linux Avalonia desktop targets
- adds regression checks tying `.WithInterFont()` to the required package

No Linux headless, WPF, PalServer, systemd, API, TLS, lifecycle, or Production Doctor behavior changed.

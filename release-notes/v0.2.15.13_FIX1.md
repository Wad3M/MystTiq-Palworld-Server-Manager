# MystTiq Palworld Server Manager v0.2.15.13 FIX1

## MOD Conflict Health False-Positive Hotfix

v0.2.15.13 introduced centralized MOD platform health evaluation. Runtime testing exposed one string-matching false positive:

`No known conflict`

was incorrectly treated as a confirmed conflict because the health service used a broad `ConflictStatus.Contains("Conflict")` test.

FIX1 requires explicit conflict evidence:
- `Compatibility == "Conflict"`, or
- `ConflictStatus == "Confirmed conflict"`

Healthy MODs with `No known conflict` therefore remain neutral/healthy and do not reduce Overall Health.

Real conflicts, runtime errors, missing dependencies, missing files, failed MODs, and misconfiguration continue to affect server health.

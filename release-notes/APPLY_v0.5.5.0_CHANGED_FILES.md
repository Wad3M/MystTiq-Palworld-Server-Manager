# Apply v0.5.5.0 Changed Files

The Changed Files ZIP is an audit/convenience package for the promoted v0.5.4.0 source baseline. Normal installation should use `MystTiqPalworldServer_v0.5.5.0_FullSource.zip` with `Update-FromDownloads.ps1` so the running artifact app closes, the staged source replaces cleanly, and the complete current-version gate runs before relaunch.

Do not overlay it onto v0.4.17.4 or an unknown source tree.

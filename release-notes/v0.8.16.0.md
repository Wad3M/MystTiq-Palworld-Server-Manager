# v0.8.16.0 — Theme Modes and Density

- **Three new modes.** The Light mode checkbox in Settings is now a **Mode** picker:
  - **Midnight:** true black, easy on OLED screens;
  - **High contrast:** white text and borders on black, with brighter status colours;
  - **Follow the system:** matches your computer's light or dark setting, and changes when it does.
  Like the accent theme, the mode is chosen per tab. Tabs you already set to Dark or Light stay as they are.
- **Compact density.** A new **Density** picker makes cards, buttons, boxes and list rows smaller, so more fits on
  screen. It applies to every tab and is remembered.

# v0.2.14.8 — Architecture & Performance Foundation

## Summary

This release reduces MainWindow lifecycle coupling without changing intended user-facing workflows.

## Added

- `ApplicationConstants` for shared operational timing and network defaults.
- `MainWindow.Lifecycle.cs` for startup, timer ownership, window-lifetime cancellation, and deterministic shutdown cleanup.

## Changed

- Startup work is cancellation-aware when the window closes.
- Timer handlers are named, logged, and explicitly detached.
- Startup and monitor exceptions are isolated from the WPF dispatcher.
- Cancellation-token sources and long-lived services are cleaned up through one shutdown path.
- MainWindow constructor responsibilities are reduced.

## Safety boundary

No world-editing, player-editing, repair, import, backup, restore, MOD, or configuration behavior is intentionally changed in this release.

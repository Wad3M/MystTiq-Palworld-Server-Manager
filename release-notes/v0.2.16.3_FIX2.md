# MystTiq Palworld Server Manager v0.2.16.3 FIX2

## Legacy MystTiq Release-Source State Removal

FIX1 correctly exposed that the old manager release-source state still existed in two active locations:

1. the MystTiq-specific finalizer fallback
2. the generic Update Center action mapper

That state is obsolete because v0.2.16.3 now has a configured GitHub Releases source.

FIX2 removes the legacy status completely from active Update Center code. If GitHub release metadata cannot be obtained, MystTiq now uses the retryable `UNABLE TO CHECK` state.

No version-number change or unrelated runtime behavior change is included.

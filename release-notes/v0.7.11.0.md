# MystTiq v0.7.11.0 — App Lifecycle: Single-Instance, Tab-Close Confirmation, Tray Reminder

## Highlights

- **Closing the window now actually closes the app when nothing is running.** Previously pressing the X always minimized to the tray, with no way to fully quit that way. Now it checks every open tab, not just the visible one — if no server is running anywhere, it exits cleanly; if one is, it minimizes to tray and shows a reminder that MystTiq is still managing it in the background.
- **Closing a tab whose server is running now asks first** — stop the server and close, leave it running and close, or cancel.
- **A second launch is now blocked** with a clear notice instead of silently opening a second window.
- Verified live: two full server instances run simultaneously with completely isolated data — no changes needed, this confirmed the existing design works as intended.

## Upgrade notes

- No configuration schema change. No server-side change — this release is entirely `MystTiq.Desktop` plus documentation fixes.
- The tray reminder is a small custom window (Avalonia has no built-in balloon-notification control) — it auto-dismisses after 5 seconds.

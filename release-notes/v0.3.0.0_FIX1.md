# MystTiq Palworld Server Manager v0.3.0.0 FIX1

## Regression Harness Reserved Variable Hotfix

The first v0.3.0.0 regression harness used `$host`, which conflicts with PowerShell's read-only built-in `$Host` variable because PowerShell variable names are case-insensitive.

The harness variable was renamed to `$headlessHostSource`.

Validated result after the correction:

- 55 PASS / 0 FAIL
- Windows build path passed
- `MystTiq.Core` built
- `MystTiq.HeadlessHost` built
- self-contained `linux-x64` publish succeeded
- Ubuntu Server 24.04.4 LTS probe succeeded
- Linux SteamCMD/PalServer paths were detected
- native `PalServer-Linux-Shipping` and UDP 8211 were detected while the server was running

v0.3.0.0 FIX1 is the official Linux/headless baseline for v0.3.0.1.

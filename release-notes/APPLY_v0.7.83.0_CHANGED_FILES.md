The Changed Files ZIP is an audit/convenience package for the promoted v0.7.83.0 source baseline. Normal installation should use `MystTiqPalworldServer_v0.7.83.0_FullSource.zip` with `Update-FromDownloads.ps1` so the running artifact app closes, the staged source replaces cleanly, and the complete current-version gate runs before relaunch.

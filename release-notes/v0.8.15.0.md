# v0.8.15.0 — A Real Remote Sign-In

- **Signing in to a remote MystTiq is now tested for real.** The Desktop signed in over the network to a MystTiq on a
  Linux machine, with remote access switched on the documented way, as a Viewer, an Operator and an Admin.
  - Each role saw exactly the cards it should, and the server allowed and refused the same things.
  - A wrong password and a wrong certificate were refused.
  - Signing out ended the session on the server.
- **Fixed: a refused change could look like it had worked.** When the server refused a change because of the role,
  a server limit or an expired sign-in, the Desktop could treat the refusal as a success (for example, the whitelist
  showed as saved). It now shows the refusal, for example "MystTiq refused this: it needs the Admin role or higher."

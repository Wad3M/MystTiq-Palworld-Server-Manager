# MystTiq Palworld Server Manager v0.3.1.3 FIX3

## Linux Gate Version-Path Validation Cleanup

The v0.3.1.3 FIX2 build and logic gate passed completely, but release validation emitted six false stale-version warnings from the logic harness.

Cause:

The validator intentionally accepts prerelease suffixes. A literal script filename such as:

`Test-v0.3.1.3-LinuxAcceptance.sh`

can therefore be interpreted by the stale-version regex as the candidate version `0.3.1.3-LinuxAcceptance.sh`.

FIX3:

- resolves the current project version through `Get-ProjectVersion.ps1`
- dynamically constructs the Linux acceptance and production-readiness script paths
- keeps all six Linux gate regression checks intact
- removes literal versioned Linux script filenames from active PowerShell source

No monitoring, API, GUI, lifecycle, TLS, systemd, PalServer, or Linux acceptance behavior changed.

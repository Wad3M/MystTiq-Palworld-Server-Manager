# MystTiq v0.6.18.3 — Configuration Page Overhaul

## Highlights

Eight pieces of direct user feedback on the Configuration page, acted on:

- **No more literal quote marks** in Server Name/Description/Admin Password/Server Password — MystTiq re-adds them automatically when writing to `PalWorldSettings.ini`.
- **"Generate Server Name"** now lives right next to the Server Name field it populates.
- **QoL presets auto-apply** the moment you pick one — no separate "Apply Preset" click.
- **Save your own presets**: type a name, click "Save As Preset," and every currently-loaded setting is captured locally — that's also how to create a "MystTiq" preset representing whatever you're running today, rather than a value map we'd have had to guess.
- **Advanced Settings highlights** any row that currently differs from Palworld's default, live as you edit.
- **Simple Settings grew from 8 to 34 settings** — Server Identity, Network/Access/Limits, and Gameplay Rates, organized into clear groups.
- **Search and filter** now sit directly above the settings list and work on both Simple and Advanced views.
- Removed a redundant header and a second dead legacy block; Import/Export are now front and center.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- Custom presets are stored locally on this machine (`%AppData%/MystTiq/config-presets.json` on Windows) — not synced across machines, matching how connection profiles and map preferences already work.

# v1.0.0.6 — Buttons and Tags That Say What They Do

## Buttons

Every button now takes its colour from what it does, the same way on every page:

| Colour | What the button does | For example |
|---|---|---|
| Red | Deletes, removes or forces something | Delete, Remove, Revoke, Kick, Ban, Force Stop, Discard |
| Purple | Opens something or goes somewhere | Open, Browse, Show on map, Open guild, Manage |
| Green | Checks without changing anything | Verify, Rescan, Recheck, Test, Validate, Run Doctor |
| Blue | Makes the change you asked for | Save, Apply, Create, Add, Install, Send, Connect |
| Teal | Reads again, previews or copies out | Refresh, Preview, Load, Export, Copy |
| Amber | Undoes, resets or pauses | Restore, Reset, Restart, Repair, Pause, Mute |
| Neutral | Moves through a step or backs out | Cancel, Back, Next, Dismiss |

- The colour follows the button's meaning, not the page. A **Delete** is red on Backups, Players and Security alike.
- Buttons whose label changes keep up. On **Server Setup** a row that says VERIFY is green, MANAGE is purple and INSTALL
  is blue.
- Confirmation windows use red for something that can't be undone and blue otherwise.
- The colours come from your theme, so they work in light, dark and high-contrast modes.

## Tags

Status tags (READY, PASS, Up to date, Healthy, Verified …) look the same everywhere and are coloured by what they say:

- **Green:** ready, passing, up to date, verified, healthy, connected.
- **Amber:** needs attention, update available, unverified.
- **Red:** missing, failed, unreadable, misconfigured, not loaded, locked.
- **Grey:** disabled, optional, self-updating, not applicable, skipped.
- **Blue:** anything in between, such as Starting or Connecting.

This covers Server Setup, Install, Update Center, Doctor, Diagnostics, Network, Backups, MOD health, Workshop, user
accounts, the MOD safe start and the connection state at the top of the window.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.0.5

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

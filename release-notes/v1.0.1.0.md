# v1.0.1.0 — Update, on Every Row

## Update Center

Every component in the Update Center now has an **Update** button. It's greyed out only where there is nothing it could
do, and then it says why beside it. Its tip always says what it will do.

| Component | What Update does |
|---|---|
| MystTiq | Downloads the new release, checks it against the release's checksums and unpacks it into a new folder beside this one. Exit MystTiq from the tray and start the new one; your settings and servers carry over. Greyed out when there is nothing newer. |
| SteamCMD | Greyed out: SteamCMD updates itself every time it runs. If it's missing, Update installs it. |
| Palworld Dedicated Server | Updates the server files with SteamCMD (the server must be stopped). |
| UE4SS | Opens the UE4SS page with the newest release selected and previews the install; you apply it there. |
| PalDefender | Downloads the newest PalDefender and replaces `PalDefender.dll` and `d3d9.dll`, keeping your settings. The server must be stopped. A PalDefender you switched off stays off, and the replaced files are kept in a backup folder. |
| pip, Palworld Save Tools | Upgrades them with pip. |
| Python, .NET, Visual C++ Runtime, C++ Build Tools, PlM/Oodle decoder | Opens the official download page. MystTiq doesn't install these itself; for Python, stay on the same 3.x release, because the save decoder is built for it. |

## Checked before anything changes

- **MystTiq** only unpacks a download that matches the release's `SHA256SUMS.txt`. Anything else is deleted and nothing changes.
- **PalDefender** only replaces files with genuine Windows DLLs whose own version is the release's.

## Fixed on the way

- The PlM/Oodle decoder row never had its link: it was looked up as "PIM" instead of "PlM", and pointed at a page that
  does not exist. It now opens the decoder's project.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.0.6

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between. From this version on, the Update Center's MystTiq row can do the download and extraction for you.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

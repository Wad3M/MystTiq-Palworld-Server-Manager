# MystTiq Palworld Server Manager v0.2.15.9

## MOD Functional Verification & Capability Analysis

v0.2.15.9 builds on the v0.2.15.8 FIX1 evidence model.

### Added
- Non-destructive static capability analysis of active-root UE4SS mods.
- Detection of RegisterHook, console handlers, keybinds, game-thread execution, async callbacks, BeginPlay/event hooks, and mod-generated logging.
- UE4SS Lua / Native-C++ / Hybrid classification where source layout makes it observable.
- `Confirmed Running` as a stronger state than `Confirmed Loaded`.
- Functional-activity promotion when a current runtime line contains both a MOD identity and an execution/activity signature.
- Verification details now explain detected capabilities and what functional evidence MystTiq expects.

### Safety
MystTiq remains observational. It does not inject Lua, patch third-party mods, invoke destructive game events, or alter MOD source to manufacture proof.

# MystTiq v0.7.9.0 — Real Server FPS/Frame Time

## Highlights

- **Real in-game performance, not just host CPU%**: Palworld's official REST API exposes its own simulation FPS and frame time — the thing that actually degrades as a server accumulates bases and Pals, independent of host CPU. MystTiq previously had no way to show this at all. Now visible on the Monitoring page alongside CPU/RAM/Threads.
- Requires the Palworld dedicated server's REST API to be enabled (the same requirement several existing MystTiq features already have) — shows "—" gracefully when it isn't.

## Upgrade notes

- No configuration schema change. No `MystTiq.Core` model changes — the new fields live entirely in `MystTiq.HeadlessHost` and `MystTiq.Desktop`.
- Historical FPS charting (matching the existing CPU/RAM history graph) is a natural next step, not included in this release.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

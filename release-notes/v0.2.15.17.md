# MystTiq Palworld Server Manager v0.2.15.17

## Live World Telemetry & Dashboard Pulse

### WORLD PULSE
The Dashboard now exposes:
- exact saved Palworld world day/time
- saved-world freshness
- current PalServer session uptime
- current/peak players
- session joins/leaves/unique players
- latest backup age
- last player transition

### Authoritative world clock
MystTiq reads `GameTimeSaveData.GameDateTimeTicks` from the decoded active `Level.sav` snapshot. One Palworld day is represented by 864,000,000,000 100-nanosecond ticks.

The value is treated as a **saved world clock**. MystTiq intentionally does not extrapolate time between saves and does not manufacture a next-day/night countdown.

### Session semantics
Player counters reset when the PalServer session ID changes. Existing players present when MystTiq first attaches to a session seed the current/peak/unique state and are not falsely counted as new joins.

No MOD health/runtime-evidence or server lifecycle policy changes are intended.

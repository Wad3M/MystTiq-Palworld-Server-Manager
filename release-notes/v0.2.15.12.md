# MystTiq Palworld Server Manager v0.2.15.12

## Server Lifecycle & Process Modularization

This release continues the behavior-preserving modularization roadmap.

### Architecture
- `ServerService` remains the public compatibility facade.
- `ServerSessionInspector` now owns Windows process-tree discovery for a server session, exact loaded-module capture, and guarded-port observation.
- `ServerLifecycleEvaluator` now owns lifecycle-state interpretation (`Starting`, `Running`, `Stopping`, `Hung`, `Crashed`, `Stopped`) as a pure policy service.
- `ServerService` delegates session snapshots and health-state evaluation to these modules.

### Runtime evidence protection
Native UE4SS module verification still consumes the current `ServerSessionSnapshot`. The refactor intentionally preserves:
- server session ID
- root PID
- process-tree membership
- canonical loaded-module paths
- snapshot refresh behavior
- snapshot invalidation when the session ends

### Platform roadmap
The extracted process/session boundary is the precursor to interfaces such as `IProcessInspector`, `IModuleInspector`, and `IProcessLauncher` before Linux implementation.

No user-facing UI/theme/button/tooltip changes are intended.

# v1.1.1.3 — Dependency Updates

Four library updates, each checked through the full release gate before release:

- **Avalonia** (the desktop's UI framework) 12.1.3 → 12.1.4, with the test harnesses' Avalonia.Headless to match.
- **Discord.Net.WebSocket** (the Discord bot) 3.20.1 → 3.20.2.
- **Microsoft.Extensions.Hosting.WindowsServices** (running as a Windows service) 10.0.12 → 10.0.13.
- The release workflow's **download-artifact** action v7 → v8.

Nothing to do: MystTiq works as in v1.1.1.2.

## Upgrading from v1.1.1.2

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder. Nothing to convert. Coming from an older version, also read the [v1.1.1.2](v1.1.1.2.md), [v1.1.1.0](v1.1.1.0.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

# MystTiq v0.7.79.0 — Server Doctor Compact, Color-Coded Checks

## Highlights

- **Server Doctor's check list is more compact** and makes better use of horizontal space — each
  finding is now one denser row (badge, component, evidence, actions) instead of a tall stacked
  card, and a redundant repeated line (Recommendation duplicating Evidence, common on passing
  checks) is now hidden.
- **PASS/WARNING/FAIL are color-coded** with a small badge (green/amber/red) instead of plain text,
  so status reads at a glance. A subtle text shadow on the badge label keeps it legible against the
  bright green PASS background.

## Upgrade notes

- No configuration changes. Touches `MystTiq.Desktop` only.

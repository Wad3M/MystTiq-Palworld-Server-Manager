# MystTiq Palworld Server Manager v0.2.15.14

## Application Composition & Platform Abstraction Preparation

This release continues the behavior-preserving modularization roadmap.

### Application composition
`ApplicationServiceComposition` now constructs the core server/MOD/diagnostics graph. `MainWindow` consumes those services instead of manually constructing that graph itself.

This keeps construction policy out of the WPF shell while preserving explicit dependencies and avoiding a service-locator pattern.

### Platform boundary
`IServerSessionInspector` now defines the observational session/process contract:
- capture current server session snapshot
- enumerate descendant process IDs
- observe guarded listening ports

The existing `ServerSessionInspector` is the Windows implementation. `ServerService` depends on the interface and supplies the Windows implementation by default.

### Linux preparation
A future Linux implementation can provide its own `IServerSessionInspector` without changing MOD native evidence consumers or the public `ServerService` facade.

No user-facing behavior changes are intended.

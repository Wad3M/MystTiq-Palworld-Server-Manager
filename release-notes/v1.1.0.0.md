# v1.1.0.0 — The New Accepted Baseline

**MystTiq 1.1 is the new accepted baseline.** It brings together everything since the last published release
(v1.0.6.1), checked as one release, and every page of the documentation has been read against the app and brought up to
date.

**Safer by default**
- **Nothing lost when a file is damaged.** If one of MystTiq's own lists (accounts, automation, kits, channels and the
  rest) can't be read, it loads the last good copy or refuses changes, and alerts you with a link to the repair.
- **One thing at a time.** Backups, updates and MOD changes can no longer overlap a server start or a save edit.
- **Secrets encrypted on disk** and kept out of logs; every archive MystTiq opens is checked before anything is written.
- **Errors are recorded and shown** instead of closing the app.

**Easier to follow**
- A server start shows its steps; backup scans show progress and can be cancelled; the connection line says what is
  wrong.
- The identity guard gives a player who is still loading 90 seconds before it acts.
- A burst of alerts is queued and repeats are combined.

**New features**
- **MOD load order and profiles** on the MOD Library page: set UE4SS's load order, and export or import your MOD setup.
- **Discord commands that answer**: start, stop, restart and backup now show their result instead of "did not
  respond".
- **Level-gap scans**: an anti-cheat rule reports a level gain far beyond the playtime behind it (it only reports).

**Tested harder**: simultaneous operations, 10,000 console lines, an update interrupted half way, and 24-hour idle runs
on Windows and Linux, both passed. A Ctrl+C on a self-run service now leaves the game running.

**Inside**: the desktop's main window code is split into one piece per page, and a test keeps every command reachable.
Nothing looks different because of it.

Still to be confirmed live: the Discord commands with your own bot, and the level-gap rule over a week of your server.
The 11 non-English translations remain drafts.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from an earlier 1.x

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert, and the service is unchanged. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

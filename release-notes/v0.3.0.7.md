# MystTiq Palworld Server Manager v0.3.0.7

## Linux Integration & Production Readiness

This is the final planned v0.3 feature/integration milestone.

### Added
- `production-doctor` headless command with JSON/text results, evidence and recommendations
- `Install-MystTiqLinux.sh` first-run setup helper
- `Upgrade-MystTiqLinux.sh` safe upgrade helper
- `Test-v0.3.0.7-ProductionReadiness.sh` one-command production gate
- production-readiness integration into extended Linux acceptance
- packaging and regression checks for all new Linux operational scripts

### Safety
- existing configuration is preserved on first run
- upgrades create a pre-upgrade configuration backup
- secrets/TLS, PalServer files, saves and backups are not replaced by the upgrade helper
- existing atomic running-binary replacement remains authoritative

### Remaining v0.3
v0.3.0.8+ is reserved only for stabilization/hotfix work discovered during v0.3.0.7 acceptance.

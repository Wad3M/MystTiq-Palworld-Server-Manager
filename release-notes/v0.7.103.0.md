# v0.7.103.0 — Doctor: Scheduled Backups and a One-Click Fix

Seventh of the "enhancements to features we already have". The Doctor said whether a backup existed; it did not say
whether anything would make the next one happen. Your Default Server has no automation rules, so its newest backup
is 12 days old and nothing will fix that by itself.

- New Doctor finding **Scheduled backups**: Warning when no automation rule creates backups, when they are all
  switched off, when none runs at least weekly, or when the scheduled rule last failed (with the reason). Pass when
  a healthy schedule exists.
- With no backup rule at all it offers **Create Nightly Backup Rule**: a backup every day at 03:00 UTC, added as
  "Nightly backup (added by Doctor)". Two clicks at once still create one rule, it never duplicates an existing
  rule, and it needs the Admin role. It says what it created and that you can change or delete it in Automation.
- The Doctor's fix buttons now say what they do (Create Nightly Backup Rule, Create Backup Folder, Install / Repair
  Server Files) instead of "Fix Automatically".
- Nothing is created until you press the button. Your servers are unchanged by this update.
- Checked on a real sidecar (including two simultaneous clicks) and on the running app. Not verified: the Admin-role
  refusal with a real Operator token.

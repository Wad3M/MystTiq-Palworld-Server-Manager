# v0.7.98.0 — Doctor: Disk, Backups, Admin Password, Memory and Recent Crashes

Fourth of the "enhancements to features we already have". The Doctor did not check the things that end a
server's life. It now does, through the same report the Doctor page and the Dashboard badge already read.

- **Disk space on every platform** (it was Linux-only): Fail under 2 GiB free, Warning under 5 GiB, and a
  Warning when the next backup would not fit.
- **Backup freshness**, judged against the world rather than the clock: how long the world's latest changes
  have gone unprotected. A world with no backup at all warns.
- **Admin access**: warns when the REST API or RCON is on and the AdminPassword is empty, very common or
  under 8 characters. The password is never shown in the report.
- **Memory**: warns on a small machine or little free memory.
- **Recent crashes**: a new critical Crash Analyzer finding now reaches the Doctor and the Dashboard badge;
  running the analysis again marks it reviewed and clears it.
- Real finding on the Default Server while testing: its newest backup is 12 days old and the world changed
  6.4 days after it.
- These findings count toward Overall Health, so a warning can move a running server to DEGRADED.
- Not verified: how the Doctor page renders (no GUI automation), and the Linux code paths.

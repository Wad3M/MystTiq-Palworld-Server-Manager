# MystTiq v0.7.15.0 — Temporary Bans & Historical FPS Charting

## Highlights

- **Temporary Bans**: ban a player for a set number of hours instead of forever — the server automatically unbans them once it expires, no need to remember to lift it yourself. A new "Temporary Bans" card lists everyone currently serving one, with time remaining and a one-click early release.
- **Historical FPS charting**: the Dashboard's resource history graph now plots real in-game FPS alongside CPU and Memory, using the same live Palworld performance data added in v0.7.9.0 — now with a 30-day trend instead of just the live number.
- **Two dead buttons cleaned up**: "Whitelist" and "Remove Admin" both sat permanently greyed-out in Player Administration. Whitelist already works fully elsewhere on the same page (that stub was just never removed); Remove Admin had no real capability behind it to ever build — Palworld doesn't have a per-player admin concept — so it's gone rather than staying as a broken promise.

## Upgrade notes

- Give-items/give-Pals and mod load-order editing were investigated as part of the same backlog pass and found to be significantly larger, riskier, or open-ended undertakings than either feature shipped here. Both remain on the backlog, unscoped — full reasoning in `CHANGELOG.md`.
- No configuration schema change beyond a new `players/temporary-bans.json` file, created automatically on first use.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

# v1.0.0.1 — Launcher, Players and a Cleaner Exit

## Server > Launcher

- A **Launcher** page under Server, below Workspace, with its own rocket icon. The advanced PalServer start options moved
  here from System > Settings.
- One-click troubleshooting presets: **Default**, **No Mods**, **Show Window** and **Like double-click**. Each keeps the server's game port and
  log path and clears custom arguments, so comparison tests are repeatable. Every option stays editable, and the exact
  command and process settings are shown before you start.
- Servers now start exactly like double-clicking `PalServer.exe` in the server folder: with no arguments (only the game
  port, for a server that is not on 8211). The **Like double-click** preset also matches how Windows starts it and shows
  its window.
- The Console page can capture what PalServer writes to its own startup window (opt in).

## Players

- **Your character stays yours.** MystTiq now checks every Steam player who joins. If the server does not give them the
  character their Steam account already has, MystTiq stops them before a duplicate character is made, keeps their real
  character untouched, and tells you on the Dashboard and in your notifications.
- The Player Directory shows each player's Steam ID and Palworld user ID, searches and exports them, and opens a player's
  Steam profile.

## When a start gets stuck

- If a server has been starting for two minutes without opening its game port, the Dashboard says so, for how long, and
  offers two tests: **Test without MODs** (one start with every MOD off, then they are switched back on) and **Find the
  MOD**, which tests them one at a time, leaves the one that hangs off and starts the server with the rest.

## Addresses on the Dashboard

- The Dashboard lists the addresses players use: this computer's local addresses for players on the same network, and the
  public address for players on the internet, each with the server's port, ready to copy.

## Closing and exiting

- Closing the window now always sends MystTiq to the tray. **Exit** in the tray menu stops the running servers safely,
  then MystTiq's background service, then the app, so nothing is left running behind. (Force Exit does the same without
  waiting.)
- The title-bar language picker opens and closes with a single click.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.0.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert: a server set up before this version starts like a double-click until you save choices on Server > Launcher. If you saved Launcher settings in a test build, choose **Like double-click** there and save.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

# MystTiq v0.7.39.0 — Mod Install Type Auto-Detection

- **MOD installation now detects PAK vs. UE4SS from the archive's own contents** — any `.pak`/`.ucas`/`.utoc` file anywhere in it means PAK, otherwise UE4SS. No more manual dropdown to forget to flip.
- The dropdown is gone from MOD Library's Install Validated ZIP card.

- Verified against a real built sidecar: the existing MOD install/traversal-rejection runtime smoke checks pass with the new detection logic.

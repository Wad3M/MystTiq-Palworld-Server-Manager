# MystTiq v0.7.20.0 — World Map Presets

## Highlights

- **Two bundled map backgrounds** for the Players page's World Map card: Palpagos (the base game map) and World Tree. No more finding and cropping your own Palworld screenshot before the map has real geography behind it.
- Still works alongside the existing "browse for your own image" and "clear background" options — presets are just two more choices, not a replacement.

## Upgrade notes

- Player dots still spread relative to whichever players are currently online — this release is backgrounds only. Real coordinate calibration (dots at their true in-game position) is a separate, deliberately isolated next step, since it depends on unresolved research into Palworld's exact coordinate-conversion formula.
- Desktop-only change, no configuration or server-side impact.

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

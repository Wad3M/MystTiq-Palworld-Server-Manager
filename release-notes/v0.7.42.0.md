# MystTiq v0.7.42.0 — Cross-Page Consistency Sweep

## Highlights

- **13 pages got the same ribbon relocation treatment** already applied elsewhere in this roadmap: World Explorer, World Transactions, Guilds/Bases, Players, Network Diagnostics, Save Tools, Notifications, Automation, Alert Center, Security, Fleet, Crash Analyzer, and Update Center.
- **Two real bugs fixed along the way**: Network Diagnostics had a literal duplicate "Re-run Network Tests" button (removed) and a redundant "Open Server Log" button already covered by the global ribbon's Console shortcut (removed).
- Confirm-gated and collapsible-section-local actions (Fleet Actions, World Transactions' Repair Center, Alert Center's Discord Bot/Anti-Cheat refreshes) stayed in-page, matching existing precedent.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- Every relocated button already worked before this release — this only changes where each one lives.
- No live GUI verification in this environment.

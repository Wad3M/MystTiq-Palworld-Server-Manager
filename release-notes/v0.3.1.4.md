# MystTiq Palworld Server Manager v0.3.1.4

## Backup & Configuration

### Backups

Added authenticated API and Avalonia workflows for:

- inventory
- Backup Now
- delete selected backup
- safe restore selected backup

Restore is fail-safe: PalServer must be stopped, the current save is protected by a pre-restore backup, and extraction occurs through staging/rollback folders.

### Headless configuration

Added restricted configuration load/save for:

- management API enabled/bind/port
- lifecycle timeouts
- service polling/recovery policy
- ServerRoot
- SteamCmdPath
- BackupRoot
- RuntimeRoot
- launch arguments

Existing authentication/TLS structures are preserved and are not writable through the desktop editor.

Every save is validated and creates a rollback `.bak`. A MystTiq system-service restart is required to apply the change.

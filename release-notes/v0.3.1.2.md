# MystTiq Palworld Server Manager v0.3.1.2

## Dashboard & Lifecycle

### Added

- API-backed PalServer Start / Stop / Restart
- server-status refresh
- system-service status refresh
- PalServer PID
- guarded listener display
- last observed / last transition display
- uptime derived from the current running transition
- optional five-second auto refresh
- lifecycle-operation busy gate
- authoritative status/service reacquisition after every mutation

### Architecture

The Avalonia desktop remains a management API client.

Start/Stop/Restart calls are sent to:

```text
POST /api/v1/server/start
POST /api/v1/server/stop
POST /api/v1/server/restart
```

The GUI does not directly own or signal PalServer.

### Security

Connection-profile and TLS behavior from v0.3.1.1 remains unchanged. Bearer tokens remain process-memory-only.

# MystTiq v0.4.8.0 — Configuration Parity

Accepted source baseline: v0.4.7.1.

This build restores the v0.2.16.4 Configuration workflow while preserving the current Avalonia → ViewModel → API → headless/Core architecture.

## Restored
- Simple Settings and Advanced Settings over the same authoritative Palworld setting DTOs.
- Search and category filtering.
- Server-name generator using the historical v0.2 name pattern.
- Official / Vanilla, Balanced QoL, and Relaxed QoL presets using the historical preset values.
- Dirty-state tracking, reset-unsaved behavior, and client-side validation for ports and maximum players.
- Cross-platform local JSON import/export via Avalonia StorageProvider.
- Save Changes remains `PUT /api/v1/palworld/config` and retains the server-side rollback backup.
- Unknown/custom OptionSettings remain available in Advanced Settings and are preserved on save.

## Remote safety
Import/export operates only on files selected on the GUI machine. Import modifies the local editor only. It cannot write a remote server path; persistence still requires Save Changes through the authenticated management API.

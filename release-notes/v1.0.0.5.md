# v1.0.0.5 — Bases and Guilds, Each in Its Own Way

## Bases

- **A base is a place.** Each base is a card showing where it is on the map, how many Pals work there and which kinds,
  and which guild owns it.
- Select a base to see every Pal working there (name, level, owner). **Show on map** opens the Map zoomed to it, and
  **Open guild** jumps to its guild.

## Guilds

- **A guild is people.** Each guild is a card with its name, its leader and how many members and bases it has, and
  who's online.
- Select a guild to see its **roster by name**: the leader first, then who's online, then everyone else with when they
  were last saved. Its bases are listed with their locations, and **Open base** jumps to each one.

## Both pages

- The summary cards and the long "evidence" text the two pages used to share are gone. Each page opens with one line
  about what's on it.
- Transfer, recovery and guild operations work as before.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.0.4

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

# MystTiq v0.7.33.0 — Home Dashboard Fixes

## Highlights

- **Removed the duplicate ONLINE PLAYERS card** on the Dashboard — the top-row PLAYERS summary card already covers it with its own OPEN button; the LIVE SERVER / MANAGER LOG card now takes the full row.
- **The BACKUP card now has an amber tint and an OPEN button**, matching the ACTIVE WORLD card's own look next to it.
- **Fixed the real cause of sparse console output at server start.** Every log-bearing request from the Desktop was capped at 120 lines against the server's own 500-line ceiling — raised to the real max everywhere it feeds a visible log view, including around Start/Stop/Restart specifically.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- No live GUI verification against a real modded server in this environment — the console-log fix is grounded in the request-value-vs-server-cap arithmetic, not a rendered comparison; flag anything that still looks thin.

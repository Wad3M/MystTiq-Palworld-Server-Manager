# v0.2.14.3 — UI Standards & Dialog Foundation

## Added
- Central `AppDialog` facade and expanded `IDialogService`.
- Reusable button density variants for standard, compact, toolbar, wide, icon-only, and DataGrid actions.
- Formal MystTiq UI standards document.

## Changed
- Existing application dialogs now route through the central dialog facade without changing user-facing behavior.
- Workspace and Player Management command styles now derive from shared density variants.
- Historical apply notes, build/test plans, and compile-hotfix notes were moved into `release-notes`.

## Validation
- Confirm all dialogs retain their previous text, icon, buttons, and default response.
- Confirm button sizing remains compact and consistent at 100%, 125%, and 150% scaling.

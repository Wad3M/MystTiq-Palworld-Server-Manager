# MystTiq Palworld Server Manager v0.2.12

First public open-source release.

## Included

- Dashboard operations center
- Server lifecycle controls
- CPU/RAM monitoring
- Health and operational-state separation
- Backup, player, guild, base, world, save, and MOD tooling
- Activity ticker and notification center
- Self-contained Windows x64 packaging

## Important

Keep backups before modifying world data. Do not upload private saves, credentials, or logs containing sensitive information when reporting issues.

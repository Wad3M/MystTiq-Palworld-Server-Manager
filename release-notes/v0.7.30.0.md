# MystTiq v0.7.30.0 — Confirmed Bug Fixes: Status Text

## Highlights

- **Fixed**: Backups' TOTAL ARCHIVES/VERIFIED/PENDING-REVIEW summary cards no longer always show 0.
- **Fixed**: UE4SS no longer reports the meaningless "0.0.0.0" as its installed version.
- **Fixed**: Server Doctor's "UNKNOWN" status label now explains itself (e.g. "Server is not running; no health issues detected.") instead of leaving you to guess.
- **Investigated, not a bug**: UE4SS's "Unverified"/"Not reported" state — turns out to be correct behavior when UE4SS genuinely hasn't written confirmable evidence yet, not a detection gap. See the architecture doc for the full explanation.

## Upgrade notes

- Desktop-only-visible change; touches `MystTiq.Desktop` and `MystTiq.HeadlessHost`, no server-side behavior change beyond the version-string fix.

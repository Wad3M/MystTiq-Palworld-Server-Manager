# MystTiq v0.7.6.0 — Fix: Multi-Tab Stale Data (Wrong-Tab Actions)

## Highlights

- **Real safety bug fixed**: switching tabs didn't refresh the displayed player list/logs/dashboard state, so for up to 5 seconds after switching, a Kick/Ban click could fire against the wrong server using the previous tab's player data. Switching tabs now clears any selected player/backup/mod/Pal/base immediately and refreshes the new tab's data right away instead of waiting for the next automatic poll.
- The "Set Up New Server" wizard's step, and profile edits/deletes, are now correctly scoped per tab instead of shared or unguarded across every open tab.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- This is the first of several planned fix/feature releases from a broader review (a full bug scan plus a competitive feature survey against other Palworld server-management tools) — see `README.md`'s roadmap table for what's next (v0.7.7.0 onward).

# MystTiq v0.6.18.2 — Server Setup Page Cleanup

## Highlights

Direct user feedback on the Server Setup page acted on:

- **Removed the top hero card.** Its description text was a verbatim duplicate of what the shared page header already shows above every page — the only real content it carried, the ENVIRONMENT HEALTH badge, now lives in an expanded stat row alongside Components/Ready/Attention, with a single Verify Files action.
- **Removed "Check for Updates" and "Install Missing"** from this page. Both were confirmed-in-code duplicate wrappers around Update Center's own authoritative update/install functionality — Update Center remains the one real place that happens. The environment checklist's per-row "Install" action for a genuinely missing component is unaffected.
- **"First-Run Server Defaults" moved** to the Settings page's connection-profile editor, and now only appears while you're creating a brand-new connection profile — not every time you open Server Setup. Labeled "In-Game Server Defaults (new server only)" to make clear it's the Palworld server's own name/settings, distinct from the Profile Name field just above it (which only labels the MystTiq connection itself).

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop` view-model/XAML.
- If you had a saved keyboard/mouse muscle-memory for the old "Check for Updates"/"Install Missing" buttons on Server Setup, use Update Center instead — it's the same functionality, unchanged.

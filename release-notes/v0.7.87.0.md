# v0.7.87.0 — Configuration: Advanced Dirty Highlighting, Save/Discard Prompt, Default Tab

Direct live feedback: "When i change items on this page they should highlight so that we know what
has been changed in both simple and advanced settings. If I do not save the changes and click away
it should ask if I want to save changes or discard. when i load up configuration it should always
start with the servers settings."

- **Advanced Settings rows now highlight when edited**, matching Simple Settings' existing amber
  unsaved-change highlight (shipped v0.7.82.0). A row can show both "differs from Palworld's default"
  and "unsaved" at once — they mean different things.
- **Navigating away from Configuration with unsaved changes now asks first** — Save Changes, Discard,
  or Cancel — instead of silently discarding them.
- **Configuration always opens on Server Settings** (Simple view), instead of remembering Advanced
  from an earlier visit in the same session.

Touches `MystTiq.Desktop` only.

See [`docs/architecture/v0.7.87.0-configuration-dirty-highlighting-and-save-prompt.md`](../docs/architecture/v0.7.87.0-configuration-dirty-highlighting-and-save-prompt.md)
for implementation detail.

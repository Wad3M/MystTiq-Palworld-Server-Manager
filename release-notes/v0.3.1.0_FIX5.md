## RunBuild Boundary Marker Hotfix

All actual v0.3.1.0 desktop gates remain healthy:

- release validation: PASS
- validation: 0 errors / 0 warnings
- Windows Avalonia desktop publish: PASS
- Linux Avalonia desktop publish: PASS

FIX4 attempted to isolate the `if($RunBuild){...}` block by looking for a later `$report=` marker. The harness has no `$report=` variable; its summary begins with:

```powershell
$passed=
```

Therefore the boundary could never resolve and the structural checks inspected an empty block.

FIX5 changes the end marker to the real `$passed=` summary boundary and adds a regression check for that exact boundary contract.

No Avalonia, WPF, headless service, API, systemd, TLS, lifecycle, PalServer or Production Doctor runtime behavior changed.

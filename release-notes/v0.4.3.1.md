# MystTiq v0.4.3.1 — Promoted Baseline / Avalonia StringFormat Parser Hotfix

v0.4.3.1 is the normalized and promoted form of the former `v0.4.0.3 FIX1` candidate under the MAJOR.MINOR.REVISION.FIX convention.

The Dashboard contained two Avalonia bindings whose StringFormat values began directly with `{0}`. Avalonia interpreted those leading braces as a markup extension and attempted to resolve a type named `0`, producing AVLN2000.

Corrected:

- `{0} player save record(s)` → `{}{0} player save record(s)`
- `{0} player record(s)` → `{}{0} player record(s)`

The v0.4.3.1 logic harness checks that leading-placeholder StringFormat values are escaped.

No backend, local-discovery, lifecycle, Linux, network-diagnostic, or MOD/UE4SS behavior changed.

# v1.1.1.1 — Cleaner Packages

**The downloads no longer include .NET's crash-dump helper.** A self-contained .NET app normally ships a small program
called `createdump.exe` beside it. MystTiq never uses it, but online malware scanners that unpack the Windows ZIP ran
it instead of MystTiq, so their reports showed only that helper and the scanner's own tools (VirusTotal matched those to
a "vcruntime140 side-loading" rule, with no antivirus engine flagging anything). Every download (Windows, Linux and the
Docker image) now holds only MystTiq's own programs, and the packaging refuses a build that contains the helper.

The README's screenshots show the current app (v1.1.1.1) again.

Nothing else changes: MystTiq runs exactly as in v1.1.1.0. The only difference is that .NET can no longer write an
on-demand memory dump of a crashed MystTiq, which MystTiq never asked it to; MystTiq's own crash records are unchanged.

## Upgrading from v1.1.1.0

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder. Nothing to convert. Coming from an older version, also read the [v1.1.1.0](v1.1.1.0.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

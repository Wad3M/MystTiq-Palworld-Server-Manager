# v0.2.14.9 FIX2 — Nested Scroll Routing

## Fixed

- Mouse-wheel input over the Diagnostics Center results grid now scrolls the grid while it has room, then continues scrolling the containing page at the grid boundary.
- Added window-level nested-scroll routing for DataGrid, ListBox, ListView, multiline TextBox, and other controls with internal WPF ScrollViewers.
- The same behavior now applies consistently across Diagnostics, Transaction Center, Players, Guilds, Backups, MODs, Configuration, World Inspector, Save Tools, and other scrollable pages.
- Scrolling over page edges or ordinary cards continues to use the page-level ScrollViewer.

## Behavior

The nearest scrollable control receives the wheel first. When that control reaches its top or bottom boundary, wheel input automatically moves to the next scrollable parent instead of appearing unresponsive.

# v0.7.108.0 — Alert Center: Configurable Reminder Interval

Twelfth of the "enhancements to features we already have". Direct follow-up to v0.7.107.0: reminder re-alerts
shipped with the interval only settable through an environment variable, a live-testing knob rather than a
real setting.

- New "Reminder every (minutes, 0 = off)" field on the Alert Center's Threshold Rules card, saved by the
  existing Save Rules button. Applies to every rule.
- Defaults to 1440 (24 hours), same as before. A rules file saved before this version loads with the same
  default rather than turning reminders off.
- The environment variable (`MYSTTIQ_ALERT_REMINDER_MINUTES`) still works and still overrides this for live
  testing, exactly as in v0.7.107.0.
- Checked with a new logic-harness scenario (including the upgrade-from-an-old-rules-file case) and a new live
  smoke that deliberately does not set the environment variable, to prove the setting itself drives the
  cadence — plus a look at the real Alert Center page.

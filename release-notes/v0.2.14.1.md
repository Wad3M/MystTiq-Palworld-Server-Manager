# MystTiq Palworld Server Manager v0.2.14.1

## Workspace Manager UI

- Adds a dedicated Workspace page to the Server navigation section.
- Shows installed versus portable deployment mode.
- Displays executable, workspace, data, server, SteamCMD, backup, downloads, exports, and logs locations.
- Adds read-only workspace validation with directory write checks and required-file detection.
- Adds MystTiq-standard Browse, Open, Refresh, Validate, and Save Paths controls.
- Keeps server, SteamCMD, and backup paths synchronized with the existing Settings page.
- Preserves installed-mode and portable-mode path behavior introduced in v0.2.13.2.

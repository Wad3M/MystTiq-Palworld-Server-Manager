# v0.7.112.0 — Give Item

Second of the four items pulled into 0.7.x on 2026-09-22.

- **Give Item works.** The Players page's Player Administration card has a "Give items or Pals" box (same
  format as Starter Kits: `item PalSphere 10`, `pal WeaselDragon 5`) and a Give button. The right-click
  "Give Items" entry is live too; it was a disabled "BACKEND REQUIRED" stub before.
- Delivered through PalDefender over RCON, the same way Starter Kits are, and only to an online player. If
  PalDefender or RCON is missing, it says which. An id that is not a plain Palworld id is refused before
  anything is sent.
- A one-off give is not a kit claim, so it never affects auto-gift.
- Checked with a new logic-harness scenario and a live route smoke of every refusal. Not yet checked: an
  item actually arriving in a real player's inventory (no player was online to test with).

# MystTiq v0.6.14.0 — Console Live-Refresh Fix

## Highlights

- **Fixes a real bug: the Console page used to show nothing while your server was starting or stopping.** You'd click Start or Stop, watch the console stay completely frozen for the whole operation, and then see everything appear all at once the moment it finished — exactly when you'd want to watch it happening live. Two separate causes were found and fixed, both confirmed against a real running server.
- The console now updates live during Start, Stop, and Restart, showing real startup/shutdown narrative and mod-load diagnostics as they happen.
- A second, independently-discovered bug meant that under some conditions the freshest log content could be silently pushed out entirely by older historical log entries — also fixed.

## Upgrade notes

- No configuration schema change — an existing v3 `mysttiq.json` loads unchanged.
- No behavior change to any existing route's contract — both fixes only change what data appears and when, never what's stored or how operations work.

Nothing new deferred by this release — it's a focused bug fix. See [`docs/architecture/v0.6.14.0-console-live-refresh-fix.md`](../docs/architecture/v0.6.14.0-console-live-refresh-fix.md) for full root-cause and verification detail.

# MystTiq Palworld Server Manager v0.3.1.5

## Production Doctor & Diagnostics GUI

This release exposes the Linux production-health model through the secured management API and makes the Avalonia Doctor page functional on Windows and Linux desktop clients.

### Added
- `GET /api/v1/doctor` authenticated diagnostic endpoint.
- Overall PASS / WARNING / FAIL health result.
- Evidence and repair recommendation for every check.
- Configuration/schema, PalServer path/readiness, SteamCMD, backup root, systemd, disk reserve, current-boot journal, and management API security checks.
- Avalonia Run Doctor / Refresh action and diagnostic report export.
- Linux acceptance coverage for the Doctor API contract.

### Security
The Doctor endpoint uses the existing management API authentication/TLS middleware. Diagnostic reports do not include bearer tokens, TLS password secrets, or Palworld admin passwords.

# MystTiq v0.7.0.0 — Themes, Skins, UI Personalization & Custom Icon Set

## Highlights

- **4 accent themes x true light/dark mode.** A new "Appearance" card on the Settings page lets you pick Default/Emerald/Crimson/Violet, plus a light-mode toggle — changes apply immediately (no restart) and are remembered next time you launch.
- **A small original icon set.** Eight hand-drawn vector icons (paw print, wrench, capture-sphere, tent, shield, network, vault, monitor+pulse) now appear on the Dashboard, Server Setup, Players, Fleet, Security, and Bases nav items, the Backup Center, and the tab bar's "+" button — replacing generic system icons on those surfaces.
- Status text and dots throughout the app (server state, health, severity) now follow whichever theme you pick, instead of staying a fixed color.

## Upgrade notes

- The default appearance (Dark, Default accent) looks exactly like it did before this release — nothing changes until you actually pick a theme in Settings.
- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- **Disclosed gap**: this is a visual feature and the environment it was built in cannot preview a running GUI. The theme colors and new icons were sanity-checked as rendered images before shipping, but the actual on-screen look, contrast, and readability in the real app — especially the light theme — is worth a look once installed. A handful of decorative hover-glow colors intentionally stay at their original dark-tuned values in every theme (a real Avalonia technical limitation, not an oversight) and most nav icons keep their existing look — only the eight listed above are new.

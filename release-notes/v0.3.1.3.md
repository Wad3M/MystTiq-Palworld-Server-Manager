# MystTiq Palworld Server Manager v0.3.1.3

## Logs, Players & Monitoring

### Headless management API

Added:

```text
GET /api/v1/players
GET /api/v1/logs/tail?lines=120
GET /api/v1/metrics
```

The existing MystTiq bearer authentication/TLS boundary protects these endpoints when remote management is enabled.

### Players

MystTiq reads the active `PalWorldSettings.ini`, contacts Palworld REST only at loopback, and returns a sanitized live-player snapshot. `AdminPassword` never leaves the managed server.

### Logs

MystTiq exposes a bounded tail from `Pal.log` or the newest Palworld `.log`.

### Metrics

MystTiq exposes PalServer CPU, working-set RAM, thread count and authoritative PID.

### Avalonia

Added a shared Players page, Monitoring page, Dashboard online-player/CPU/RAM summaries, PalServer log tail, and recent in-memory metric history.

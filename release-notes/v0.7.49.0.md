# MystTiq v0.7.49.0 — UE4SS Install/Rollback

## Highlights

- **UE4SS releases can now actually be installed and rolled back from the UE4SS page**, not just browsed. Select a release, Preview Install to see exactly what will happen, Confirm Install to apply it, and Rollback to undo the last install — all from the ribbon.
- **Verified live against real release zips from both sources before writing any install code**: the Palworld Fork and Official Upstream repos package UE4SS differently (a modern `ue4ss/` subfolder vs. a legacy flat layout) — install faithfully mirrors whichever layout the selected release actually uses, and refuses to install a release whose layout doesn't match an existing install, rather than risking UE4SS loading twice.
- **Your installed mods are never touched.** Any file inside a `Mods` folder — at any nesting depth — is skipped during install, so `mods.txt` and every mod you've installed are safe. An existing `UE4SS-settings.ini` is preserved rather than overwritten.
- A safety snapshot of the exact files about to change is taken automatically before every install, and Rollback restores it on demand — or automatically, if an install fails partway through.

## Upgrade notes

- Installing requires PalServer to be stopped first, since UE4SS's files are loaded into the running game process.
- This was exercised live end to end (fresh installs, rollback, settings preservation, and the layout-mismatch refusal all confirmed working against real GitHub release data) but not yet against a real, already-populated Palworld server install — recommend trying it on a non-critical server first, or after taking your own backup, until it's been run against a live install.
- No way to visually render this app in the environment that built it — please click through the UE4SS page's new Preview/Confirm/Rollback flow before considering this fully verified.

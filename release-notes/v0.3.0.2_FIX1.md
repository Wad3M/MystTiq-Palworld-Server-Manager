# MystTiq Palworld Server Manager v0.3.0.2 FIX1

## systemd Unit Raw-String Compile Hotfix

The first v0.3.0.2 compile exposed a C# parser failure in `LinuxSystemdServiceManager.BuildUnit()`.

### Symptom

The compiler reported:

```text
CS8997: Unterminated raw string literal
```

followed by cascading parser errors inside the generated systemd unit body.

### Fix

`BuildUnit()` now uses ordinary compile-safe C# string construction while preserving the same unit contents and service policy.

No lifecycle, supervisor, recovery, or Windows WPF behavior changed.

The v0.3.0.2 harness now explicitly checks that `BuildUnit()` avoids raw-string syntax and still emits `[Unit]`, `[Service]`, and `[Install]`.

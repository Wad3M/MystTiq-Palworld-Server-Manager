# MystTiq v0.7.45.0 — Update Center Overhaul

## Highlights

- **Update Center now tracks real installed/latest versions for all 11 components** from the v0.2.16.4 reference, not just a single "Update Palworld Server" action — Core Server (MystTiq itself, SteamCMD, Palworld Dedicated Server, UE4SS Runtime) and Save & Runtime Dependencies (Python, pip, Palworld Save Tools, PlM/Oodle Decoder, .NET Runtime, Visual C++ Runtime, Microsoft C++ Build Tools).
- **MystTiq checks its own GitHub releases** for a newer version — informational only, no auto-download or auto-install.
- **Real sources only, researched before committing to any of them**: Steam's own unauthenticated Web API for the Palworld Dedicated Server build, the official .NET releases feed, real PyPI package data for pip and Palworld Save Tools, and GitHub releases for MystTiq and UE4SS.
- **Honest about what can't be checked**: Python, Visual C++ Runtime, Microsoft C++ Build Tools, and the PlM/Oodle Decoder tooling genuinely have no reliable unattended "latest version" source — those rows say so plainly instead of guessing.

## Upgrade notes

- Read-only version reporting only — no new update actions, no change to the existing Palworld Dedicated Server update flow.
- Makes outbound network calls to GitHub, PyPI, the official .NET release-notes feed, and Steam's Web API when you refresh Update Center. Every call degrades gracefully to "Unavailable" on failure; nothing else on the page is affected.
- Direct mid-session scope decision: build all 11 components at once (not a smaller starter slice), and include MystTiq's own self-update awareness.

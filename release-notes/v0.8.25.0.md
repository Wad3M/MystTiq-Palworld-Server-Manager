# v0.8.25.0 — Every Colour Follows the Mode

- **Light, Midnight and High contrast now reach every colour.** The glows, shadows, fixed borders and chart colours that
  stayed dark-mode colours in every mode now follow the chosen mode. Dark looks exactly as before.
- **Windows contrast themes.** With a Windows contrast theme on (Aquatic, Desert, Dusk, Night sky), MystTiq's High
  contrast mode uses its colours, and "Follow the system" switches to it.
- **Fixed:** green success buttons had white text that was hard to read in Light mode; it is dark there now.
- **The HOST tab has its own picture and icon** (it used the System ones before).
- This version is the new **accepted baseline**.
## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Repository and release preparation

The README and active roadmap now distinguish completed v0.8 work from v0.9 translation and v1.0 acceptance. Historical planning is preserved separately. GitHub packaging targets the current Avalonia desktop and service instead of the legacy WPF application, includes the native Windows helper and creates a draft prerelease for review. Upstream dependency updates are retained. An obsolete Linux supervisor left in Git (but absent from the accepted source archive) is removed to restore clean builds; release documentation is no longer hidden by an overbroad ignore rule, and a compiled object/stale manifest are untracked.

## Known limitations

This is an accepted development baseline, not v1.0. Translation remains partial. Real Linux desktop interactions and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need live integration checks. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

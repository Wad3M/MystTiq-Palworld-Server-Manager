# v0.8.25.0 — Every Colour Follows the Mode

- **Light, Midnight and High contrast now reach every colour.** The glows, shadows, fixed borders and chart colours that
  stayed dark-mode colours in every mode now follow the chosen mode. Dark looks exactly as before.
- **Windows contrast themes.** With a Windows contrast theme on (Aquatic, Desert, Dusk, Night sky), MystTiq's High
  contrast mode uses its colours, and "Follow the system" switches to it.
- **Fixed:** green success buttons had white text that was hard to read in Light mode; it is dark there now.
- **The HOST tab has its own picture and icon** (it used the System ones before).
- This version is the new **accepted baseline**.

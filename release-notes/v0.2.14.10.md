# MystTiq Palworld Server Manager v0.2.14.10

## Build & Release Modernization

This version modernizes the repository build and release pipeline without changing application UI or runtime feature logic.

### Implemented

- Modernized the root `Build.ps1` action router.
- Added `scripts/Build-Release.ps1` as the single release orchestration pipeline.
- Added `scripts/Build-Checksums.ps1` for deterministic SHA256 generation and verification.
- Modernized `scripts/Build-Installer.ps1` with Inno Setup 6 and 7 discovery through:
  - Explicit `-ISCC` path
  - `INNO_SETUP_HOME`
  - System `PATH`
  - Standard per-machine and per-user install locations
  - Windows uninstall registry entries
  - Windows App Paths registry entries
- Prevented duplicate portable publishing during the combined release pipeline.
- Centralized checksum ownership outside portable and installer scripts.
- Expanded release validation to verify required build scripts, version format, release documentation, PowerShell parsing, repository hygiene, XAML resources, handlers, and dialog-service compliance.
- Updated README, CONTRIBUTING, and RELEASE_CHECKLIST build instructions.
- Incremented active product version metadata to `0.2.14.10`.

### Intended build sequence

```powershell
.\Build.ps1 Clean
.\Build.ps1 Validate
.\Build.ps1 All
```

### Scope boundary

No Update Center, Admin Commands, button-color, scroll-routing, or application UI changes are included. Those remain Phase 2 work after this release is validated.

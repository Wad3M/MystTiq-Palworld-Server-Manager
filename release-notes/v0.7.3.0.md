# MystTiq v0.7.3.0 — New-Server Creation Wizard

## Highlights

- **"Set Up New Server" is now a guided 3-step wizard**: Connection Details → In-Game Server Defaults (with last release's live port-conflict warnings built in) → Confirm & Finish — instead of one long flat form.
- Nothing about editing an already-saved server profile changed — the wizard only applies while setting up a brand-new one.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- Every wizard step reuses the exact same fields and commands the flat form already had — nothing new to learn, just a clearer order.

# MystTiq v0.6.18.0 — Anti-Cheat & Save-Integrity Scanning

## Highlights

- **New: Anti-Cheat & Save-Integrity Scanning.** The fourth and final item from the v0.6.15.0 competitive survey. MystTiq now watches for three real, cited integrity signals: a malformed Steam ID on join, an impossible player/Pal level, and a Pal with out-of-bounds stats (Level/Talent/Rank) found during a periodic save scan.
- **Every rule defaults to Flag (notify + log only).** No player is ever auto-kicked or auto-banned until you explicitly opt a rule into enforcement — this ships safe by default.
- **Configurable responses**: switch any rule from Flag to Kick or Ban, using the same moderation path the v0.6.17.0 Discord bot's `/mysttiq-kick`/`/mysttiq-ban` commands already use.
- Live checks (Steam ID, level) run on the existing 15-second background poll — no new polling. The Pal stat scan reuses the v0.6.15.0 Pal Editor's decode engine, strictly read-only — it never touches your save file.

## Upgrade notes

- No configuration schema change to `mysttiq.json`. New per-profile file: `anticheat/rules.json`, created with safe (`Flag`-only) defaults on first run.
- New routes: `GET`/`PUT /anticheat/rules` (Admin-gated), `GET /anticheat/findings`.

## What's deferred

- Player inventory/save decode — still not built.
- Automatic Pal correction — anti-cheat only flags/kicks/bans; use the Pal Editor to actually fix a Pal.
- Behavioral cheat detection (aim-bot-style analysis) — out of scope for a save/API-level scanner.

This closes out the full four-milestone sequence the v0.6.15.0 competitive survey scoped. See [`docs/architecture/v0.6.18.0-anti-cheat-save-integrity-scanning.md`](../docs/architecture/v0.6.18.0-anti-cheat-save-integrity-scanning.md) for full verification detail.

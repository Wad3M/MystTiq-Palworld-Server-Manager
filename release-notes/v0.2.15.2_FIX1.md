# v0.2.15.2 FIX1 — Release Validation Warning Fix

## Purpose

Correct a false-positive version-consistency warning reported by `Build.ps1 Validate` for `docs/index.html`.

The GitHub Pages landing page intentionally references multiple versions from the same release line at once: the current release candidate, the official baseline, and planned versions. The validator already requires `docs/index.html` to contain the current build version, so the generic stale-reference scan should not also treat legitimate baseline/roadmap references on that page as stale.

## Change

- Keep the existing requirement that `docs/index.html` contains the current version.
- Exclude `docs/index.html` from the generic same-release-line stale-version scan.
- Preserve stale-version scanning for application source, build scripts, installer definitions, workflow files, and other active product files.

## Expected Result

`Build.ps1 Validate` should report **0 errors and 0 warnings** for the current v0.2.15.2 repository when no other validation problems are present.

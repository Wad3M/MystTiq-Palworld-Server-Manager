# v0.9.2.0 — Game Names in Your Language

- **Item and Pal names in your language:** the Give Item picker, starter kits and the map's Pal markers now show the
  game's own names in the language you picked (モコロン, 까부냥, Lamball…), read straight from the Palworld server you
  installed. The game ships names for all 12 of MystTiq's languages. Search in the picker finds them too.
- **Switching language updates them:** the picker reads the names again, and the map picks them up on its next
  refresh. Each language is read from the game once and kept until the game updates.
- **English when the game has none:** if an installed game lacks a language's names, English names are shown and the
  picker says so.
- **Whole map texts translated:** the summary under the map, a Pal's tooltip (name, level, where it is, coordinates)
  and the host's uptime now follow the language too.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.1.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. The English names already read from the game are reused; other languages are read the first time they are needed (a few seconds each). Game names need Python with the Oodle module (ooz), as before.

## Known limitations

This is a development version, not v1.0. Messages sent by the MystTiq service itself (Doctor findings, server replies) are still English (v0.9.3.0). The 11 translations need native review. On Linux, file pickers and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need the live scripts to be run with a player and real channels. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# MystTiq Palworld Server Manager v0.3.0.6

## Secure Remote API Enrollment & TLS Provisioning

v0.3.0.6 makes the existing remote-management security boundary operational without requiring manual token, certificate, JSON, ownership and curl steps.

### New commands

```bash
./mysttiq-server api-tls-create
./mysttiq-server api-remote-enable
./mysttiq-server api-remote-disable
```

### Linux enrollment

From the extracted v0.3.0.6 build:

```bash
bash ./scripts/Configure-MystTiqRemoteApi.sh \
  --bind 192.168.1.248
```

The enrollment runner asks for explicit confirmation and one sudo authorization, then:

- creates/reuses the bearer token
- creates/reuses the self-signed TLS PFX/password
- assigns protected files to the MystTiq service account at mode 0600
- enables auth + TLS remote configuration
- reinstalls/restarts the current MystTiq service
- validates the systemd unit
- validates HTTPS health
- validates bearer-authenticated status

No firewall rules are changed.

### Windows LAN acceptance

```powershell
.\scripts\Test-MystTiqRemoteApi.ps1
```

The test uses the existing dedicated SSH key to retrieve the token into process memory only, then verifies LAN HTTPS reachability, unauthenticated HTTP 401 and authenticated HTTP 200.

### Safe rollback

```bash
bash ./scripts/Disable-MystTiqRemoteApi.sh
```

returns MystTiq to the loopback API configuration.

### Test certificate

The generated self-signed certificate is appropriate for the disposable test environment. Production certificate enrollment/trust remains future work.

# v1.0.7.2 — Progress You Can See

The third release from the outside quality review (roadmap items Q-8, Q-12, Q-13 and Q-7).

## A server start shows its steps

A start used to say only "Starting" until it was running or had failed, so a slow start and a stuck one looked the
same. The Dashboard's server tile now says which step a start is at and for how long: checking settings, launching
PalServer, waiting for the game port (for example "Waiting for the game port: 40 s (starting for 85 s)"). A start that
fails names the step it stopped at.

## Backup scans show progress and can be cancelled

Verify All, and the reading of each backup's world day, now show "12 of 47" on the Backups page, list each archive
they could not read with the reason, and have a **Cancel** button. Cancelling Verify All keeps the results it already
has. The world-day list is saved every 10 backups instead of after every one.

## Opening a page while MystTiq is busy says so

Map and Players opened while something else was running used to sit empty for up to a minute. They now say at once
what they are waiting for, load the moment it finishes, and stop waiting if you move to another page.

## The connection line says what is wrong

Instead of "Connection failed" for everything, the connection line now tells these apart, each with what to do:
- the service is unreachable;
- reconnecting (with the attempt number);
- the sign-in was rejected;
- the certificate doesn't match the pinned one;
- the service answered with an error.

When Palworld is running but its REST API isn't answering, the Dashboard says so too.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.0.7.1

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. If the Dashboard says the local service is older, click **Update Service To This Version**. Coming from an older version, also read the notes of the versions in between.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

# MystTiq v0.7.41.0 — MOD Update Detection

## Highlights

- **New "Check for Update" / "Update" actions** in MOD Library's details panel, scoped to what's actually verifiable without a live network call: whether Steam's own local Workshop content cache for a matching item is newer than what's currently installed.
- MODs with no matching local Workshop source get an honest "no known update source" message instead of a guess.
- Update reuses the existing, already-tested Workshop-import route.
- Deliberately kept out of the Update Center, per the original finding.

## Upgrade notes

- No configuration schema change.
- This is not a live "check Steam's servers for the newest version" feature — that would require a genuinely new Steam Web API integration, explicitly deferred (same category as the UE4SS Release Catalog Backend item). What ships here is real, on-disk evidence only.
- Verified against a real built sidecar: the existing MOD install/traversal runtime smoke checks pass unaffected.

# MystTiq v0.7.53.0 — Dashboard Layout Density

## Highlights

- **The Dashboard's stat cards are noticeably more compact** — smaller padding and font sizes
  across the main stat-card grids and the World Pulse strip, matching the density of an older
  MystTiq reference build. Fits more information on screen without scrolling.

## Upgrade notes

- No configuration changes, no behavior changes — purely visual density.
- No way to visually render this app in the environment that built it — please take a look at the
  Dashboard before considering this fully verified; the exact padding/font-size values are
  reasonable estimates, not pixel-tuned against a rendered window.

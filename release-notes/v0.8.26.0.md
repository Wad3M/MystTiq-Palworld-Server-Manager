# v0.8.26.0 — Clean Repository, Live Acceptance Scripts

- **No change to how the app behaves.** This is a clean-up and verification release on top of the v0.8.25.0 baseline.
- **The legacy WPF app is gone.** `src/PalworldManager`, its Inno Setup installer and the scripts that only built or
  packaged it were removed. The solution now holds exactly the product: `MystTiq.Core`, `MystTiq.HeadlessHost` and
  `MystTiq.Desktop`. The Desktop carries the version in its own Windows manifest.
- **About a thousand obsolete files removed:** old tests the release gate no longer runs, pre-0.8 change lists and
  test plans (every version's notes stay), WPF-to-Avalonia parity notes and working-tree leftovers. They remain in the
  git history and earlier source archives. Every remaining file was reviewed and carries a v0.8.26.0 review stamp; the
  full list is in `docs/release/FILE_AUDIT_v0.8.26.0.md`.
- **Windows and Linux packages from one command:** `Build.ps1 Package` builds the self-contained Windows and Linux
  ZIPs (the desktop with the headless service beside it) and their checksums. The GitHub release workflow publishes
  the Windows package.
- **Live acceptance scripts** for the checks that used to need a person:
  - `Test-v0.8.26.0-LinuxDesktopSession.ps1`: the desktop on a real Linux X11 session: window, maximize and restore,
    clipboard, tray icon and all four sign-in roles (passed 16/16 on the XFCE test machine);
  - `Test-v0.8.26.0-InGame.ps1`: with a player on the clone server, gives one item, captures their position through
    PalDefender, teleports them to it and puts the teleport settings back, and records the map calibration pair;
  - `Test-v0.8.26.0-Alerts.ps1`: sends a real test notification through every switched-on channel and reports any
    failed send;
  - `Test-v0.8.26.0-ContrastTheme.ps1`: with a Windows contrast theme on, checks the MystTiq window uses its colours.
  The in-game and alerts scripts are rehearsed against stand-in servers by the release gate.
- **Fixed:** the v0.8.25.0 release note's title had a garbled dash; the publishing guide and the README no longer
  describe the removed WPF installer; building the native console helper no longer leaves `dllmain.obj` in the
  repository root; Linux shell scripts keep LF line endings on every checkout.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.8.25.0

Close MystTiq, extract v0.8.26.0 into a new folder and start it; settings, accounts and server data are stored outside the application folder and are kept. Nothing about stored data changed in this version. If you built from source, note that `src/PalworldManager`, `installer/` and the old `Test-v*` scripts are gone: pull with a clean working tree.

## Known limitations

This is a development version, not v1.0. Translation remains partial. On Linux, file pickers and installed-service priority recovery still need acceptance. Actual give-item/Pal delivery, live map/teleport calibration and real Discord/email delivery need the live scripts above to be run with a player and real channels. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

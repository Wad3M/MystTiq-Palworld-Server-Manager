# MystTiq v0.7.48.0 — Central Theme System Completion, Foundation Pass

## Highlights

- **Accent themes and Light mode now actually re-theme far more of the app** — every page's accent color (Server/World/Mods/Backups/Tools/System), every status glow, category tabs, ribbon context colors, status badges, mod/backup cards, and general interactive hover glow now respond to your theme choice, not just a handful of surfaces.
- **Per-page accent colors now shift with your chosen accent theme** (Emerald/Crimson/Violet), not just with Dark/Light — a direct scope decision, since previously they stayed locked to the default palette regardless of which theme you picked.
- **Also fixed**: Update Center's UE4SS row was reading a stale GitHub tag from before the fork changed its release strategy — now always shows the actual latest release.

## Upgrade notes

- This is a foundation pass, not full coverage — roughly 240 more hardcoded colors remain in the shared style sheet (mostly elaborate translucent "glass" hover effects) that need more careful, harder-to-verify work before they can safely become theme-aware too. Tracked as a follow-up.
- Nav pane icons and background/atmosphere artwork are confirmed as wanted for theming but are out of scope for this version — they're pre-rendered images with no editable source, so making them theme-aware needs real asset or rendering work, not a config change.
- Three terminal-style log views (Dashboard's mini console, RCON output, the full Console page) are deliberately kept dark/green in every theme, matching how most apps keep a terminal panel dark regardless of the overall UI theme.
- No way to visually render this app in the environment that built it — please click through Settings' theme picker across all four themes and both Light/Dark before considering this fully verified, and report back anything that still looks wrong.

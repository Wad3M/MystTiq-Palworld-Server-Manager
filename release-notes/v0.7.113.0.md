# v0.7.113.0 — Teleport Points

Third of the four items pulled into 0.7.x on 2026-09-22.

- **Players can teleport from anywhere to a named point** by typing a chat command: `!tp spawn`, or just `!tp`
  to list the points. Set it up on the Map page's new Teleport Points card: switch it on, choose the command
  and a cooldown, and list the points.
- Why a chat command: the game's own fast travel cannot be opened up from the server. Palworld only has
  "fast travel on/off" and "base camps only"; fast travel from anywhere exists only as a client-side mod every
  player would install.
- Needs PalDefender and RCON (MystTiq runs PalDefender's teleport for the player) and the Palworld REST API
  (to confirm who typed the command). "Capture Selected Player's Position" asks PalDefender where an online
  player is standing, so you don't have to work out coordinates. "Send" moves a selected player to a point
  directly.
- Safety: only a player who is online under exactly that name and id can trigger it, so a fake chat header
  can't teleport someone else. Each player has a cooldown, and old chat is never replayed.
- Checked with 5 new logic-harness scenarios, and a live smoke where a chat line in a PalDefender log produced
  exactly the right teleport command over RCON. Not yet checked with a real player and real PalDefender chat.

# MystTiq v0.7.1.0 — Page Ordering, Tab Bar & Simple Settings Visibility

## Highlights

- **Seven page-ordering fixes**: the Players page's World Map no longer sits between the search bar and the list it doesn't filter; Backups no longer shows duplicate Verify/Restore/Delete buttons; Automation shows existing rules before the new-rule form; Monitoring shows CPU/RAM/Threads before the audit log; Fleet shows existing server profiles before Clone World; Diagnostics Center's "Restart Server" is now visually separated from safe read-only actions; Settings no longer duplicates Workspace's editable server-path fields.
- **Pal Editor** moved from the Guilds page to the Players page, where it actually belongs.
- **Simple Settings** now shows a visible note if any curated setting isn't found in your server's actual `PalWorldSettings.ini`, instead of silently vanishing. (The Simple Settings code itself was already correct — no bug there.)
- **Tab bar** now shows each server's name with "Local" or "Remote" underneath, and the **"+"** button is a plain plus sign.

## Upgrade notes

- No configuration schema change, no server-side change at all — this release is entirely `MystTiq.Desktop`.
- This is the first of several planned v0.7.x releases addressing a broader UX pass (port-conflict validation, a new-server wizard, card visual "flare," and reducing how much scrolling most pages need) — see `CHANGELOG.md` for the full plan.

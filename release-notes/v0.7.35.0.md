# MystTiq v0.7.35.0 — Button Color System

## Highlights

- **Two new semantic button colors**, designed once and applied consistently: cyan `inspectAction` for non-mutating "look at/confirm" buttons, violet `targetAction` for "act on a specific thing" buttons — neither reuses the Save/Start gradient.
- **Workspace's Browse (4) and Open-in-explorer (10) buttons** now use these colors instead of the identical default gray every button in the app previously shared.
- **Server Setup's per-row VERIFY/RESCAN vs. MANAGE/INSTALL/CREATE/ENABLE action buttons** now pick up the right color automatically, driven by the row's real action type.
- **Configuration's Generate button** is now bigger and labeled "🎲 Generate" instead of an icon-only button — it was already functionally enabled, just easy to mistake for disabled.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- The new gradients follow the exact same construction as the already-shipped success/danger/warning button colors, so they should read consistently — flag anything that looks off once seen live.

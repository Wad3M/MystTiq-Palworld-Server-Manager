# v0.5.1.2 — v0.5 Shell Functional Integration

This correction makes the approved v0.5.0.18 prototype shell the actual functional desktop foundation.

- The custom title bar, MystTiq wordmark, profile tabs, category strip, ribbon, glass navigation, workspace atmosphere and bottom operation bar are now used by `MystTiq.Desktop`.
- Server tabs bind to real saved connection profiles rather than prototype sample servers.
- Refresh, Start, Restart, Stop, Backup, Console and Doctor invoke the existing production commands.
- All restored pages remain intact inside the workspace with their View → ViewModel → API client → route → headless service wiring.
- Home contains Dashboard and Notifications.
- World contains Inspector, Players, Bases and Guilds, with the Inspector aligned at the top.
- System contains Settings and Activity & Audit.
- The notification and settings buttons in the title area open their corresponding real pages.
- Card clipping, centered metallic buttons, the single aggregate status poll, remote/LAN security, and Windows/Linux parity remain mandatory.

Promotion requires strict validation, the versioned logic gate, Windows and Linux headless/desktop builds, runtime smoke, visual verification, packaging and checksum verification.

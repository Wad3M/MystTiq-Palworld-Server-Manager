# MystTiq Palworld Server Manager v0.3.1.3 FIX4

## Dynamic Deployment Version & Validation Cleanup

Fixes two stale-version defects found during live deployment preparation:

- `Deploy-Test-MystTiqLinux.ps1` now derives the current project version from `Get-ProjectVersion.ps1` instead of hard-coding v0.3.0.7.
- Headless archive selection is version-driven, so a v0.3.1.3 build is matched to the v0.3.1.3 archive.
- The logic harness uses dynamically constructed current-version Linux acceptance/production paths so release validation no longer flags those filenames as stale prerelease-like versions.

No runtime behavior changed.

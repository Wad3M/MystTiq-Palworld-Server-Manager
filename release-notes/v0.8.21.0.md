# v0.8.21.0 — Linux: Back to Full Speed After Eco Mode

- **On Linux, eco mode can now be undone.** Until now, once eco mode had lowered the server's priority, the MystTiq
  service could not raise it again when a player joined. The service MystTiq installs now allows that, without
  running as root or getting any extra permission. Run `service-install` again to update an existing service.
- **New `service-unit` command.** It shows exactly what `service-install` would write, without installing anything or
  needing sudo.
- **Tests no longer write to your real MystTiq data.** Some of MystTiq's own automated tests used to add lines to the
  real fleet activity log (and, since v0.8.20.0, host history readings). Each test now keeps its own folder. The new
  `--fleet-root` option makes that possible for any command.

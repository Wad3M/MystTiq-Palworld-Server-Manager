# MystTiq v0.7.47.0 — UE4SS Release Catalog

## Highlights

- **The UE4SS page's "Release source" dropdown now shows real release data** for the first time — Palworld Fork (`Okaetsu/RE-UE4SS`) and Official Upstream (`UE4SS-RE/RE-UE4SS`) each list their actual GitHub releases, with the correct install asset already picked out from each release's multiple attached files.
- **Investigated the real console-capture fix live, before building anything**: tested `-ABSLOG` file logging and launching the game's own process directly, both against an isolated copy of your real server. Neither captured any real engine output — this isn't a configuration problem, it's how Palworld's engine handles its own console internally. The only proven working technique (used by a third-party tool called PalServerLogger) is native DLL injection, which is a genuinely separate, larger project — scoped in the roadmap, not built yet.
- **Surfaced a real, unrelated finding along the way**: the UE4SS fork's release strategy recently changed, which means Update Center's UE4SS "latest version" row (shipped in v0.7.45.0) is now reading stale data. Not fixed in this version — flagged for a follow-up.

## Upgrade notes

- Listing only — there's no install or rollback action yet. Picking a release just shows you what's available; installing one still means downloading and applying it yourself for now.
- Makes an outbound network call to GitHub when "Refresh Runtime" is clicked on the UE4SS page. Degrades gracefully if GitHub is unreachable.

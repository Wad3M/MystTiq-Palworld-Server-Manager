# MystTiq v0.7.51.0 — Per-Tab Color Coding

## Highlights

- **Every open tab now has its own persistent identity color** — a small colored stripe in the tab
  strip, auto-assigned when a server profile is first created and kept for that server from then on.
  Makes it easy to tell tabs apart at a glance once you have several servers open.
- The identity color is deliberately separate from the existing green/amber/red status dot (health)
  and the selected-tab highlight (which server tab currently has focus) — three independent signals,
  not merged into one.

## Upgrade notes

- No configuration needed — colors are assigned automatically and immediately for both new and
  already-saved profiles.
- No way to visually render this app in the environment that built it — please take a look at the
  tab strip with a few servers open before considering this fully verified.

# MystTiq v0.7.34.0 — Category Tab & Nav Pane Styling

## Highlights

- **Category tab selected/hover gradients swapped.** Selecting a tab now settles into the darker glass look; hovering shows the brighter gradient — the reverse of before, and now matching the stylesheet's own long-standing comment describing the intended look.
- **Navigation pane background** changed to the same darker glass-hover gradient used elsewhere in the app (ribbon buttons, category tabs, nav buttons), replacing a flatter fill.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- Both changes are pure style-resource swaps — no new resources, no layout changes.

# v0.2.14.9 FIX3 — Update Center Actions & Admin Commands Runtime Detection

## Changed
- Reduced the Update Center row action button and column dimensions.
- Added semantic action colors: amber for Update, green for Verify/Install/Enable/Create, blue for Source/Manage/Check/Retry, and warning amber for Disable.

## Fixed
- Admin Commands runtime evidence is detected from both live process output and `Pal.log`.
- Detection accepts display/package variants such as `AdminCommands`, `Admin Commands`, bracketed names, and underscore-separated names.
- Successful initialization, registration, hook, heartbeat, and load messages update the console status immediately.
- Explicit load failures reset the status.

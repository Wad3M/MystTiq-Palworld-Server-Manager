# MystTiq v0.7.8.0 — RCON-Powered Admin Tools

## Highlights

- **Unban and a Ban List view**: the "Unban" button on the Players page — disabled since it was first added — now works, backed by Palworld RCON's `UnBanPlayer` command. A new collapsible Ban List card shows who's currently banned.
- **Admin teleport**: summon a player to you, or teleport to them, via RCON. Requires your own admin character to be present in the world — Palworld's dedicated server has no built-in concept of an admin who isn't also a player.
- **Save World Now**: a one-click force-save button on the Dashboard, instead of needing to type `Save` into the raw RCON console.
- **Real bug fixed**: found while wiring the above onto the same player-selection mechanism Kick/Ban already use — that selection wasn't actually covered by v0.7.6.0's tab-switch fix (a different property than the one that fix addressed), and had an even wider staleness window. Fixed in this release.

## Upgrade notes

- No configuration schema change. The only server-side change is four new thin RCON-wrapper routes — no `MystTiq.Core` model changes.
- All three new features require Palworld's RCON to be enabled and configured on the target server (the same requirement the existing raw RCON console already has).

Full detail in [`CHANGELOG.md`](../CHANGELOG.md).

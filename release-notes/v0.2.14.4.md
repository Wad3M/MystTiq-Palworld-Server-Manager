# MystTiq Palworld Server Manager v0.2.14.4

## World Inspector Reorganization & World Management Foundation

### Added
- World Inspector tabs for Overview, Players, Guilds, Bases, Saves, World Validator, World Management, Repair Center, and Transaction History.
- Dark-themed progressive World Management migration wizard.
- Status and next-step guidance throughout migration.
- Disabled-stage explanations and consistent MystTiq semantic button styles.
- Sidebar shortcut that opens the nested World Validator tab.

### Notes
- Player, Guild, and Base tabs provide world-context guidance and open the existing full managers for detailed actions.
- Transaction History is intentionally informational until the transaction engine is implemented; it contains no misleading inactive action controls.
- Repair Center continues to provide preview-only repair planning in this release.

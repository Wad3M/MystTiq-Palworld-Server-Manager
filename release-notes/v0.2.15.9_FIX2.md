# MystTiq Palworld Server Manager v0.2.15.9 FIX2

## Native UE4SS Detection & Verification

This refinement addresses the live AntiDupe and PalImportFilter results from FIX1.

### Changes
- UE4SS folders are classified from their actual payload as Lua, Native, Hybrid, or generic UE4SS.
- Native DLLs receive safe static PE/string capability analysis without loading or executing third-party code.
- Static DLL findings never promote runtime state by themselves.
- Active / Unverified is no longer counted as a failure/attention condition when no other problem exists.
- Dashboard wording changes to `awaiting runtime confirmation` for quiet valid MODs.

### Expected AntiDupe / PalImportFilter behavior
Their inventory type should become `UE4SS / Native` when the package contains DLL payload and no Lua source. They may remain Active / Unverified until genuine current-session loader or functional evidence is observed.

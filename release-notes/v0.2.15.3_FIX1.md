# MystTiq Palworld Server Manager v0.2.15.3 FIX1

## Installer default path and elevation hotfix

Application logic remains v0.2.15.3. This hotfix corrects installer behavior discovered during release-candidate testing.

### Fixed
- New installer deployments default to `C:\GameServers\MystTiqPalworldServer`.
- Installer execution now requires administrator privileges.
- The post-install **Launch MystTiq Palworld Server Manager** action runs with the elevated installer credentials.
- The application manifest continues to require administrator privileges for normal Start Menu, desktop-shortcut, and direct executable launches.
- README installation/download guidance now reflects the available installer, actual executable name, default install directory, and elevation requirement.

### Upgrade behavior
`UsePreviousAppDir=yes` is retained intentionally. Existing installations keep their previously selected installation directory during upgrade; fresh installations default to `C:\GameServers\MystTiqPalworldServer`.

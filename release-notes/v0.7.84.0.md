# MystTiq v0.7.84.0 — Fleet Clone World Workflow

## Highlights

- **Clone World on the Fleet page is now a clear, labeled workflow**: a SOURCE section names which
  connection you're cloning from, a NEW PROFILE section for the new server's ID/name, and a PORT
  OFFSET section explaining what it does — instead of one flat, unlabeled card.
- **New: "Restart MystTiq Now" button** appears after a successful clone, so you can bring the new
  server online immediately without hunting for a manual restart step.

## Upgrade notes

- No configuration changes. Touches `MystTiq.Desktop` only.

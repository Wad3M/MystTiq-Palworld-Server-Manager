# MystTiq v0.4.0.0 — Windows Persistent Service Foundation

This begins the v0.4 architecture line.

## Added

- `WindowsServiceManager` in shared core with SCM status/install/uninstall support.
- Automatic-start registration and bounded Windows service restart policy.
- `WindowsServiceStatus` and install-result contracts.
- `Build.ps1 WindowsHeadless` and `scripts/Build-WindowsHeadless.ps1`.
- win-x64 publication of the shared headless host.

## Boundary

This is the service **foundation**. The next v0.4 build connects Windows-native PalServer lifecycle/session supervision and the management API to service-run. Existing WPF behavior is intentionally preserved until that acceptance gate passes.

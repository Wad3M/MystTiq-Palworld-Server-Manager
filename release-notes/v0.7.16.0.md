# MystTiq v0.7.16.0 — Responsive Tab Strip

## Highlights

- **The tab strip finally uses the space it has.** It was capped at a fixed 720px no matter how wide the window actually was, and tabs that didn't fit within that cap were silently cut off with no way to get to them.
- **A new chevron button appears once tabs overflow**, opening a list of the hidden ones — click to switch — plus "Set Up New Server," the same option the "+" button already offers, so you're never stuck without a way to add another server just because the strip is full.
- **Switching to a tab always brings it into view**, including from the new overflow list — the tab you're looking at is never the one that gets hidden.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.

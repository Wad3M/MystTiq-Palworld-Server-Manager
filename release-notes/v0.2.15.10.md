# MystTiq Palworld Server Manager v0.2.15.10

## Native Runtime Module Evidence

Adds a second independent runtime proof source for native/hybrid UE4SS mods.

- Enumerates modules mapped into the current MystTiq PalServer session.
- Matches exact canonical DLL paths to the resolved active UE4SS mod folder.
- Supports duplicate filenames such as multiple mods using `main.dll`.
- A mapped native DLL promotes Active / Unverified to Confirmed Loaded at 100% confidence.
- Confirmed Running remains reserved for observed mod-specific functional activity.
- Empty/unavailable Windows module enumeration remains Unverified rather than Failed.
- Module evidence is tied to the current ServerService session/PID snapshot and is discarded when that session ends.
- Inspection is read-only; MystTiq does not inject, load, unload, patch, or execute third-party DLLs.

# v1.0.0.0 — MystTiq 1.0

MystTiq 1.0 is the first stable release of the desktop and service for running Palworld communities. It brings
together everything from the v0.9 series.

- **Your language:** the desktop, the service's messages and the game's item and Pal names in 12 languages, with numbers
  and dates in the chosen language's format (English keeps your system's). Server and player names stay exactly as you
  wrote them.
- **Servers you can trust:** servers never start each other, adding a new server leaves the running ones alone, and
  one local helper watches them all. Upgrades, restores and rollbacks keep your settings, worlds and accounts.
- **Let players in:** Settings, Diagnostics and the new-server wizard show whether Windows Firewall lets players reach
  the port each server really uses, with an **Allow through Firewall** button. The Doctor spots a port mismatch and
  fixes it on request.
- **Know when something falls behind:** the Alert Center tells you (and Discord or email) when the game server,
  PalDefender, UE4SS or an installed MOD has an update.
- **Find the cause:** the Crash Analyzer names known causes, including a server whose session ends as a player joins.
- **Find your servers:** the server search checks 256 addresses at a time and lists each server as it answers.
- **Built on Avalonia 12**, with accessible names and keyboard reach throughout, and roles that explain what each
  control needs.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.x

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

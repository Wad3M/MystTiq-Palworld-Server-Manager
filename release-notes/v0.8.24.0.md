# v0.8.24.0 — Processor Cores

- **Choose which processor cores a server uses.** The HOST tab's priority card has a new "Processor cores" field (for
  example `0-3, 6`; empty means every core). Handy when several servers or other programs share the machine. Each
  running process shows the cores it is on.
- **Priority, eco mode and cores apply as soon as the server starts** through MystTiq, instead of up to 15 seconds
  later.

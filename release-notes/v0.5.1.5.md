# v0.5.1.5 — First-Run Setup Wiring and Update Center Correction

This release completes the remaining first-run Server Setup workflow identified by the ordered v0.2.16.4 screen comparison and corrects Update Center card visibility.

- Server Setup restores Server Name, Description, Admin Password, optional Server Password, Maximum Players, Game Port, and REST Port fields.
- Create Default Settings follows View → ViewModel → API client → `POST /api/v1/palworld/config/defaults` → `PalworldSettingsConfigurationService`.
- Creation requires explicit confirmation and bounded server-side validation.
- An existing `PalWorldSettings.ini` is never overwritten; active servers continue to use Configuration for edits.
- The official default configuration is the creation source, and its REST/RCON enabled states are preserved rather than changed implicitly.
- Passwords are omitted from audit details and cleared from the setup ViewModel after successful creation.
- Update Center again displays its Platform, SteamCMD, and Palworld Server summary cards on the correct page.

Promotion requires clean validation, logic, Windows/Linux desktop and headless builds, Windows runtime smoke, archive-entry verification, and SHA-256 verification.

# MystTiq v0.7.66.0 — Tray Reminder Toast Positioning Fix

## Highlights

- **Fixes a real reported bug**: on a multi-monitor setup (secondary monitor stacked above the
  primary at a negative Y origin), the "MystTiq is still running" tray toast rendered far from its
  intended bottom-right corner — roughly mid-screen. Root cause: it resolved its target monitor from
  its own not-yet-positioned window at the moment it first opened, rather than from something already
  settled on the correct screen. It now resolves the screen from the main window instead (which is
  always already correctly positioned when the toast appears, since it only shows right after the
  main window is hidden to the tray).

## Upgrade notes

- No configuration changes, Desktop-only.
- **Not verified visually** — no way to render the native Avalonia window or reproduce the reported
  multi-monitor layout in this environment. The fix targets the specific mechanism identified in the
  bug report; a live check on the actual hardware is the way to fully confirm it.

# MystTiq Palworld Server Manager v0.3.0.1

## Linux Server Lifecycle Control

v0.3.0.1 is the first v0.3 phase that grants the Linux headless host direct PalServer lifecycle authority.

### Commands

```bash
./mysttiq-server status
./mysttiq-server start
./mysttiq-server stop
./mysttiq-server restart
```

### Start

- verifies `PalServer.sh`
- blocks duplicate starts
- launches PalServer in a detached Linux session
- preserves the validated default launch arguments
- captures detached console output under the MystTiq runtime directory
- waits for the real `PalServer-Linux-Shipping` process
- verifies UDP 8211 before reporting ready
- leaves a still-running process alone if only port verification times out

### Stop

- persists the stop intent before signalling
- sends POSIX SIGTERM first
- waits for the configured graceful timeout
- only then escalates remaining managed PalServer processes/descendants to SIGKILL
- reports whether force escalation was required

### Restart

An active server is stopped safely and then started. Restart from stopped/crashed state behaves as start.

### Lifecycle evidence

`/opt/mysttiq/runtime/lifecycle-state.json` retains transition evidence across short-lived CLI invocations. A previously running/starting PalServer that disappears without a requested stop can be surfaced as `Crashed`.

### Exit codes

- `0` success/status healthy
- `2` invalid command/arguments
- `10` duplicate start blocked
- `11` stop requested while already stopped
- `12` server entry missing
- `13` launch failed
- `14` startup verification timeout
- `15` stop timeout after escalation
- `16` crash detected by `status`
- `20` lifecycle command used on an unsupported host platform
- `130` interactive cancellation

### Tested Linux reference

Primary runtime validation remains:

- Ubuntu Server 24.04.4 LTS
- x86_64 / amd64
- observed kernel: 6.8.0-137-generic
- Valve Linux SteamCMD
- Palworld Dedicated Server App 2394010
- Linux depot 2394012
- native `PalServer-Linux-Shipping`
- UDP 8211

Windows WPF behavior is intentionally unchanged in this phase.

# MystTiq v0.7.52.0 — "+" Flow Restructure

## Highlights

- **The "+" (add tab) button now offers four clear choices instead of one**: Set Up New Server,
  Connect to Local Server, Connect to Remote Server, and Clone a Server (shown once you have at
  least one connected local server to clone from). Local vs. Remote used to be buried one step
  inside the setup wizard — now you pick it directly from the flyout.
- Clone a Server is reachable from the "+" flyout for the first time — it always worked, but used
  to require navigating to the Fleet page manually first.

## Upgrade notes

- No configuration changes, no new backend routes — every new flyout entry reuses existing,
  already-working commands.
- No way to visually render this app in the environment that built it — please open the "+" flyout
  with and without a connected local server open, to see all four (and five) states, before
  considering this fully verified.

# MystTiq Palworld Server Manager v0.3.1.1

## Shared Shell, Navigation & Connection Foundation

### Added

- working cross-platform Avalonia navigation
- Dashboard, Server, Players, Backups, Mods, Doctor and Settings pages
- persistent local/remote connection profiles
- cross-platform JSON profile storage
- process-memory-only bearer token handling
- optional TLS SHA-256 certificate pinning for known self-signed MystTiq endpoints
- normal OS TLS validation when no certificate pin is configured
- profile save/delete flows
- Linux desktop build/deploy/SHA256/smoke-launch automation
- `Build.ps1 DeployDesktopLinux`

### Authority boundary

The GUI remains an API client. Closing the desktop application does not stop `mysttiq-server` or PalServer.

### Deferred

Lifecycle Start/Stop/Restart UI is intentionally deferred to v0.3.1.2.
Players/logs/monitoring are planned for v0.3.1.3.
Backups/configuration are planned for v0.3.1.4.
Doctor presentation is planned for v0.3.1.5.

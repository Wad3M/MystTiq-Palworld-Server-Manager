# MystTiq v0.7.19.0 — Full Navigation Icon Set

## Highlights

- **Every page in the nav sidebar now has a real icon.** Since v0.7.0.0, only 7 of 25 destinations did — the rest (Configuration, Console, Workspace, Inspector, Guilds, both MOD pages, UE4SS, Update Center, Server Doctor, Crash Analyzer, Save Tools, Diagnostics, Settings, Notifications, Activity & Audit, Automation, Alert Center) were stuck with plain text symbols like "⚙" and "▰" glued onto the label.
- **A complete, consistent "glass orb" icon set** — glossy gradient spheres in distinct accent colors, each with a purpose-matched glyph — replaces both the old icons and the old text symbols uniformly.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- Adds 25 new PNG files under `Assets/Icons/`; the app is a few MB larger as a result.

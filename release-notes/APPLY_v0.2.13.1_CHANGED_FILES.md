# Apply v0.2.13.1 Changed Files

This package is intended for the clean v0.2.12 GitHub baseline.

1. Close Visual Studio and MystTiq Palworld Server Manager.
2. Back up or commit the current repository state.
3. Extract this ZIP over the repository root, preserving folders.
4. Allow replacement of existing files.
5. Open `PalworldServerManager.slnx`.
6. Clean and rebuild `Release | x64`.
7. Follow `BUILD_TEST_PLAN_v0.2.13.1.md`.

The authoritative version is now `VersionPrefix` in `Directory.Build.props`.

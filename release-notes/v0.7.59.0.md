# MystTiq v0.7.59.0 — Safe-Start MOD Diagnostic

## Highlights

- **A new "Safe-Start Diagnostic" button on MOD Library** automates the standard community fix for
  a crashing/hanging modded server: it stops the server, then restarts it one MOD at a time,
  testing each one for both an outright crash AND a startup hang that never becomes ready. Any MOD
  that fails is disabled automatically and the run continues; you get the server back up and
  running with the working MODs, no manual trial-and-error required.
- **A baseline check runs first** — if the server won't even start with every MOD disabled, the
  diagnostic stops immediately and tells you it's not a MOD problem, instead of wasting time and
  falsely blaming every MOD in turn.
- Runs over several minutes (real start/stop cycles), with a live progress card showing what's
  being tested and the results as they come in. Cancellable at any point — cancelling restores
  every MOD to how it was before the diagnostic began.

## Upgrade notes

- No configuration changes, no data migration.
- This is real live-server work when you use it — it stops and restarts your server repeatedly.
  Only run it when you're prepared for that (e.g., after a crash, not during active play).
- No way to visually render this app in the environment that built it — please try the diagnostic
  against a real modded server and confirm the progress card and Cancel button behave as expected.

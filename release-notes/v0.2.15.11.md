# MystTiq Palworld Server Manager v0.2.15.11

## MOD Architecture Modularization

This release is an internal architecture refactor. It intentionally preserves the v0.2.15.10 FIX1 user experience and MOD behavior.

### Architecture
- `ModCoordinator` owns application-level MOD workflow orchestration.
- `ModDashboardStateService` owns Dashboard row projection/state merging and summaries.
- `ModWorkflowModels` provides explicit workflow result contracts.
- `MainWindow.ModCenter.cs` contains MOD-specific UI handlers, reducing the central MainWindow file.

### Why
The smaller boundaries reduce MainWindow coupling and prepare the codebase for server/platform modularization before v0.3.0.0 Linux support.

### Compatibility
No settings, MOD storage layout, runtime evidence semantics, visual theme, button standards, or tooltip standards are intentionally changed.

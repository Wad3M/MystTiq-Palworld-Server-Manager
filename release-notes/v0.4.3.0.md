# MystTiq v0.4.3.0 — Dashboard & Local Server Backend Integration

## Added

- Cross-platform local installation discovery in `MystTiq.Core`.
- Windows discovery reads the current persistent-service configuration when present and falls back to the original GUI's `%ProgramData%\MystTiqPalworldServer\settings-v2.1.json`.
- Known Windows default `C:\GameServers\Palworld\Server` and Linux `/opt/mysttiq/palserver` remain safe final discovery candidates.
- MystTiq service state, PalServer installation state and management API state are represented independently.
- The Avalonia client automatically discovers the local API endpoint and attempts the local connection at startup.
- API failure no longer erases local PalServer installation evidence.
- The Dashboard now loads real monitoring, distribution, backups, world, player/guild and MOD information when connected.
- The dashboard layout more closely follows the information density and operational pattern of the v0.2.16.4 interface.

## Safety / architecture

- Local discovery is read-only.
- Destructive server lifecycle operations remain routed through the management API.
- No fake player/world/MOD/backup data is synthesized.
- Windows and Linux use the same Avalonia ViewModel and Core discovery contract.

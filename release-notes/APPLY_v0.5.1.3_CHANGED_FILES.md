# Apply v0.5.1.3 Changed Files

The Changed Files ZIP is an audit/convenience package for the promoted v0.5.1.2 source baseline. Normal installation should use `MystTiqPalworldServer_v0.5.1.3_FullSource.zip` with `Update-FromDownloads.ps1` so the running artifact app closes, the staged source replaces cleanly, and the complete current-version gate runs before relaunch.

Do not overlay it onto v0.4.17.4 or an unknown source tree.

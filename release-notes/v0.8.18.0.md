# v0.8.18.0 — Bandwidth

- **Bandwidth limits on the HOST tab.** Choose how much the server may send to each player and how often it updates
  them, or keep the game's own limits (the default). Palworld allows 64 Mbit/s per player, with 60 updates a second on
  Windows and 20 on Linux.
- **Know whether your connection can take it.** Enter your upload speed to see the most a full server could send.
  You're warned when that would fill your connection, and "Use It" fills in a limit that fits.
- **It sticks.** MystTiq writes the limits into the server's Engine.ini just before every start, including restarts
  after a crash. The game rewrites that file when it stops, so a change made while it runs would otherwise be lost.
  If you save while the server is running, MystTiq tells you a restart is needed. Nothing else in Engine.ini is
  changed, and the original file is kept.
- Everyone signed in can see the limits; changing them needs Admin.

# MystTiq v0.7.21.0 — Experimental Real-World Map Positions

## Highlights

- **A new "Experimental: real-world positions" checkbox** on the World Map card, visible when the Palpagos preset is selected — turns on player dots placed at their actual in-game position instead of just their spread relative to other online players.
- **The underlying math is genuinely verified**, not a guess: it reproduces the reverse-engineering project it's based on's own published worked example exactly, and its constants reconcile precisely with Palworld's documented world-coordinate bounds.
- **Off by default, and clearly labeled experimental** — one piece (the map image's own orientation) isn't independently confirmed, so dots might come out mirrored or offset until someone can check it against a real server. If that happens, just leave it unchecked; the existing relative-position view is untouched.

## Upgrade notes

- Palpagos only — World Tree has no documented calibration source, so it stays relative-position-only.
- The toggle doesn't persist across restarts.
- Desktop-only change, no configuration or server-side impact.

# v0.8.11.0 — Pal Positions on the Map

- **Your Pals are on the map.** With the Palpagos map, violet circles show owned Pals working at a base, or travelling
  in a player's party. Each is placed where the world save last recorded it.
- **Crowds become a count.** Pals standing close together share one circle with a number. A base's workers show as a
  badge on the base's corner. Click it, or its row in "Pals on the map", to zoom right in and see each one.
- **Hover for details.** Each circle shows the Pal's species, nickname, level, and which base or party it belongs to.
- **Honest about what's missing.** Palbox Pals aren't drawn, because the save only remembers where each was last let
  out. Wild Pals aren't in the save at all. The map says how many Pals it isn't showing and why. Species use the
  game's internal names (for example PinkCat) until real display names are available.
- Player names on the map no longer print over a Pal count.

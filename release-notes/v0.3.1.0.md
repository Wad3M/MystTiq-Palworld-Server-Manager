# MystTiq Palworld Server Manager v0.3.1.0

## Avalonia Desktop Foundation

- adds `src/MystTiq.Desktop` using Avalonia, .NET 10, C# and XAML
- establishes Windows/Linux shared desktop codebase
- adds MVVM shell and MystTiq dark styling foundation
- adds management API client boundary and local connection profile
- consumes `/api/v1/status` for first live GUI connection
- adds `DesktopWindows` and `DesktopLinux` build actions
- preserves the existing WPF application during migration

No direct PalServer lifecycle ownership is added to the GUI.

# v1.1.1.2 — Current Players, Guilds and Map, New Icons

**The Players, Guilds, Bases and Map pages show the world as it is now.** They read a decoded copy of the world save.
MystTiq keeps that copy beside `Level.sav` when it may write there, and otherwise in its own folder. Only the Dashboard's
day used MystTiq's own copy; the pages kept reading the one beside `Level.sav`, which on a server whose save folder
MystTiq may not write could be days or weeks old (players under IDs they no longer have, characters marked "Missing
save"). Every page now reads whichever copy is newer, and says which one and when it was decoded.

**New icons** for **MODs > MOD Sources** (it borrowed the MOD Dashboard icon) and **Server > Launcher**.

## Upgrading from v1.1.1.1

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder. Nothing to convert. Coming from an older version, also read the [v1.1.1.1](v1.1.1.1.md), [v1.1.1.0](v1.1.1.0.md) and [v1.1.0.0](v1.1.0.0.md) notes.

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.

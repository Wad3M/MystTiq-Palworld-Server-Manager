# MystTiq v0.7.31.0 — Duplicate-Install Prevention

## Highlights

- **New**: if two open tabs turn out to be connected to the same physical server install — even through different addresses or ports — the Dashboard now shows a warning naming the shared install path.
- Identity is the install location the server reports about itself, not the host/port you connected through, since two genuinely different servers can share a port.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.
- This is a warning, not a block — the install location can only be discovered after connecting, so it appears once detected rather than preventing the connection.

# v0.9.7.0 — Avalonia 12

- **The desktop now runs on Avalonia 12,** the current version of the UI framework it is built with (from 11.3), so it
  keeps receiving fixes and platform support. Nothing about how you use MystTiq changes.
- **Checked page by page:** every page was rendered in all 12 languages and in each appearance mode and compared with
  the previous version. The one visible difference: a window smaller than its content now folds the ribbon into a "»"
  menu instead of running off the edge.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v0.9.6.0

Back up your server data and configuration, then extract into a new application folder. Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert: settings, profiles and languages carry over.

## Known limitations

This is a development version, not v1.0. The Linux desktop on Avalonia 12 still needs its real-session check (window, clipboard, tray) on the test VM. The 11 translations are drafts awaiting native review. See the [roadmap](https://github.com/Wad3M/MystTiq-Palworld-Server-Manager/blob/main/docs/roadmap/PRODUCT_ROADMAP.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server.

# MystTiq v0.7.29.0 — Confirmed Bug Fixes: Detection & Config

## Highlights

- **Fixed**: selecting the "Official / Vanilla" configuration preset no longer overwrites your Server Name, Description, Admin Password, or Server Password — it now only resets gameplay rates, matching how the Balanced/Relaxed presets already behaved.
- **Fixed**: a genuinely-running PalServer at an unexpected install path no longer silently shows as "Stopped" with no explanation. The Dashboard now tells you when it found a matching process at a different path than configured.

## Upgrade notes

- Desktop-only change, no configuration schema change.
- If you've previously applied "Official / Vanilla" and lost a custom server name/password, you'll need to re-enter it — this release prevents it from happening again, it doesn't restore anything that was already overwritten.

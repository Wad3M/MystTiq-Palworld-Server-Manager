# v0.7.92.0 — World Map: Guild Base Markers and Click-to-Select

First of the "real gaps" from the competitive feature review.

- **Guild base markers** on the live World Map (amber squares labelled with the guild name), read
  from the base coordinates in the decoded `Level.sav.json`. Verified live against the real world:
  both bases of guild "MystTik" returned with the coordinates stored in the save.
- Markers appear in the **experimental real-world-position mode** (Palpagos map). Bases come from
  save coordinates and players from the REST API; only the calibrated formula treats them as one
  coordinate space, so the default relative-spread view deliberately shows players only.
- **Click a player dot** to select that player, then use Teleport To Me / Teleport To Player from a
  new action row under the map. Palworld's vanilla RCON has no teleport-to-coordinates command, so
  click-anywhere teleport is not offered.
- New **Refresh Bases** button; bases load once when the map first shows them, never on the status
  poll. Tab switches clear them so one server's bases never show on another's map.

Touches `MystTiq.HeadlessHost` and `MystTiq.Desktop`. Full detail:
[`docs/architecture/v0.7.92.0-world-map-base-markers.md`](../docs/architecture/v0.7.92.0-world-map-base-markers.md).

# MystTiq v0.6.15.0 — Save-Data Edit Engine Foundation (Pal Editor)

## Highlights

- **New: Pal Editor.** Following a survey of 21 other Palworld server tools, the single most-requested capability MystTiq lacked was real Pal editing — several popular tools do this today. You can now browse every Pal in your active world and adjust a Pal's nickname, level, rank, IVs (Talent HP/Shot/Defense), gender, and Lucky flag, with the same safety pipeline (preview, fresh safety backup, independent verification before commit) already used for guild and base ownership repair.
- Requires PalServer to be stopped while applying an edit, matching every other save-mutating feature in MystTiq.
- **A real bug found and fixed while testing this release**: Pal ownership wasn't resolving correctly — every Pal appeared unowned even when it genuinely belonged to a player. Fixed and confirmed against real save data.

## Upgrade notes

- No configuration schema change — an existing v3 `mysttiq.json` loads unchanged.
- New, additive routes: `GET /pals`, `POST /pals/edit/preview`, `POST /pals/edit/apply`.

## What's deferred

- Editing a Pal's active/passive skills or its species — not yet supported.
- Player inventory and base storage editing — the other half of what this survey found competitors doing; a separate, larger future release (it needs to work across both `Level.sav` and each player's own save file).
- A live in-game world map, two-way Discord bot control, and anti-cheat scanning are scoped as the next few releases — see `docs/architecture/v0.6.15-plus-competitive-survey.md` for the full comparison this came from.

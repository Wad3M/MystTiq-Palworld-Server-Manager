# MystTiq Palworld Server Manager v0.3.0.5

## Passwordless Linux Deployment & SSH Trust Foundation

v0.3.0.5 removes repeated Linux password prompts from the normal MystTiq development/test deployment loop.

### One-time setup

From Windows PowerShell:

```powershell
.\scripts\Initialize-MystTiqLinuxSSH.ps1
```

The setup creates/reuses a dedicated MystTiq Ed25519 key, installs only its public key on `mystroth@192.168.1.248`, and verifies key-only login.

### Normal deployment

```powershell
.\scripts\Deploy-Test-MystTiqLinux.ps1 -Extended
```

The deployment wrapper now prefers the dedicated key and uses it consistently for SSH and SCP. Missing/failed key authentication stops deployment with setup instructions.

Password prompting is available only through explicit:

```powershell
-AllowPasswordFallback
```

### Security

The private key remains on Windows and is never copied to Linux. Normal key-authenticated connections disable password authentication for the connection and run in OpenSSH batch mode.

All previous archive hashing and automated Linux acceptance behavior remains in place.

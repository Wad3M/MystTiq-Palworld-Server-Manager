# MystTiq v0.7.83.0 — New Server Wizard: Reordered Steps & Genuine Second-Server Support

## Highlights

- **"Set Up New Server" reordered**: World Source (New World / Import / Clone) → Server Identity &
  Ports (with live port-conflict warnings) → World Settings (preset or customize after install) →
  Install Directory → Download & Install → Confirm & Finish.
- **New: genuine second-server support** — if your default server location is already occupied, the
  wizard now registers a real, separate fleet profile at a derived directory, automatically restarts
  the local MystTiq service to bring it online, and reconnects — no manual steps required.
- **Removed the "+" menu's "Clone a Server" shortcut** — Clone is now only reached through the
  wizard's own World Source step, where it belongs.
- **Set Up New Server now auto-connects** instead of requiring a manual click, and skips straight to
  World Source once ready.
- **Fixed several real bugs found while building and testing this**: a duplicate-connection guard
  that blocked the wizard's own Connect step entirely, a Step 1 header that silently stayed blank,
  the Confirm summary showing a generic placeholder name instead of your actual server name, and a
  second, deeper round of the Alert Center disk-space-prediction crash fix.

## Upgrade notes

- No configuration schema changes. Touches `MystTiq.Desktop` only.

# v0.2.15.8 FIX1 — Runtime Evidence Model & Confidence Engine

Runtime state is now evidence-based rather than binary. Positive current-session proof yields **Confirmed Loaded**. Correctly deployed/enabled UE4SS mods with no unique execution signature yield **Active / Unverified**, not the false claim **Not Loaded**. Real deployment blockers remain **Not Loaded**, runtime failures remain **Error**, disabled mods remain **Disabled**, and non-UE4SS types remain **N/A**.

Evidence assessments include confidence, source, matched alias, and explanation. UE4SS loader acknowledgement such as `Mod '<name>' has enabled.txt, starting mod.` is recognized as positive evidence.

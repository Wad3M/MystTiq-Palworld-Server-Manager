# MystTiq v0.7.22.0 — Per-Action Busy Status

## Highlights

- **The footer now says what's actually running.** Starting, stopping, or restarting the server, creating or restoring a backup, and applying a world transaction all show their own real status text instead of the same generic "Working…" no matter what triggered it.
- Everything else still shows "Working…" for now — this covers the highest-value operations first, not every possible action in the app.

## Upgrade notes

- Desktop-only change, no configuration or server-side impact.

# MystTiq Palworld Server Manager v0.2.15.1

## UE4SS Runtime Resolver — Phase 1

### Purpose

Introduce one authoritative UE4SS path resolver before migrating MOD operations away from hard-coded `Win64\Mods` assumptions.

### Implemented

- Added `Ue4ssRuntimeResolver` with session-cached path resolution.
- Added `Ue4ssRuntimeInfo` to expose Win64, UE4SS, modern, legacy, active, and runtime-reported MOD paths.
- Modern layout detection recognizes `Win64\ue4ss\Mods` when the UE4SS folder and Mods folder exist.
- Runtime verification parses the newest usable `UE4SS.log` evidence for `Loading mods from: <path>`.
- Legacy compatibility recognizes `Win64\Mods` when no modern path or runtime-log path is available.
- Expected-path fallback uses the detected UE4SS installation layout without creating or modifying directories.
- Manager/runtime path disagreement is reported as `Degraded` with a concrete mismatch message.
- Startup logging records the complete resolver decision and health state.
- Resolution is stable for the session until explicitly refreshed or invalidated.

### Scope Control

Phase 1 is detection and architecture only. It does not migrate legacy mods, normalize ZIP packages, or rewrite install/enable/disable/delete/verify behavior yet. Existing MOD data is not moved or deleted.

### Next Phase

v0.2.15.2 will migrate MOD operations and inventory to consume the resolver's authoritative Active Mods Root.

# MystTiq v0.7.12.0 — Test Coverage: Whitelist Enforcement & Route Smoke

## Highlights

- **A real test for the whitelist's actual kick behavior**, not just its settings page — a new standalone harness fakes only what needs faking and runs the real enforcement logic through 6 scenarios (enable/disable, kick vs. allow, re-kick timing, config-change reset, and an unreachable server).
- **Permanent coverage for every route added in the last three releases** (Unban, Ban List, Teleport, Save Now, Whitelist, server FPS metrics) — previously these had only been checked by hand during development, with nothing to catch a future regression.

## Upgrade notes

- This is a test-infrastructure release — no product behavior changed. No configuration schema change, no server-side change to the shipped app.
- A stale code comment describing whitelist and teleport as still-deferred features (both have since shipped) was also fixed.

# MystTiq Palworld Server Manager v0.2.13.1

## Version & Build System

This development release establishes a single authoritative application version and removes active hard-coded version strings from runtime services.

### Added
- Central `Directory.Build.props` version source.
- Runtime `ApplicationVersion` service based on generated assembly metadata.
- Shared PowerShell version reader for packaging and installer builds.
- Tag-to-project version validation in the GitHub release workflow.
- Version-focused build and release checklists.

### Changed
- Window title and sidebar version now use assembly metadata.
- HTTP user agents and exported repair metadata now use the central version.
- Portable and installer scripts now default to the central project version.
- Release notes are selected dynamically from the requested version.

### Scope
This release does not yet introduce portable data paths. That work begins in v0.2.13.2.

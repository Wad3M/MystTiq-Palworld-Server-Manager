# MystTiq Palworld Server Manager v0.2.14.2

## Core Reliability

- Added a single authoritative `PlayerSaveDiscoveryService`.
- Added guarded filesystem enumeration and stable-file checks.
- Unified player-save validation across player history, recovery, Guilds, World discovery, and World Tools.
- Added rejected-player-save diagnostics with clear reasons.
- Added a startup coordinator so world-data stages execute in a predictable order and fail independently.
- Improved resilience when Palworld replaces files or folders during autosaves.

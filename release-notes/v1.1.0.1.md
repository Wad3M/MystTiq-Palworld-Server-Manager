# v1.1.0.1 — Start-up Notice Fix

**Fixed: "Something went wrong (background task)" after the desktop started.** Starting its local helper, the desktop
checks whether the helper's port is already in use. Windows takes about two seconds to refuse a connection to a port
nothing is listening on, but the check stopped waiting after 0.75 seconds and left its attempt running. When that
attempt failed later, nothing was waiting for it, so the desktop showed the error notice and wrote a crash record.

Nothing stopped and no data was affected, but the notice could appear on any start where the helper had to be
launched. The check now cancels its attempt when it stops waiting and finishes it before moving on.

## Downloads

Use **Windows-x64.zip** for the self-contained Avalonia desktop and its matching headless service. Extract the whole folder and run `MystTiq.Desktop.exe`; retain `headless` alongside it. **FullSource.zip** is the developer source package. Check downloaded ZIPs against `SHA256SUMS.txt`.

## Upgrading from v1.1.0.0

Back up your server data and configuration, then extract into a new application folder (or use **Update** on the MystTiq row of the Update Center once this release is published). Keep the existing service/configuration/data locations and the matching `headless` folder; verify your connection and language choice before resuming administration. Nothing to convert. Coming from an older version, also read the [v1.1.0.0 notes](v1.1.0.0.md).

Back up server data before upgrading. Keep application files separate from server data; closing the desktop does not stop a managed server until you choose Exit from the tray.
